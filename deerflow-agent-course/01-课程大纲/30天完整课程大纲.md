# 🦌 DeerFlow Python Agent 架构师训练营：30天完整课程大纲

## 🎯 课程概述

### 课程目标
本课程旨在通过30天系统化学习，从零开始掌握DeerFlow Python Agent框架，培养学员成为能够设计、开发和部署复杂AI Agent系统的高级架构师。

### 课程特色
- **120节精品课程**：30天×4节/天，每节45分钟，科学编排学习曲线
- **手把手实战**：基于真实DeerFlow 2.0代码库，逐行分析核心源码
- **面试导向**：每周末设置大厂面试真题解析和模拟面试
- **项目驱动**：从零构建一个完整的多Agent系统作为毕业项目

### 学员要求
- **基础**：Python基础语法，了解异步编程
- **环境**：本地开发环境（Python 3.12+、Docker基础）
- **态度**：每天投入3-4小时学习时间，完成作业和项目

2. **软件安装**：
   - Python 3.12+
   - Docker & Docker Compose
   - Git
   - 代码编辑器（VS Code推荐）
3. **账户注册**：
   - OpenAI API账户（或其他LLM提供商）
