# 🦌 DeerFlow Python Agent 架构师训练营 - 第一周教师指南

## 📚 教学指南：第一周（Day 1-7）

### 教学目标
1. **知识目标**：掌握现代AI Agent架构的核心概念，理解LangGraph、LangChain和DeerFlow的关系
2. **技能目标**：能够配置开发环境，运行第一个Agent，理解状态管理和中间件机制
3. **思维目标**：培养系统化思考Agent架构的能力，理解各组件间的协作关系

### 教学重点与难点
- **重点**：LangGraph StateGraph、ThreadState、中间件链、工具系统
- **难点**：RunnableConfig运行时配置、自定义Reducer函数、中间件执行顺序

### 教学资源准备
1. **硬件**：演示用电脑（16GB+ RAM，支持AVX指令集）
2. **软件**：Python 3.12.0、Docker Desktop、VS Code、Git
3. **账户**：OpenAI API密钥、GitHub账户
4. **代码**：DeerFlow 2.0代码库（提前克隆到本地）

### 常见问题解答

#### Q1：学员没有AI开发经验怎么办？
**A**：课程设计从基础开始，假设学员只有Python基础。第一周重点讲解概念和基础操作，提供详细的步骤指导。同时提供额外的预备知识材料。

#### Q2：如何解决环境配置问题？
**A**：提供详细的环境配置指南和Docker容器。设置助教值班时间，帮助学员解决环境问题。录制环境配置视频教程。

#### Q3：学员进度不一致如何处理？
**A**：采用分层教学策略：
- 基础任务：所有学员必须完成
- 扩展挑战：为进阶学员提供额外练习
- 个性化指导：根据学员水平提供不同深度的指导

#### Q4：如何评估学习效果？
**A**：采用多维度评估：
- 每日测验（选择题、简答题）
- 每周项目（代码实现、架构设计）
- 月度考核（综合能力测试）
- 毕业答辩（项目演示和问答）

### 第一周项目任务

#### 基础项目：构建简单的文件处理Agent
**要求**：
1. 创建一个能够读取、写入、处理文件的Agent
2. 实现自定义中间件记录操作日志
3. 添加文件类型验证和错误处理
4. 编写测试用例，覆盖率>70%

**交付物**：
1. 完整的Python代码
2. 配置文件和环境说明
3. 测试报告和性能分析
4. 使用文档和API文档

#### 扩展挑战：实现多格式文件转换
**要求**：
1. 支持PDF、Word、Markdown格式互转
2. 使用子代理处理复杂转换任务
3. 实现转换进度跟踪和状态恢复
4. 添加批量处理和支持队列

## 📝 教师备忘录

### 第一天重点
- **关键概念**：StateGraph、AgentState、Runnable
- **难点突破**：使用可视化工具展示状态流转
- **成功标准**：所有学员成功运行第一个Agent

### 第二天重点
- **关键概念**：TypedDict、Reducer函数、配置继承
- **难点突破**：通过代码对比理解Reducer作用
- **成功标准**：学员能够扩展ThreadState

### 第三天重点
- **关键概念**：提示模板、内存注入、技能系统
- **难点突破**：分析实际注入的提示内容
- **成功标准**：学员能够创建自定义技能

### 第四天重点
- **关键概念**：中间件链、生命周期、状态传递
- **难点突破**：跟踪一个请求的完整流程
- **成功标准**：学员理解中间件执行顺序

### 第五天重点
- **关键概念**：错误处理、澄清机制、中断恢复
- **难点突破**：模拟各种错误场景的处理
- **成功标准**：学员能够实现优雅的错误处理

### 第六天重点
- **关键概念**：图片处理、子代理限制、任务管理
- **难点突破**：Base64编码和图片嵌入
- **成功标准**：学员能够处理图片相关任务

### 第七天重点
- **关键概念**：工具发现、延迟加载、工具绑定
- **难点突破**：理解工具调用链
- **成功标准**：学员能够开发和集成自定义工具
