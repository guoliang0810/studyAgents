# 🎓 详细教案 - Day1 第1节课：AI Agent演进史

## 📋 课程基本信息
- **课程名称**: AI Agent演进史与大厂技术选型
- **授课日期**: 2024年3月25日（周一）
- **上课时间**: 上午9:00-9:45（第1节课）
- **授课教师**: 张老师
- **学生背景**: Python基础一般，刚学完基础语法，对AI有浓厚兴趣
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解AI Agent发展的四个阶段及其特征
2. 掌握现代AI Agent的五个核心特征
3. 了解各大厂在AI Agent领域的技术布局

### 技能目标（学生将能够）
1. 对比分析不同阶段的AI Agent技术特点
2. 识别AI Agent在实际应用中的价值
3. 初步理解DeerFlow在大厂技术生态中的定位

### 情感/态度目标
1. 激发对AI Agent技术的兴趣和好奇心
2. 建立从历史演进理解技术发展的视角
3. 培养技术选型的批判性思维

## 📚 教学重点与难点
- **教学重点**: AI Agent四个发展阶段的特征对比，现代AI Agent的核心能力
- **教学难点**: 理解从规则系统到LLM-based Agent的技术跃迁
- **突破方法**: 使用生活化比喻（从计算器到智能助手），展示实际代码示例

## 🛠️ 教学资源准备
- **硬件**: 演示用电脑（16GB+ RAM）
- **软件**: VS Code、Chrome浏览器、PPT演示软件
- **账户**: GitHub账户（展示DeerFlow仓库）
- **代码**: DeerFlow 2.0代码库（提前克隆到本地）
- **演示材料**: PPT幻灯片（15页）、技术对比表格、时间轴图
- **学生材料**: 课堂笔记模板、阶段特征对比表、思考问题卡

## 🎭 师生互动设计

### 提问策略
1. **导入提问**: "大家用过哪些AI工具？"（激活经验）
2. **引导提问**: "为什么规则系统无法处理复杂对话？"（引导思考局限）
3. **挑战提问**: "如果没有大语言模型，AI Agent可能发展起来吗？"（激发深度思考）
4. **应用提问**: "你能想到AI Agent在生活中的哪些应用？"（促进知识迁移）

### 讨论活动
1. **小组讨论**: 3人一组，讨论现代AI Agent应用场景
2. **案例分析**: 分析订餐Agent、编程助手的工作流程
3. **技术辩论**: "规则系统在特定场景是否仍有价值？"
4. **场景想象**: "如果AI Agent有身体（机器人），能做什么？"

### 反馈机制
1. **即时反馈**: 课堂问答，及时纠正错误理解
2. **过程反馈**: 练习指导，帮助完善对比分析
3. **成果反馈**: 点评小组分享，提供改进建议
4. **同伴反馈**: 小组内互相评价讨论贡献

## 🔧 差异化教学

### 针对基础薄弱学生

3. **领导机会**: 担任小组讨论引导者

1. **渐进提升**: 从填写表格到自主分析演进规律
2. **榜样学习**: 学习优秀同学的分析框架

## 📊 评估方式

### 形成性评估（课堂内）
1. **观察评估**: 观察学生参与讨论的积极性和深度
2. **提问评估**: 通过提问检验对发展阶段的理解
3. **练习评估**: 检查对比表格的完整性和准确性
4. **自评互评**: 学生自我评估理解程度，小组互评贡献

### 总结性评估（课堂后）
1. **作业评估**: 检查阅读理解和思考作业质量
2. **测验关联**: 在周测验中设置相关题目
3. **项目基础**: 为后续Agent设计项目打下基础

### 评估标准
- **优秀**: 能清晰阐述四个阶段特征，并能分析技术演进的内在逻辑
- **良好**: 能正确描述四个阶段，理解现代AI Agent特征
- **合格**: 能记住四个阶段名称和基本特征
- **需改进**: 混淆发展阶段，不理解技术演进意义

1. **网络中断**: 提前下载PPT和视频到本地，使用离线演示
2. **共享屏幕故障**: 准备截图版PPT，通过聊天框发送

### 学生问题
1. **理解困难**: 增加生活化比喻，使用更多具体示例
2. **进度跟不上**: 提供课堂笔记摘要，课后一对一辅导
3. **兴趣不足**: 增加趣味案例（如AI玩游戏、创作音乐）
4. **技术背景弱**: 强调概念理解优先，代码实现后续学习

### 内容调整
1. **进度过快**: 增加小组讨论时间，减少理论讲解
2. **进度过慢**: 精简历史细节，聚焦核心演进逻辑
3. **内容过难**: 重点讲解现代AI Agent，简化历史阶段
4. **内容过易**: 增加技术深度，讨论实现挑战和限制
