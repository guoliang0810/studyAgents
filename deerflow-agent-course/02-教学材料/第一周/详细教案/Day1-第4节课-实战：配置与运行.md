2. 理解AI Agent系统的基本组件和运行机制

### 技能目标（学生将能够）
1. 独立完成DeerFlow环境配置和依赖安装
2. 配置API密钥和运行第一个Agent
3. 诊断和解决常见的环境配置问题

### 情感/态度目标
1. 体验从理论到实践的转化过程，增强学习信心

## 🎭 师生互动设计

### 提问策略
1. **经验激活提问**: "你以前配置Python环境遇到过什么问题？怎么解决的？"（连接已有经验）
2. **过程检查提问**: "当前步骤遇到了什么困难？需要什么帮助？"（及时发现障碍）
3. **理解验证提问**: "虚拟环境的主要作用是什么？为什么我们需要它？"（检验概念理解）
4. **应用延伸提问**: "如果你的项目需要添加新依赖，会怎么做？"（促进知识迁移）

### 实践活动
1. **分步跟随**: 教师演示一步，学生操作一步，确保同步
2. **屏幕共享**: 邀请学生共享屏幕，集体帮助诊断问题
3. **结对编程**: 2人一组，互相检查配置，讨论解决方案
4. **代码审查**: 互相检查配置文件，确保安全和正确性

### 反馈机制
1. **即时反馈**: 操作正确时立即肯定，错误时立即纠正
2. **进度反馈**: 提供检查清单，学生可自我评估进度
3. **成果反馈**: 展示成功运行示例，增强完成信心
4. **同伴反馈**: 小组内互相验收配置，提供改进建议

## 🔧 差异化教学

### 针对基础薄弱学生
1. **简化任务**: 提供预配置的虚拟机镜像或Docker容器
2. **额外支持**: 一对一指导，帮助解决具体环境问题
3. **资源推荐**: 提供Python环境配置入门教程
4. **成功体验**: 确保能完成基本配置，运行简单示例

2. **深入探索**: 研究依赖关系，理解包冲突解决原理
3. **优化任务**: 优化配置流程，编写自动化配置脚本
4. **帮助角色**: 担任助教，帮助其他同学解决配置问题

### 针对中等水平学生
1. **标准完成**: 按照指南完成所有配置步骤
2. **问题记录**: 记录遇到的问题和解决方案
3. **理解验证**: 能解释每个配置步骤的目的
4. **互助学习**: 参与小组讨论，分享配置技巧

## 📊 评估方式

### 形成性评估（课堂内）
1. **操作评估**: 观察学生配置步骤的正确性和顺序
2. **问题解决评估**: 评估学生诊断和解决配置问题的能力
3. **理解评估**: 通过提问检验对配置项作用的理解
4. **完成度评估**: 检查是否成功运行第一个Agent

### 总结性评估（课堂后）
1. **作业评估**: 检查配置文件的完整性和正确性
2. **环境评估**: 后续课程依赖本课配置，作为持续评估
3. **问题记录评估**: 评估问题诊断和解决记录的全面性

### 评估标准
- **优秀**: 能独立完成所有配置，理解各配置项作用，能帮助他人解决问题
- **良好**: 能完成所有配置，基本理解配置目的，能解决常见问题
- **合格**: 在指导下完成配置，能运行Agent，理解关键步骤
- **需改进**: 配置不完整，无法运行Agent，不理解配置目的

## 🚨 应急预案

### 技术故障
1. **网络问题**: 提供离线安装包，本地依赖镜像
2. **API服务不可用**: 提供本地模型选项（Ollama），备用测试密钥

4. **Python版本不兼容**: 提供Docker镜像，在线开发环境链接

### 学生问题
1. **配置完全失败**: 提供云端开发环境访问权限
2. **时间不够**: 提供课后继续完成的详细指南，录制操作视频

4. **设备限制**: 提供在线Jupyter Notebook环境，免配置运行

### 内容调整
1. **进度过快**: 增加配置原理讲解，深入每个步骤的意义
2. **进度过慢**: 聚焦核心配置（虚拟环境、依赖、API密钥），简化次要步骤
3. **内容过难**: 提供更详细的步骤分解，增加检查点

### 附录C：常见问题速查表
| 问题症状 | 可能原因 | 检查步骤 | 解决方案 |
|----------|----------|----------|----------|
| "Python: command not found" | Python未安装或不在PATH | 1. `python --version`<br>2. `which python` | 安装Python 3.12+，添加PATH |
| "No module named 'venv'" | Python安装不完整 | `python -m ensurepip` | 重新安装Python，选择"Add to PATH" |
| "Could not find a version..." | 网络问题或包名错误 | 1. `pip config list`<br>2. 测试网络连接 | 使用国内镜像：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| "ERROR: Failed building wheel..." | 缺少编译工具 | 系统环境检查 | Linux: `apt install build-essential`<br>Mac: `xcode-select --install`<br>Windows: 安装Visual C++ Build Tools |
| "AuthenticationError" | API密钥无效或配额不足 | 1. 检查config.yaml格式<br>2. 检查密钥有效性<br>3. 检查账户余额 | 1. 修正YAML格式<br>2. 申请新密钥<br>3. 检查OpenAI账户 |
| "ModuleNotFoundError: No module named 'xxx'" | 依赖未安装或虚拟环境未激活 | 1. `pip list`<br>2. 检查虚拟环境激活 | 1. `pip install xxx`<br>2. 重新激活虚拟环境 |
| "ConnectionError" | 网络连接问题 | 1. `ping api.openai.com`<br>2. 检查代理设置 | 1. 检查防火墙<br>2. 配置代理：`export HTTPS_PROXY=...` |
| "YAML parse error" | 配置文件语法错误 | 检查config.yaml格式 | 使用YAML验证工具，检查缩进和冒号 |
| "AttributeError: module 'xxx' has no attribute 'yyy'" | 版本不兼容 | 检查包版本：`pip show xxx` | 安装指定版本：`pip install xxx==1.2.3` |
| "RuntimeError: Could not determine..." | 环境检测失败 | 检查系统信息 | 设置环境变量：`export DEERFLOW_ENV=development` |
