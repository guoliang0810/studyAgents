# ThreadState字段速查卡

## 核心字段（必需）
- `messages: List[BaseMessage]` - 对话消息历史，Agent记忆核心
  - 类型：LangChain BaseMessage列表
  - 作用：保存用户输入和Agent响应
  - 示例：`[HumanMessage("你好"), AIMessage("你好，有什么可以帮助？")]`

## 可选字段（NotRequired）
- `sandbox: dict | None` - 沙箱执行环境状态
  - 作用：管理代码执行沙箱的配置和状态
  - 包含：环境变量、挂载目录、资源限制等

- `thread_data: dict | None` - 线程自定义数据
  - 作用：存储会话级别的自定义数据
  - 使用：开发者可自由扩展，存储业务相关状态

- `title: str | None` - 对话标题
  - 作用：自动生成或手动设置的对话标题
  - 生成：由TitleMiddleware自动生成

- `todos: list | None` - 待办事项列表
  - 作用：记录Agent计划执行的任务
  - 管理：由TodoMiddleware管理，支持增删改查

- `uploaded_files: list[dict] | None` - 上传文件列表
  - 作用：记录用户上传的文件信息
  - 信息：文件名、大小、类型、存储路径等

## 特殊处理字段（Annotated）
- `artifacts: Annotated[list[str], merge_artifacts]` - 生成文件列表
  - 作用：记录Agent生成的文件路径
  - 合并：使用merge_artifacts函数合并（连接+去重）
  - 示例：`["report.pdf", "data.csv"]`

- `viewed_images: Annotated[dict[str, dict], merge_viewed_images]` - 查看图片记录
  - 作用：记录Agent查看的图片信息
  - 结构：字典，key为图片路径，value为图片元数据
  - 合并：使用merge_viewed_images函数合并

## 设计模式速查
1. **类型安全**: 使用TypedDict确保字段类型正确
2. **可选字段**: 使用NotRequired标记可选字段
3. **合并逻辑**: 使用Annotated绑定字段和合并函数
4. **向后兼容**: 新字段默认可选，不影响现有代码
5. **领域建模**: 字段反映业务领域概念
