# Reducer设计原则检查清单

## 原则1：幂等性（Idempotence）
- [ ] **定义**: 多次合并相同状态，结果不变
- [ ] **公式**: merge(a, b) == merge(merge(a, b), b)
- [ ] **检查方法**: 用相同参数调用两次，比较结果
- [ ] **示例**: 列表去重合并满足，计数器相加不满足（每次增加）
- [ ] **业务意义**: 保证重复操作不会产生意外效果

## 原则2：可交换性（Commutativity）
- [ ] **定义**: 合并顺序不影响结果
- [ ] **公式**: merge(a, b) == merge(b, a)
- [ ] **检查方法**: 交换参数顺序调用，比较结果
- [ ] **示例**: 加法满足，减法不满足
- [ ] **业务意义**: 支持并发和乱序状态更新

## 原则3：可结合性（Associativity）
- [ ] **定义**: 分组合并不影响结果
- [ ] **公式**: merge(a, merge(b, c)) == merge(merge(a, b), c)
- [ ] **检查方法**: 不同分组方式调用，比较结果
- [ ] **示例**: 加法满足，除法不满足
- [ ] **业务意义**: 支持分布式和分层状态合并

## 原则4：空值处理（Null Handling）
- [ ] **定义**: 正确处理None/空值输入
- [ ] **规则1**: merge(None, x) == x (x != None)
- [ ] **规则2**: merge(x, None) == x (x != None)
- [ ] **规则3**: merge(None, None) == 合理默认值
- [ ] **检查方法**: 测试所有None组合情况
- [ ] **业务意义**: 处理初始化、缺失、清理等场景

## 原则5：类型安全（Type Safety）
- [ ] **定义**: 输入输出类型明确且一致
- [ ] **检查1**: 函数签名明确标注类型
- [ ] **检查2**: 处理类型转换和验证
- [ ] **检查3**: 类型不匹配时明确错误
- [ ] **工具支持**: 使用mypy进行类型检查
- [ ] **业务意义**: 减少运行时错误，提高代码可靠性

## 原则6：性能可接受（Performance）
- [ ] **定义**: 合并操作时间和空间复杂度合理
- [ ] **时间复杂度**: O(1) > O(log n) > O(n) > O(n²)
- [ ] **空间复杂度**: 避免不必要复制和缓存
- [ ] **优化策略**: 惰性计算、批处理、缓存
- [ ] **检查方法**: 性能测试和大数据量测试
- [ ] **业务意义**: 支持大规模和高频状态更新

## 常见反模式
1. **全局状态依赖**: Reducer依赖外部可变状态
2. **副作用操作**: Reducer执行IO、网络请求等副作用

# Reducer实现模板
from typing import TypeVar, Callable

T = TypeVar('T')  # 状态类型

def create_reducer_template(
    merge_logic: Callable[[T, T], T],
    default_value: T
) -> Callable[[T | None, T | None], T]:
    """创建符合设计原则的Reducer模板"""
    
    def reducer(existing: T | None, new: T | None) -> T:
        # 处理空值
        if existing is None and new is None:
            return default_value
        if existing is None:
            return new  # type: ignore
        if new is None:
            return existing
        
        # 应用合并逻辑
        return merge_logic(existing, new)
    
    return reducer

# 使用模板创建计数器Reducer
def add_numbers(a: int, b: int) -> int:
    return a + b

merge_counter = create_reducer_template(add_numbers, 0)

# 使用模板创建取最大值Reducer  
def max_value(a: int, b: int) -> int:
    return max(a, b)

merge_max = create_reducer_template(max_value, 0)

# 复杂业务逻辑Reducer示例：用户会话状态
from datetime import datetime, timedelta
from typing import TypedDict

class UserSession(TypedDict):
    user_id: str
    last_active: datetime
    activity_count: int
    preferences: dict

def merge_sessions(existing: UserSession, new: UserSession) -> UserSession:
    """合并用户会话状态"""
    # 使用较新的活跃时间
    last_active = max(existing["last_active"], new["last_active"])
    
    # 累加活动计数
    activity_count = existing["activity_count"] + new["activity_count"]
    
    # 合并偏好，新的覆盖旧的
    preferences = {**existing["preferences"], **new["preferences"]}
    
    return {
        "user_id": existing["user_id"],  # 假设相同用户
        "last_active": last_active,
        "activity_count": activity_count,
        "preferences": preferences
    }

# 创建会话Reducer
merge_user_session = create_reducer_template(merge_sessions, {
    "user_id": "",
    "last_active": datetime.min,
    "activity_count": 0,
    "preferences": {}
})

# 集成到ThreadState
from typing import Annotated
from deerflow.agents.thread_state import ThreadState

class ExtendedThreadState(ThreadState):
    user_sessions: Annotated[dict[str, UserSession], merge_user_session]
