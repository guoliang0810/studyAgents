# 🎓 详细教案 - 第9节课：提示模板架构

## 📋 课程基本信息
- **课程名称**: Day3-第9节课：提示模板架构
- **授课日期**: 2024年3月27日（周三）
- **上课时间**: 上午9:00-9:45
- **授课教师**: 张老师（10年AI系统架构经验，DeerFlow核心贡献者）
- **学生背景**: Python基础一般，前两天的学习掌握了状态管理基础
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解提示模板在AI Agent系统中的核心作用
2. 掌握DeerFlow提示模板的五大设计原则
3. 了解提示模板继承体系的结构和用途
4. 理解多语言提示支持系统的实现原理

### 技能目标（学生将能够）
1. 设计符合五大原则的专业提示模板
2. 使用PromptTemplate基类创建自定义模板
3. 实现简单的模板渲染和变量替换
4. 设计翻译助手等实际应用的提示模板

### 情感/态度目标
1. 培养系统化设计思维，理解模块化设计的重要性
2. 增强对AI Agent可解释性和可控性的认识
3. 激发对提示工程技术的探索兴趣

## 📚 教学重点与难点
- **教学重点**: 提示模板五大设计原则、模板继承体系、模板渲染机制
- **教学难点**: 模板变量注入的动态性、多语言模板的切换逻辑
- **突破方法**: 通过对比简单模板与高级模板的差异，逐步引入复杂概念；使用可视化流程图展示模板渲染过程

## 🛠️ 教学资源准备
- **硬件**: 演示用电脑（16GB+ RAM，支持AVX指令集）
- **软件**: Python 3.12.0、VS Code、Jupyter Notebook
- **账户**: OpenAI API密钥（备用）、GitHub账户
- **代码**: DeerFlow 2.0代码库中的提示模板模块
- **演示材料**: PPT幻灯片（提示模板架构图、五大原则图示、代码示例）
- **学生材料**: 练习手册、模板设计检查清单、评估表

## 🎭 师生互动设计

### 提问策略
1. **导入提问**: "你听说过'提示工程'吗？"激活已有知识
2. **引导提问**: "为什么需要模板系统？直接写提示不行吗？"引导学生思考设计价值
3. **挑战提问**: "如果模板变量冲突了怎么办？"激发深度思考
4. **应用提问**: "设计电商客服Agent的提示模板需要考虑哪些因素？"联系实际场景

### 讨论活动
1. **小组讨论**: 3-4人小组，讨论"优秀提示模板的特征"
2. **案例分析**: 分析GitHub Copilot等产品的提示模板设计
3. **代码审查**: 互相review提示模板代码，提高设计质量

### 反馈机制
1. **即时反馈**: 课堂问答，及时纠正对模板原则的错误理解
2. **过程反馈**: 练习指导，帮助学生完善模板设计
3. **成果反馈**: 作业批改，提供模板设计优化建议
4. **同伴反馈**: 学生互评模板设计，互相学习优点

## 🔧 差异化教学

### 针对基础薄弱学生
1. **简化任务**: 提供填空式模板设计练习
2. **额外支持**: 一对一辅导模板变量设计
3. **资源推荐**: 提供提示工程基础阅读材料
4. **成功体验**: 设计可达成的子目标：完成一个简单模板

### 针对进阶学生
1. **扩展挑战**: 实现动态模板选择算法
2. **创新空间**: 设计模板版本管理和A/B测试系统
3. **领导机会**: 担任小组长，帮助其他同学理解模板设计
4. **项目实战**: 为真实项目设计专业提示模板

### 针对中等水平学生
1. **渐进提升**: 从简单模板逐步增加复杂性
2. **榜样学习**: 学习优秀同学的模板设计思路
3. **目标引导**: 设定明确的设计质量提升目标
4. **反馈激励**: 及时肯定设计改进和创意

## 📊 评估方式

### 形成性评估（课堂内）
1. **观察评估**: 观察学生设计模板时的思考过程和问题解决策略
2. **提问评估**: 通过提问检验对五大原则的理解程度
3. **练习评估**: 检查翻译助手模板设计的完整性和专业性
4. **自评互评**: 学生自我评估模板设计质量，互相提供反馈

### 总结性评估（课堂后）
1. **作业评估**: 批改三种类型模板设计作业，评分反馈
2. **测验评估**: 单元测验检验模板设计原则掌握情况
3. **项目评估**: 在周项目中评估模板设计的实际应用效果

### 评估标准
- **优秀（90-100分）**: 全面掌握五大原则，能设计专业级模板，考虑边界情况
- **良好（80-89分）**: 基本掌握原则，能完成符合要求的模板设计
- **合格（60-79分）**: 理解核心概念，能设计简单模板，需要指导完善
- **需改进（<60分）**: 需要重新学习模板设计原则和基本实现

## 🚨 应急预案

### 技术故障
1. **网络中断**: 准备离线演示材料，包含完整代码示例和图示
2. **软件故障**: 准备在线Python环境（如Google Colab）备用
3. **平台故障**: 准备备用教学平台（Zoom、腾讯会议等）
4. **代码运行错误**: 准备预先生成的运行结果截图和视频

### 学生问题
1. **理解困难**: 放慢节奏，增加生活化比喻（如"模板就像菜谱"）
2. **设计困难**: 提供模板设计检查清单和常见模式参考
3. **时间不足**: 调整内容优先级，先掌握五大原则，设计练习可课后完成
4. **兴趣不足**: 展示优秀模板设计的实际效果，激发学习动机

### 内容调整
1. **进度过快**: 增加模板设计练习时间，补充更多示例
2. **进度过慢**: 精简多语言支持等进阶内容，聚焦核心原则
3. **内容过难**: 分解复杂概念，先掌握基类再学习继承体系
4. **内容过易**: 增加动态模板选择、模板优化等深度挑战

- 保持模板简洁但完整
