#### 1. 中间件追踪原理（5分钟）

**教师讲解**：
```
🔍 追踪系统组成：
1. 执行记录器：记录每个中间件的开始/结束时间
2. 数据容器：存储执行记录，支持查询统计
3. 包装器：在不修改原有中间件的情况下添加追踪功能
4. 报告生成器：生成人类可读的性能报告
```

**代码展示**：
```python
# 中间件执行记录的数据结构
@dataclass
class MiddlewareExecution:
    middleware_name: str  # 中间件名称
    phase: str           # "before" 或 "after"
    start_time: float    # 开始时间
    end_time: float      # 结束时间
    duration_ms: float   # 执行时长（毫秒）
    success: bool        # 是否成功
    error: str           # 错误信息
```

#### 2. MiddlewareTracer实现（5分钟）

**教师讲解**：
```
📊 MiddlewareTracer职责：
1. 记录完整的请求执行过程
2. 管理所有中间件的执行记录
3. 生成详细的性能报告
4. 支持错误追踪和瓶颈定位
```

**代码展示**：
```python
class MiddlewareTracer:
    def __init__(self):
        self.executions: List[MiddlewareExecution] = []
        self.request_start: float = 0
        self.request_end: float = 0
    
    def start_request(self):
        """开始追踪整个请求"""
        self.request_start = time.time()
        print(f"⏱️  [{self.__class__.__name__}] 开始追踪请求")
    
    def record_execution(self, middleware_name, phase, start_time, end_time, success=True, error=""):
        """记录单个中间件执行"""
        execution = MiddlewareExecution(
            middleware_name=middleware_name,
            phase=phase,
            start_time=start_time,
            end_time=end_time,
            success=success,
            error=error
        )
        self.executions.append(execution)
        status = "✅" if success else "❌"
        print(f"  {status} {middleware_name}.{phase}: {execution.duration_ms:.2f}ms")
    
    def generate_report(self) -> str:
        """生成格式化的执行报告"""
        # 统计各种指标
        total_duration = (self.request_end - self.request_start) * 1000
        before_count = len([e for e in self.executions if e.phase == "before"])
        after_count = len([e for e in self.executions if e.phase == "after"])
        success_count = sum(1 for e in self.executions if e.success)
        
        # 找出最慢的中间件
        slowest = max(self.executions, key=lambda e: e.duration_ms)
        
        # 格式化报告
        return f"""
═══════════════════════════════════════════
        中间件执行追踪报告
═══════════════════════════════════════════

📊 总体统计:
   • 总执行时间: {total_duration:.2f}ms
   • 前置中间件数: {before_count}
   • 后置中间件数: {after_count}
   • 成功执行: {success_count}
   • 失败执行: {len(self.executions) - success_count}

⏱️  执行时间明细:
   【前置处理】
   • AuthenticationMiddleware: 12.34ms
   • LoggingMiddleware: 5.67ms
   • RateLimitMiddleware: 8.91ms

   【后置处理】
   • RateLimitMiddleware: 4.56ms
   • LoggingMiddleware: 3.21ms
   • AuthenticationMiddleware: 2.34ms

🐌 最慢中间件:
   • {slowest.middleware_name} ({slowest.phase}): {slowest.duration_ms:.2f}ms

⚠️  错误列表:
   • 无错误
═══════════════════════════════════════════
"""
```

#### 3. TracedMiddleware包装器（5分钟）

**教师讲解**：
```
🎁 包装器设计模式：
优点：
1. 不修改原有中间件代码
2. 可以灵活添加/移除追踪功能
3. 支持对任意中间件进行包装
```

**代码展示**：
```python
class TracedMiddleware:
    """带追踪功能的中间件包装器"""
    
    def __init__(self, middleware: AgentMiddleware, tracer: MiddlewareTracer):
        self.middleware = middleware
        self.tracer = tracer
    
    async def before_agent(self, request, config=None):
        """追踪前置执行"""
        start = time.time()
        try:
            result = await self.middleware.before_agent(request, config)
            self.tracer.record_execution(
                self.middleware.name, "before", start, time.time(), success=True
            )
            return result
        except Exception as e:
            self.tracer.record_execution(
                self.middleware.name, "before", start, time.time(), success=False, error=str(e)
            )
            raise
    
    async def after_agent(self, response, config=None):
        """追踪后置执行"""
        start = time.time()
        try:
            result = await self.middleware.after_agent(response, config)
            self.tracer.record_execution(
                self.middleware.name, "after", start, time.time(), success=True
            )
            return result
        except Exception as e:
            self.tracer.record_execution(
                self.middleware.name, "after", start, time.time(), success=False, error=str(e)
            )
            raise
```

class PerformanceMiddleware:
    """性能分析中间件"""
    def __init__(self):
        self.metrics: Dict[str, List[float]] = {}
    
    async def before_agent(self, request, config=None):
        request["_start_time"] = time.time()
        return request
    
    async def after_agent(self, response, config=None):
        start_time = response.get("_start_time")
        if start_time:
            duration = time.time() - start_time
            middleware_name = self.__class__.__name__
            
            if middleware_name not in self.metrics:
                self.metrics[middleware_name] = []
            self.metrics[middleware_name].append(duration)
        
        return response
    
    def get_performance_report(self) -> Dict:
        """获取性能统计报告"""
        report = {}
        for name, durations in self.metrics.items():
            if durations:
                report[name] = {
                    "count": len(durations),
                    "avg_ms": sum(durations) / len(durations) * 1000,
                    "p95_ms": sorted(durations)[int(len(durations) * 0.95)] * 1000,
                    "max_ms": max(durations) * 1000
                }
        return report
