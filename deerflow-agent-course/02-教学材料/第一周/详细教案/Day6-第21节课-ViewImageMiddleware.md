# 🎓 详细教案 - ViewImageMiddleware（图片查看中间件）

## 📋 课程基本信息
- **课程名称**: ViewImageMiddleware（图片查看中间件）
- **授课日期**: 第6天 - 第1节课
- **上课时间**: 09:00-09:45（45分钟）
- **授课教师**: 张老师（高级架构师讲师）
- **学生背景**: Python基础一般，已学完前5天课程，掌握中间件基础概念
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解现代AI Agent系统中图片处理的核心需求和挑战
2. 掌握Base64编码/解码原理及其在图片传输中的应用
3. 理解ViewImageMiddleware的设计思想和工作原理
4. 了解视觉模型在图片描述生成中的作用和实现方式

### 技能目标（学生将能够）
1. 实现图片的Base64编码解码功能
2. 编写简单的图片验证逻辑（大小、格式验证）
3. 实现基本的ViewImageMiddleware原型
4. 集成视觉模型生成图片描述

### 情感/态度目标
1. 培养对多模态AI Agent的兴趣和探索精神
2. 建立安全处理用户上传图片的责任意识
3. 激发对计算机视觉与自然语言处理交叉领域的创新思维

## 📚 教学重点与难点
- **教学重点**: 
  1. Base64编码解码原理与实践
  2. ViewImageMiddleware的架构设计和实现
  3. 图片验证和安全处理机制
- **教学难点**: 
  1. Base64编码大小计算和优化
  2. 视觉模型集成与异步调用
  3. 图片内容替换策略设计
- **突破方法**: 
  1. 通过实际代码演示讲解Base64原理
  2. 分步骤实现中间件核心功能
  3. 提供完整的代码模板和调试技巧

# 课堂练习：实现图片验证函数

## 任务描述
在提供的ImageProcessor类基础上，完善validate_image函数，实现以下功能：
1. 验证Base64字符串格式正确性
2. 计算图片解码后的大小（MB）
3. 检查是否超过最大限制（默认10MB）
4. 返回验证结果布尔值

## 要求
- [ ] 正确处理带data URL前缀的Base64字符串
- [ ] 准确计算解码后图片大小（注意Base64编码规则）
- [ ] 实现可配置的最大大小限制
- [ ] 添加适当的错误处理和日志记录

## 步骤指导
1. 分析Base64字符串结构，提取纯编码部分
2. 计算编码数据长度，估算解码后大小（公式：size_bytes = len(data) * 3 / 4）
3. 将字节大小转换为MB（除以1024两次）
4. 比较计算大小和限制大小，返回布尔值
5. 添加try-except处理格式错误的Base64数据

## 提示与技巧
- Base64编码规则：每3字节原始数据编码为4字符
- data URL格式：`data:image/jpeg;base64,<actual_base64_data>`
- 可以使用`base64.b64decode`尝试解码验证格式
- 注意内存使用，不要实际解码大图片

## 检查点
- [ ] 测试1：验证正常图片（5MB）返回True
- [ ] 测试2：验证超大图片（15MB）返回False  
- [ ] 测试3：验证格式错误Base64返回False
- [ ] 测试4：验证带data URL前缀的Base64正确处理

## 扩展挑战（可选）
- 添加图片格式验证（通过文件头判断）
- 实现图片尺寸验证（宽高限制）
- 添加图片内容安全检查（NSFW检测）
