# 🎓 详细教案 - TodoMiddleware（任务管理中间件）

## 📋 课程基本信息
- **课程名称**: TodoMiddleware（任务管理中间件）
- **授课日期**: 第6天 - 第3节课
- **上课时间**: 11:00-11:45（45分钟）
- **授课教师**: 张老师（高级架构师讲师）
- **学生背景**: 已学习ViewImageMiddleware和SubagentLimitMiddleware，了解中间件基础
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解复杂任务管理在AI Agent系统中的重要性和挑战
2. 掌握任务分解的四种核心需求：分解、跟踪、持久化、优先级
3. 理解TodoItem数据结构和依赖关系管理机制
4. 了解任务进度计算和状态同步原理

### 技能目标（学生将能够）
1. 设计合理的TodoItem数据结构（dataclass）
2. 实现任务依赖检查和阻塞状态判断
3. 编写TodoMiddleware的before/after方法
4. 计算和生成任务进度报告

### 情感/态度目标
1. 培养系统化任务管理和项目规划能力
2. 建立复杂问题分解和逐步解决的思维模式
3. 激发对工作流自动化和智能任务管理的创新兴趣

## 📚 教学重点与难点
- **教学重点**: 
  1. TodoItem数据结构的完整设计
  2. 任务依赖关系管理和阻塞检查
  3. TodoMiddleware的双向执行流程（加载/保存）
- **教学难点**: 
  1. 任务依赖图的构建和遍历算法
  2. 进度百分比计算和状态同步
  3. 存储抽象层（TodoStorage）的设计
- **突破方法**: 
  1. 通过示例展示依赖关系图
  2. 使用简化版进度计算公式
  3. 提供存储接口的默认实现

```markdown
# 课堂练习：实现任务依赖检查方法

## 任务描述
在提供的TodoItem类基础上，完善is_blocked方法，实现以下功能：
1. 检查当前任务的所有依赖任务
2. 判断依赖任务是否已完成
3. 如果任何依赖任务未完成，则当前任务被阻塞
4. 返回阻塞状态布尔值

## 要求
- [ ] 正确处理空依赖列表（无依赖则不被阻塞）
- [ ] 处理无效依赖ID（不存在于todos字典中）
- [ ] 递归检查依赖的依赖（间接依赖）
- [ ] 避免无限循环（处理循环依赖）

## 步骤指导
1. 遍历self.dependencies列表中的每个依赖ID
2. 在todos字典中查找对应的TodoItem对象
3. 如果依赖不存在，可以忽略或记录警告
4. 如果依赖存在且状态不是"completed"，则返回True（被阻塞）
5. 如果所有依赖都已完成，返回False（未被阻塞）
6. 考虑添加visited集合防止无限递归

## 提示与技巧
- 使用字典查找：dep = todos.get(dep_id)
- 状态检查：dep.status != "completed"
- 递归实现：可以调用dep.is_blocked(todos)检查间接依赖
- 循环依赖检测：传递visited集合记录已检查的任务

## 检查点
- [ ] 测试1：无依赖任务返回False
- [ ] 测试2：依赖已完成的任务返回False  
- [ ] 测试3：依赖未完成的任务返回True
- [ ] 测试4：间接依赖（依赖的依赖）正确检查
- [ ] 测试5：循环依赖检测避免无限递归

## 扩展挑战（可选）
- 添加依赖类型支持（强依赖/弱依赖）
- 实现依赖图可视化输出
- 添加依赖冲突检测和解决建议
```
