# 🎓 详细教案 - Day7 第28节课：实战：创建自定义工具

## 📋 课程基本信息
- **课程名称**: Day7-第28节课：实战：创建自定义工具
- **授课日期**: 第7天（第二周星期一）
- **上课时间**: 16:15-17:00（第4节课）
- **授课教师**: DeerFlow认证架构师讲师
- **学生背景**: Python基础一般，已完成工具系统理论学习，了解工具发现、沙箱工具集和内置工具使用
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 掌握自定义工具开发的完整流程：需求分析→接口设计→安全设计→实现逻辑→测试验证→文档编写
2. 理解自定义工具的安全设计原则和性能优化策略
3. 掌握工具注册表的使用方法和工具集成的最佳实践

### 技能目标（学生将能够）
1. 独立设计和实现一个完整的自定义工具（以天气查询工具为例）
2. 编写全面的单元测试和集成测试，确保工具质量
3. 使用ToolRegistry注册和管理自定义工具，集成到DeerFlow系统中

### 情感/态度目标
1. 培养学生对工具开发质量的责任感和工匠精神
2. 增强学生在面对复杂实现时的耐心和系统性思维
3. 激发学生创建实用工具解决实际问题的成就感

## 📚 教学重点与难点
- **教学重点**: 
  1. 自定义工具开发的完整流程和关键环节
  2. 天气查询工具的实现细节和代码结构
  3. 工具测试的方法和最佳实践
- **教学难点**: 
  1. 异步编程在工具开发中的应用（async/await）
  2. API调用错误处理和缓存机制的实现
  3. Mock测试的编写和测试覆盖率
- **突破方法**: 
  1. 通过分步骤代码演示，逐步构建完整工具
  2. 使用可视化流程图展示工具调用过程
  3. 提供详细的代码注释和常见错误示例

## 🛠️ 教学资源准备
- **硬件**: 演示用电脑（16GB+ RAM，支持AVX指令集）
- **软件**: Python 3.12.0、VS Code、Git、Postman（API测试）
- **账户**: WeatherAPI账户（或使用Mock API）、GitHub账户
- **代码**: DeerFlow 2.0代码库（提前克隆到本地）、课堂演示代码
- **演示材料**: PPT幻灯片（自定义工具开发流程）、架构图、代码示例
- **学生材料**: 练习手册、代码模板、测试用例模板、评估表

2. **引导提问**: "如果你要设计一个天气查询工具，会考虑哪些安全性问题？"（引导思考）

## 🔧 差异化教学

### 针对基础薄弱学生
1. **简化任务**: 提供完整的汇率查询工具代码框架，只需填写关键部分
2. **额外支持**: 一对一辅导，重点讲解异步编程基础
3. **资源推荐**: 提供异步编程速成教程和API调用示例
4. **成功体验**: 设计可达成的子目标：先实现同步版本，再改为异步

### 针对进阶学生
1. **扩展挑战**: 实现带缓存、重试、熔断机制的高级工具
2. **创新空间**: 鼓励探索不同的API设计模式和错误处理策略
3. **领导机会**: 担任小组长，帮助其他同学解决技术问题
4. **项目实战**: 参与真实项目中的工具开发任务

### 针对中等水平学生
1. **渐进提升**: 从简单实现开始，逐步添加高级功能
2. **榜样学习**: 学习优秀同学的工具设计和代码组织
3. **目标引导**: 设定明确的代码质量和测试覆盖率目标
4. **反馈激励**: 及时肯定进步，鼓励持续改进

## 📊 评估方式

### 形成性评估（课堂内）
1. **观察评估**: 观察学生参与讨论、提问和练习的积极程度
2. **提问评估**: 通过提问检验对工具开发流程的理解
3. **练习评估**: 检查汇率查询工具的完成情况和代码质量
4. **自评互评**: 学生自我评估学习效果，互相评估代码实现

### 总结性评估（课堂后）
1. **作业评估**: 批改课后作业，评分反馈工具实现质量
2. **测验评估**: 单元测验，检验工具开发知识的掌握程度
3. **项目评估**: 项目中的工具开发任务完成情况和质量
4. **综合评估**: 结合课堂表现、作业质量和项目贡献综合评价

### 评估标准
- **优秀（90-100分）**: 独立完成高质量工具实现，代码规范、测试全面、文档完整
- **良好（80-89分）**: 基本完成工具实现，代码可运行但有待优化
- **合格（60-79分）**: 理解核心概念，在指导下完成工具实现
- **需改进（<60分）**: 需要重新学习异步编程和工具开发基础

```markdown
# 课堂练习：汇率查询工具开发

## 任务描述
实现一个汇率查询工具，能够查询指定货币对之间的实时汇率。工具需要支持缓存机制和错误处理。

## 要求
- [ ] 继承BaseTool类，实现完整的工具接口
- [ ] 支持查询任意两种货币之间的汇率
- [ ] 实现30分钟TTL缓存，减少API调用
- [ ] 完善的错误处理（网络错误、API错误、数据解析错误）
- [ ] 清晰的输出格式，包含汇率数值和更新时间

## 步骤指导
1. 定义工具参数：from_currency, to_currency, amount(可选)
2. 选择汇率API：推荐使用exchangerate-api.com（免费版）
3. 实现异步API调用，使用aiohttp库
4. 添加缓存机制，使用cachetools.TTLCache
5. 实现错误处理，返回用户友好的错误信息
6. 格式化输出，包含汇率信息和缓存状态

## 提示与技巧
- 使用环境变量存储API密钥，不要硬编码
- 异步函数中注意异常捕获和资源释放
- 缓存键设计：f"{from_currency}:{to_currency}"
- 测试时使用Mock API避免产生实际费用

## 检查点
- [ ] 工具类正确定义，包含name、description、args_schema
- [ ] _run方法正确实现异步API调用
- [ ] 缓存机制正常工作，相同查询返回缓存结果
- [ ] 错误处理覆盖网络错误和API错误
- [ ] 输出格式清晰，包含所有必要信息

## 扩展挑战（可选）
- 支持批量查询多个货币对
- 实现历史汇率查询功能
- 添加汇率趋势分析和预测
- 集成到DeerFlow Agent中进行自动化汇率换算
```
