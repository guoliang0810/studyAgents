## 🧠 第一部分：概念理解与选择 - 答案与解析

### 1.1 多项选择题

**1. 内存系统三层架构中，哪一层负责存储当前会话的对话历史？**
**答案**: C) 短期记忆  
**解析**: 短期记忆专门存储当前会话的对话历史，通常有容量和时间限制。工作记忆存储当前推理的临时信息，长期记忆存储跨会话的重要信息，永久记忆和缓存记忆不是标准的三层架构组成部分。

**2. 上下文注入状态机中，哪个状态负责根据优先级对上下文项进行排序？**
**答案**: D) PRIORITIZING  
**解析**: PRIORITIZING状态负责根据重要性、相关性、时间等因素对上下文项进行优先级排序。INITIAL是初始状态，FORMATTING格式化对话历史，FILTERING过滤不相关内容，TRIMMING修剪超限内容。

**3. 记忆检索策略中，哪种策略优先返回最近的记忆项？**
**答案**: B) 时间检索  
**解析**: 时间检索策略优先返回最近的记忆项，基于时间衰减因子给近期记忆更高权重。关键词检索基于关键词匹配，相关性检索基于语义相似度，混合检索组合多种策略，随机检索没有优先级。

**4. 动态上下文窗口管理的核心挑战是什么？**
**答案**: C) token限制  
**解析**: 动态上下文窗口管理的核心挑战是如何在有限的token预算内选择最重要的上下文信息进行注入。其他选项（美观性、安全性、多语言支持、颜色搭配）虽然可能相关，但不是核心挑战。

**5. 在记忆系统中，重要性评分（importance score）的主要作用是什么？**
**答案**: B) 控制记忆的存储优先级和检索权重  
**解析**: 重要性评分决定记忆在长期存储中的保留优先级和在检索中的权重，是记忆管理的核心机制。它不直接影响颜色显示、存储空间计算、创建时间或加密状态。

### 1.2 判断题

**1. "短期记忆应该无限存储所有对话历史，以确保不会丢失任何信息。"**
**答案**: 错误  
**解析**: 短期记忆应该有容量限制（如token数或项数），因为无限存储会导致内存膨胀、性能下降，且大部分历史信息随着时间推移相关性降低。合理的设计是LRU（最近最少使用）淘汰策略。

**2. "上下文注入状态机必须严格按照状态转换表的顺序执行，不能有任何跳跃。"**
**答案**: 错误  
**解析**: 状态机可以根据实际情况灵活跳转。例如，如果token未超限，可以跳过TRIMMING状态；如果所有上下文项都符合要求，可以简化流程。状态转换表提供默认顺序，但允许优化跳转。

**3. "混合检索策略总是比单一检索策略效果更好，应该在所有场景中使用。"**
**答案**: 错误  
**解析**: 混合检索策略通常效果更好，但并非总是最优。在某些特定场景下，单一策略可能更合适：简单查询适合关键词检索，时间敏感查询适合时间检索，计算资源有限时单一策略更高效。应基于实际需求选择。

**4. "token计算只需要考虑字符数量，不需要考虑语言差异（中文/英文）。"**
**答案**: 错误  
**解析**: token计算必须考虑语言差异。中文和英文的tokenization方式不同：英文单词通常被分割为子词（subwords），中文字符可能单独或组合成token。简化估算时，中文约2字符1token，英文约4字符1token。

**5. "长期记忆应该存储所有用户输入，无论重要性如何。"**
**答案**: 错误  
**解析**: 长期记忆应只存储重要性高的信息，避免存储冗余和不重要内容。存储所有输入会导致数据膨胀、检索效率降低、隐私风险增加。通常设置重要性阈值（如0.7），只存储超过阈值的信息。

### 1.3 填空题

**1. 内存系统三层架构包括: ______、______、______。**
**答案**: 短期记忆、长期记忆、工作记忆  
**解析**: 这是标准的三层内存架构。短期记忆存储对话历史，长期记忆存储重要信息，工作记忆存储当前推理的临时信息。

**2. 上下文注入状态机的七个核心状态是: ______ → ______ → ______ → ______ → ______ → ______ → ______。**
**答案**: INITIAL → FORMATTING → FILTERING → PRIORITIZING → TOKEN_COUNTING → TRIMMING → INJECTING  
**解析**: 这是完整的上下文注入流程：初始化→格式化→过滤→排序→token计数→修剪→注入。最后可能还有COMPLETE完成状态。

**3. 四种记忆检索策略是: ______、______、______、______。**
**答案**: 关键词检索、时间检索、相关性检索、混合检索  
**解析**: 关键词检索基于关键词匹配，时间检索基于时间衰减，相关性检索基于语义相似度，混合检索组合多种策略。

**4. 动态上下文窗口管理的三个关键步骤是: ______、______、______。**
**答案**: token计算、重要性评估、智能修剪  
**解析**: 首先计算各上下文项的token数，然后评估它们的重要性/相关性，最后根据token限制智能修剪次要内容。

**5. 记忆项(MemoryItem)的五个核心属性是: ______、______、______、______、______。**
**答案**: 内容(content)、内存类型(memory_type)、时间戳(timestamp)、重要性(importance)、标签(tags)  
**解析**: 这些是MemoryItem的基本属性。内容存储信息本身，内存类型标识所属层，时间戳记录创建时间，重要性影响存储和检索优先级，标签用于分类和搜索。

### 2.1 实现三层内存系统

**完整实现**:

```python
from typing import List, Dict, Any, Optional
from enum import Enum
import time
import re

class MemoryType(Enum):
    """内存类型枚举"""
    SHORT_TERM = "short_term"
    LONG_TERM = "long_term"
    WORKING = "working"

class MemoryItem:
    """记忆项"""
    def __init__(self, content: str, memory_type: MemoryType, 
                 importance: float = 0.5, tags: List[str] = None,
                 metadata: Dict[str, Any] = None):
        self.content = content
        self.memory_type = memory_type
        self.importance = max(0.0, min(1.0, importance))  # 限制在0-1之间
        self.tags = tags or []
        self.metadata = metadata or {}
        self.timestamp = time.time()
        self.token_count = self.calculate_tokens()
    
    def calculate_tokens(self) -> int:
        """计算token数（简化实现）"""
        # 中文约2字符1个token，英文约4字符1个token
        chinese_chars = len(re.findall(r'[\u4e00-\u9fff]', self.content))
        other_chars = len(self.content) - chinese_chars
        return (chinese_chars // 2) + (other_chars // 4) + 1  # +1确保非空内容至少1个token
    
    def to_dict(self) -> Dict[str, Any]:
        """转换为字典"""
        return {
            "content": self.content,
            "memory_type": self.memory_type.value,
            "importance": self.importance,
            "tags": self.tags,
            "token_count": self.token_count,
            "timestamp": self.timestamp,
            "metadata": self.metadata
        }
    
    def __repr__(self):
        return f"MemoryItem(content='{self.content[:30]}...', type={self.memory_type.value}, importance={self.importance})"

class ShortTermMemory:
    """短期记忆"""
    def __init__(self, max_items: int = 20, max_tokens: int = 4000):
        self.max_items = max_items
        self.max_tokens = max_tokens
        self.items = []  # 列表实现，新项添加到末尾
        self.current_tokens = 0
    
    def add(self, item: MemoryItem):
        """添加记忆项"""
        # 检查是否超限
        while (self.current_tokens + item.token_count > self.max_tokens or 
               len(self.items) >= self.max_items):
            if self.items:
                self._evict_oldest()
            else:
                # 没有可淘汰的项，无法添加
                print(f"⚠️ 短期记忆已满，无法添加: {item.content[:50]}...")
                return
        
        self.items.append(item)
        self.current_tokens += item.token_count
    
    def _evict_oldest(self):
        """淘汰最旧的记忆项"""
        if self.items:
            removed = self.items.pop(0)  # 移除最旧的（列表开头）
            self.current_tokens -= removed.token_count
    
    def get_recent(self, count: int = 10) -> List[MemoryItem]:
        """获取最近的记忆项"""
        return self.items[-count:] if self.items else []
    
    def stats(self) -> Dict[str, Any]:
        """统计信息"""
        return {
            "item_count": len(self.items),
            "token_count": self.current_tokens,
            "max_items": self.max_items,
            "max_tokens": self.max_tokens,
            "avg_importance": sum(item.importance for item in self.items) / len(self.items) if self.items else 0.0
        }
    
    def clear(self):
        """清空短期记忆"""
        self.items.clear()
        self.current_tokens = 0

class LongTermMemory:
    """长期记忆"""
    def __init__(self, min_importance: float = 0.7):
        self.min_importance = min_importance
        self.items = []
    
    def add(self, item: MemoryItem):
        """添加记忆项（只存储重要性高的）"""
        if item.importance >= self.min_importance:
            self.items.append(item)
            # 按重要性排序，方便检索
            self.items.sort(key=lambda x: x.importance, reverse=True)
    
    def search_by_tags(self, tags: List[str]) -> List[MemoryItem]:
        """按标签搜索"""
        results = []
        for item in self.items:
            if any(tag in item.tags for tag in tags):
                results.append(item)
        return results
    
    def search_by_keywords(self, keywords: List[str]) -> List[MemoryItem]:
        """按关键词搜索"""
        results = []
        for item in self.items:
            content_lower = item.content.lower()
            # 检查是否包含任何关键词
            if any(keyword.lower() in content_lower for keyword in keywords):
                results.append(item)
        return results
    
    def get_important(self, min_importance: float = 0.8) -> List[MemoryItem]:
        """获取重要性高的记忆项"""
        return [item for item in self.items if item.importance >= min_importance]

class WorkingMemory:
    """工作记忆"""
    def __init__(self, max_tokens: int = 2000):
        self.max_tokens = max_tokens
        self.items = []
        self.current_tokens = 0
    
    def add(self, item: MemoryItem):
        """添加工作记忆项"""
        if self.current_tokens + item.token_count <= self.max_tokens:
            self.items.append(item)
            self.current_tokens += item.token_count
        else:
            # 尝试清理空间
            self._compact()
            if self.current_tokens + item.token_count <= self.max_tokens:
                self.items.append(item)
                self.current_tokens += item.token_count
            else:
                print(f"⚠️ 工作记忆已满，无法添加: {item.content[:50]}...")
    
    def _compact(self):
        """压缩工作记忆（移除低重要性项）"""
        if self.items:
            # 按重要性排序，保留高重要性项
            self.items.sort(key=lambda x: x.importance, reverse=True)
            # 重新计算token
            compacted_items = []
            current_tokens = 0
            for item in self.items:
                if current_tokens + item.token_count <= self.max_tokens:
                    compacted_items.append(item)
                    current_tokens += item.token_count
                else:
                    break
            self.items = compacted_items
            self.current_tokens = current_tokens
    
    def clear(self):
        """清空工作记忆"""
        self.items.clear()
        self.current_tokens = 0
    
    def get_context(self) -> str:
        """获取上下文（所有工作记忆内容）"""
        return "\n".join([item.content for item in self.items])

class ThreeLayerMemorySystem:
    """三层内存系统"""
    def __init__(self):
        self.short_term = ShortTermMemory(max_items=20, max_tokens=4000)
        self.long_term = LongTermMemory(min_importance=0.7)
        self.working = WorkingMemory(max_tokens=2000)
        
        # 统计信息
        self.stats = {
            "short_term_adds": 0,
            "long_term_adds": 0,
            "working_adds": 0,
            "searches": 0
        }
    
    def add_memory(self, content: str, memory_type: MemoryType, 
                   importance: float = 0.5, tags: List[str] = None) -> MemoryItem:
        """添加记忆"""
        item = MemoryItem(content, memory_type, importance, tags)
        
        if memory_type == MemoryType.SHORT_TERM:
            self.short_term.add(item)
            self.stats["short_term_adds"] += 1
        elif memory_type == MemoryType.LONG_TERM:
            self.long_term.add(item)
            self.stats["long_term_adds"] += 1
        elif memory_type == MemoryType.WORKING:
            self.working.add(item)
            self.stats["working_adds"] += 1
        
        return item
    
    def search_memories(self, query: str, 
                       memory_types: List[MemoryType] = None) -> List[MemoryItem]:
        """搜索记忆"""
        self.stats["searches"] += 1
        
        if memory_types is None:
            memory_types = [MemoryType.SHORT_TERM, MemoryType.LONG_TERM]
        
        all_results = []
        
        # 从长期记忆搜索
        if MemoryType.LONG_TERM in memory_types:
            keywords = query.split()
            long_term_results = self.long_term.search_by_keywords(keywords)
            all_results.extend(long_term_results)
        
        # 从短期记忆搜索（简单关键词匹配）
        if MemoryType.SHORT_TERM in memory_types:
            short_term_items = self.short_term.get_recent(10)
            query_lower = query.lower()
            for item in short_term_items:
                if query_lower in item.content.lower():
                    all_results.append(item)
        
        # 从工作记忆搜索
        if MemoryType.WORKING in memory_types:
            for item in self.working.items:
                if query.lower() in item.content.lower():
                    all_results.append(item)
        
        # 去重并按相关性排序（简化：按时间倒序）
        unique_results = []
        seen_contents = set()
        for item in all_results:
            if item.content not in seen_contents:
                unique_results.append(item)
                seen_contents.add(item.content)
        
        unique_results.sort(key=lambda x: x.timestamp, reverse=True)
        return unique_results
    
    def get_context_for_injection(self, max_tokens: int = 3000) -> str:
        """获取用于注入的上下文"""
        # 收集所有可用上下文
        contexts = []
        
        # 1. 工作记忆上下文（最高优先级）
        working_context = self.working.get_context()
        if working_context:
            contexts.append(("工作记忆", working_context, 0.9))
        
        # 2. 短期记忆上下文（最近对话）
        short_term_items = self.short_term.get_recent(10)
        if short_term_items:
            short_term_content = "\n".join([f"[对话{i+1}] {item.content}" 
                                          for i, item in enumerate(short_term_items)])
            contexts.append(("近期对话", short_term_content, 0.7))
        
        # 3. 长期记忆上下文（相关记忆）
        # 使用工作记忆或查询作为搜索词
        search_query = working_context if working_context else "AI Agent"
        keywords = search_query.split()[:5]
        long_term_items = self.long_term.search_by_keywords(keywords)
        if long_term_items:
            long_term_content = "\n".join([f"[知识{i+1}] {item.content}" 
                                         for i, item in enumerate(long_term_items[:3])])
            contexts.append(("相关知识", long_term_content, 0.8))
        
        # 按优先级排序
        contexts.sort(key=lambda x: x[2], reverse=True)
        
        # 构建完整上下文
        full_context = ""
        current_tokens = 0
        
        for source, content, priority in contexts:
            content_tokens = len(content) // 4  # 简化token计算
            if current_tokens + content_tokens <= max_tokens:
                full_context += f"【{source}】\n{content}\n\n"
                current_tokens += content_tokens
            else:
                # 尝试部分添加
                if current_tokens < max_tokens * 0.8:  # 还有足够空间
                    # 修剪内容以适应剩余空间
                    remaining_tokens = max_tokens - current_tokens
                    trimmed_content = self._trim_content(content, remaining_tokens)
                    if trimmed_content:
                        full_context += f"【{source}】\n{trimmed_content}\n\n"
                        current_tokens += len(trimmed_content) // 4
                break
        
        return full_context.strip()
    
    def _trim_content(self, content: str, max_tokens: int) -> str:
        """修剪内容以适应token限制"""
        # 按段落修剪
        paragraphs = content.split('\n\n')
        trimmed_paragraphs = []
        current_tokens = 0
        
        for para in paragraphs:
            para_tokens = len(para) // 4
            if current_tokens + para_tokens <= max_tokens:
                trimmed_paragraphs.append(para)
                current_tokens += para_tokens
            else:
                # 尝试修剪段落内部
                lines = para.split('\n')
                trimmed_lines = []
                for line in lines:
                    line_tokens = len(line) // 4
                    if current_tokens + line_tokens <= max_tokens:
                        trimmed_lines.append(line)
                        current_tokens += line_tokens
                    else:
                        break
                if trimmed_lines:
                    trimmed_paragraphs.append('\n'.join(trimmed_lines))
                break
        
        return '\n\n'.join(trimmed_paragraphs)
    
    def print_stats(self):
        """打印统计信息"""
        print("📊 内存系统统计:")
        print(f"  短期记忆: {self.short_term.stats()}")
        print(f"  长期记忆项数: {len(self.long_term.items)}")
        print(f"  工作记忆项数: {len(self.working.items)}")
        print(f"  操作统计: {self.stats}")
```

**代码解析**:
1. **MemoryItem类**: 完整实现记忆项的数据结构和token计算，考虑中英文差异。
2. **三层内存类**: 每层都有合适的容量限制和淘汰策略：短期记忆LRU淘汰，长期记忆重要性过滤，工作记忆动态压缩。
3. **内存系统整合**: ThreeLayerMemorySystem协调三层内存，提供统一的添加、搜索、上下文获取接口。
4. **智能上下文修剪**: `_trim_content`方法按段落和行进行智能修剪，优先保留完整语义单元。
5. **统计和监控**: 跟踪各种操作计数，便于性能分析和优化。

```python
from enum import Enum
from typing import List, Dict, Any
import time

class InjectionState(Enum):
    """上下文注入状态枚举"""
    INITIAL = "initial"           # 初始状态
    FORMATTING = "formatting"     # 格式化对话历史
    FILTERING = "filtering"       # 过滤不相关内容
    PRIORITIZING = "prioritizing" # 优先级排序
    TOKEN_COUNTING = "token_counting"  # token计数
    TRIMMING = "trimming"         # 修剪超限内容
    INJECTING = "injecting"       # 注入到提示
    COMPLETE = "complete"         # 完成
    ERROR = "error"               # 错误

class ContextItem:
    """上下文项"""
    def __init__(self, content: str, source: str, priority: float = 0.5):
        self.content = content
        self.source = source  # 来源: working, short_term, long_term
        self.priority = max(0.0, min(1.0, priority))  # 限制在0-1之间
        self.token_count = 0
        self.timestamp = time.time()
        self.metadata = {}
    
    def calculate_tokens(self) -> int:
        """计算token数"""
        # 简化计算
        self.token_count = len(self.content) // 4
        return self.token_count
    
    def __repr__(self):
        return f"ContextItem(source={self.source}, priority={self.priority:.2f}, tokens={self.token_count}, content='{self.content[:30]}...')"

class ContextInjectionStateMachine:
    """上下文注入状态机"""
    def __init__(self, memory_system):
        self.memory_system = memory_system
        self.current_state = InjectionState.INITIAL
        self.context_items = []  # 待注入的上下文项
        self.injected_items = []  # 已注入的上下文项
        self.current_tokens = 0
        self.max_tokens = 3000
        
        # 状态转换表
        self.transitions = {
            InjectionState.INITIAL: InjectionState.FORMATTING,
            InjectionState.FORMATTING: InjectionState.FILTERING,
            InjectionState.FILTERING: InjectionState.PRIORITIZING,
            InjectionState.PRIORITIZING: InjectionState.TOKEN_COUNTING,
            InjectionState.TOKEN_COUNTING: InjectionState.TRIMMING,
            InjectionState.TRIMMING: InjectionState.INJECTING,
            InjectionState.INJECTING: InjectionState.COMPLETE,
        }
        
        # 错误处理
        self.errors = []
        self.warnings = []
    
    def run(self, max_tokens: int = 3000) -> str:
        """运行状态机，返回注入后的提示"""
        print(f"🚀 启动上下文注入状态机 (max_tokens={max_tokens})")
        self.max_tokens = max_tokens
        self.current_state = InjectionState.INITIAL
        self.context_items = []
        self.injected_items = []
        self.current_tokens = 0
        
        try:
            while self.current_state != InjectionState.COMPLETE:
                self._process_current_state()
                
                # 状态转换
                if self.current_state in self.transitions:
                    next_state = self.transitions[self.current_state]
                    print(f"  ↪️  状态转换: {self.current_state.value} → {next_state.value}")
                    self.current_state = next_state
                else:
                    # 到达终态或错误状态
                    if self.current_state == InjectionState.COMPLETE:
                        break
                    elif self.current_state == InjectionState.ERROR:
                        raise RuntimeError(f"状态机进入错误状态: {self.errors}")
                    else:
                        print(f"  ⚠️  未知状态: {self.current_state}")
                        break
        except Exception as e:
            self.current_state = InjectionState.ERROR
            self.errors.append(str(e))
            print(f"❌ 状态机错误: {e}")
        
        # 生成最终提示
        return self._generate_final_prompt()
    
    def _process_current_state(self):
        """处理当前状态"""
        state_handlers = {
            InjectionState.INITIAL: self._handle_initial,
            InjectionState.FORMATTING: self._handle_formatting,
            InjectionState.FILTERING: self._handle_filtering,
            InjectionState.PRIORITIZING: self._handle_prioritizing,
            InjectionState.TOKEN_COUNTING: self._handle_token_counting,
            InjectionState.TRIMMING: self._handle_trimming,
            InjectionState.INJECTING: self._handle_injecting,
        }
        
        handler = state_handlers.get(self.current_state)
        if handler:
            print(f"  📍 处理状态: {self.current_state.value}")
            handler()
    
    def _handle_initial(self):
        """初始状态处理"""
        print("  📋 收集内存系统统计...")
        self.memory_system.print_stats()
    
    def _handle_formatting(self):
        """格式化对话历史"""
        print("  📝 格式化对话历史...")
        
        # 1. 工作记忆格式化
        working_context = self.memory_system.working.get_context()
        if working_context:
            self.context_items.append(
                ContextItem(working_context, "working", priority=0.9)
            )
            print(f"    添加工作记忆: {len(working_context)} 字符")
        
        # 2. 短期记忆格式化
        short_term_items = self.memory_system.short_term.get_recent(10)
        for i, item in enumerate(short_term_items):
            formatted = f"[对话{i+1}] {item.content}"
            self.context_items.append(
                ContextItem(formatted, "short_term", priority=0.6 + item.importance * 0.3)
            )
        print(f"    添加短期记忆: {len(short_term_items)} 项")
        
        # 3. 长期记忆格式化
        # 使用工作记忆作为查询词
        if working_context:
            keywords = working_context.split()[:5]
            long_term_items = self.memory_system.long_term.search_by_keywords(keywords)
            for i, item in enumerate(long_term_items[:3]):
                formatted = f"[知识{i+1}] {item.content}"
                self.context_items.append(
                    ContextItem(formatted, "long_term", priority=0.7 + item.importance * 0.2)
                )
            print(f"    添加长期记忆: {len(long_term_items[:3])} 项")
        
        print(f"  ✅ 格式化完成: {len(self.context_items)} 个上下文项")
    
    def _handle_filtering(self):
        """过滤不相关内容"""
        print(f"  🧹 过滤前: {len(self.context_items)} 个上下文项")
        
        filtered_items = []
        for item in self.context_items:
            # 过滤空内容
            if not item.content or item.content.strip() == "":
                continue
            
            # 过滤过短内容（可能不完整）
            if len(item.content.strip()) < 10:
                self.warnings.append(f"过滤过短内容: {item.content[:30]}...")
                continue
            
            # 过滤重复内容（简单去重）
            content_simple = item.content.strip().lower()
            if any(content_simple == ci.content.strip().lower() 
                   for ci in filtered_items):
                continue
            
            filtered_items.append(item)
        
        self.context_items = filtered_items
        print(f"  ✅ 过滤后: {len(self.context_items)} 个上下文项")
    
    def _handle_prioritizing(self):
        """优先级排序"""
        print(f"  📊 对 {len(self.context_items)} 个上下文项进行优先级排序...")
        
        # 根据来源、内容长度、时间等因素调整优先级
        for item in self.context_items:
            base_priority = item.priority
            
            # 来源权重：工作记忆 > 长期记忆 > 短期记忆
            source_weights = {
                "working": 1.2,
                "long_term": 1.1,
                "short_term": 1.0,
            }
            item.priority *= source_weights.get(item.source, 1.0)
            
            # 长度权重：适中长度最佳（100-500字符）
            content_len = len(item.content)
            if 100 <= content_len <= 500:
                item.priority *= 1.05  # 适中长度有优势
            elif content_len > 1000:
                item.priority *= 0.9   # 过长内容降低优先级
            elif content_len < 50:
                item.priority *= 0.95  # 过短内容稍降优先级
        
        # 按优先级排序（降序）
        self.context_items.sort(key=lambda x: x.priority, reverse=True)
        
        # 显示前5项
        print("  📈 优先级最高的5个上下文项:")
        for i, item in enumerate(self.context_items[:5], 1):
            print(f"    {i}. {item.content[:50]}... (优先级: {item.priority:.2f}, 来源: {item.source})")
    
    def _handle_token_counting(self):
        """token计数"""
        print("  🧮 计算token数...")
        
        self.current_tokens = 0
        for item in self.context_items:
            item.calculate_tokens()
            self.current_tokens += item.token_count
        
        print(f"  📊 总token数: {self.current_tokens} (限制: {self.max_tokens})")
        
        # 检查是否超限
        if self.current_tokens > self.max_tokens:
            print(f"  ⚠️  token超限: {self.current_tokens} > {self.max_tokens}")
            self.warnings.append(f"token超限: {self.current_tokens} > {self.max_tokens}")
        else:
            print(f"  ✅ token在限制内")
    
    def _handle_trimming(self):
        """修剪超限内容"""
        if self.current_tokens <= self.max_tokens:
            print("  ✅ token未超限，无需修剪")
            return
        
        print(f"  ✂️  开始修剪 (当前: {self.current_tokens}, 限制: {self.max_tokens})")
        
        # 按优先级排序（确保高优先级在前）
        self.context_items.sort(key=lambda x: x.priority, reverse=True)
        
        # 计算需要修剪的token数
        excess_tokens = self.current_tokens - self.max_tokens
        print(f"  🔢 需要修剪 {excess_tokens} 个token")
        
        # 从低优先级开始修剪
        trimmed_items = []
        remaining_tokens = 0
        
        for item in self.context_items:
            if remaining_tokens + item.token_count <= self.max_tokens:
                trimmed_items.append(item)
                remaining_tokens += item.token_count
            else:
                # 尝试部分修剪该项
                if item.token_count > 50:  # 只修剪较长的项
                    # 计算需要减少的token数
                    needed_reduction = (remaining_tokens + item.token_count) - self.max_tokens
                    trimmed_content = self._trim_item_content(item.content, needed_reduction)
                    if trimmed_content and len(trimmed_content) > 20:  # 保留有意义的内容
                        trimmed_item = ContextItem(trimmed_content, item.source, item.priority)
                        trimmed_item.token_count = trimmed_item.calculate_tokens()
                        trimmed_items.append(trimmed_item)
                        remaining_tokens += trimmed_item.token_count
                        excess_tokens -= (item.token_count - trimmed_item.token_count)
                        print(f"    部分修剪: {item.token_count} → {trimmed_item.token_count} tokens")
                # 否则完全丢弃该项
                else:
                    print(f"    完全丢弃: {item.content[:30]}... ({item.token_count} tokens)")
        
        self.context_items = trimmed_items
        self.current_tokens = remaining_tokens
        
        print(f"  ✅ 修剪完成: 保留 {len(self.context_items)} 项, {self.current_tokens} 个token")
    
    def _trim_item_content(self, content: str, target_token_reduction: int) -> str:
        """修剪单个项的内容"""
        # 按句子修剪（以句号、问号、感叹号分割）
        import re
        sentences = re.split(r'([。！？\.!?])', content)
        
        # 重组句子，每句后加回标点
        grouped = []
        for i in range(0, len(sentences) - 1, 2):
            if i + 1 < len(sentences):
                grouped.append(sentences[i] + sentences[i + 1])
        
        if not grouped:
            return content
        
        # 从后往前移除句子（先移除相对不重要的部分）
        trimmed_sentences = []
        current_tokens = len(content) // 4
        target_tokens = current_tokens - target_token_reduction
        
        for sentence in grouped:
            sentence_tokens = len(sentence) // 4
            if current_tokens - sentence_tokens >= target_tokens:
                current_tokens -= sentence_tokens
            else:
                trimmed_sentences.append(sentence)
        
        return ''.join(trimmed_sentences)
    
    def _handle_injecting(self):
        """注入到提示"""
        print("  💉 将上下文注入到提示...")
        
        # 标记为已注入
        self.injected_items = self.context_items.copy()
        
        print(f"  ✅ 注入完成: {len(self.injected_items)} 个上下文项已注入")
    
    def _generate_final_prompt(self) -> str:
        """生成最终提示"""
        if self.current_state == InjectionState.ERROR:
            error_msg = f"上下文注入失败: {', '.join(self.errors)}"
            print(f"  ❌ {error_msg}")
            return error_msg
        
        print("  📄 生成最终提示...")
        
        # 组装提示
        prompt_parts = []
        
        # 1. 系统提示
        system_prompt = """你是一个专业的AI助手，拥有以下上下文信息："""
        prompt_parts.append(system_prompt)
        
        # 2. 上下文部分
        for i, item in enumerate(self.injected_items, 1):
            source_labels = {
                "working": "工作记忆",
                "short_term": "近期对话",
                "long_term": "相关知识"
            }
            source_label = source_labels.get(item.source, item.source)
            
            prompt_parts.append(f"\n【{source_label} {i}】")
            prompt_parts.append(item.content)
        
        # 3. 用户指令部分
        prompt_parts.append("\n\n基于以上上下文，请专业、准确地回答用户的问题。")
        
        # 4. 统计信息（调试用，实际中可能移除）
        if self.warnings:
            prompt_parts.append(f"\n\n[系统提示: 本次上下文注入有{len(self.warnings)}个警告]")
        
        final_prompt = "\n".join(prompt_parts)
        
        # 统计信息
        stats = {
            "上下文项数": len(self.injected_items),
            "总token数": self.current_tokens,
            "最终字符数": len(final_prompt),
            "状态": self.current_state.value,
            "警告数": len(self.warnings)
        }
        
        print("  📊 最终提示统计:")
        for key, value in stats.items():
            print(f"    {key}: {value}")
        
        return final_prompt
```

### 2.3 实现混合检索策略

**完整实现**:

```python
from typing import List, Dict, Any
from abc import ABC, abstractmethod
import time
import re

# 假设MemoryItem类已定义
class MemoryItem:
    """记忆项（简化版）"""
    def __init__(self, content: str, memory_type: Any, importance: float = 0.5, 
                 tags: List[str] = None, timestamp: float = None):
        self.content = content
        self.memory_type = memory_type
        self.importance = importance
        self.tags = tags or []
        self.timestamp = timestamp or time.time()

class RetrievalStrategy(ABC):
    """记忆检索策略基类"""
    @abstractmethod
    def retrieve(self, query: str, memories: List[MemoryItem]) -> List[MemoryItem]:
        """检索记忆"""
        pass
    
    @abstractmethod
    def score_memory(self, query: str, memory: MemoryItem) -> float:
        """评分记忆（0.0-1.0）"""
        pass

class KeywordRetrieval(RetrievalStrategy):
    """关键词检索策略"""
    def __init__(self, min_score_threshold: float = 0.1):
        self.min_score_threshold = min_score_threshold
    
    def retrieve(self, query: str, memories: List[MemoryItem]) -> List[MemoryItem]:
        """基于关键词的检索"""
        keywords = self._extract_keywords(query)
        
        if not keywords:
            return memories[:10]  # 无关键词时返回最近的
        
        scored_memories = []
        for memory in memories:
            score = self.score_memory(query, memory)
            if score >= self.min_score_threshold:
                scored_memories.append((memory, score))
        
        # 按分数排序
        scored_memories.sort(key=lambda x: x[1], reverse=True)
        return [memory for memory, score in scored_memories]
    
    def score_memory(self, query: str, memory: MemoryItem) -> float:
        """基于关键词匹配的评分"""
        keywords = self._extract_keywords(query)
        
        if not keywords:
            return 0.0
        
        content_lower = memory.content.lower()
        matched_keywords = 0
        
        for keyword in keywords:
            if keyword.lower() in content_lower:
                matched_keywords += 1
        
        # 基础分数：匹配关键词比例
        base_score = matched_keywords / len(keywords)
        
        # 根据记忆重要性调整
        adjusted_score = base_score * (0.5 + memory.importance * 0.5)
        
        return min(adjusted_score, 1.0)
    
    def _extract_keywords(self, query: str) -> List[str]:
        """提取关键词"""
        # 中文停用词
        chinese_stop_words = {"的", "了", "在", "是", "我", "有", "和", "就", "不", "人", "都", "一", "个", "上", "也", "很", "到", "说", "要", "去", "你", "会", "着", "没有", "看", "好", "自己", "这"}
        # 英文停用词
        english_stop_words = {"the", "a", "an", "and", "or", "but", "in", "on", "at", "to", "for", "of", "with", "by", "as", "is", "are", "was", "were", "be", "been", "being", "have", "has", "had"}
        
        all_stop_words = chinese_stop_words.union(english_stop_words)
        
        # 分割单词（简单实现）
        words = re.findall(r'[\u4e00-\u9fff]+|[a-zA-Z]+', query)
        
        keywords = []
        for word in words:
            clean_word = word.lower().strip()
            if (clean_word and 
                clean_word not in all_stop_words and 
                len(clean_word) > 1):
                keywords.append(clean_word)
        
        return keywords[:10]  # 最多10个关键词

class TemporalRetrieval(RetrievalStrategy):
    """时间检索策略"""
    def __init__(self, time_decay_factor: float = 0.5):
        self.time_decay_factor = time_decay_factor  # 时间衰减因子
    
    def retrieve(self, query: str, memories: List[MemoryItem]) -> List[MemoryItem]:
        """基于时间的检索"""
        # 按时间排序（最近的在前）
        sorted_memories = sorted(memories, key=lambda x: x.timestamp, reverse=True)
        
        # 如果记忆很少，直接返回
        if len(sorted_memories) <= 10:
            return sorted_memories
        
        # 计算时间分数
        scored_memories = []
        current_time = time.time()
        
        for memory in sorted_memories:
            score = self.score_memory(query, memory)
            
            # 时间衰减：越近的记忆分数越高
            time_diff = current_time - memory.timestamp
            time_factor = max(0.1, 1.0 - (time_diff / (24 * 3600)) * self.time_decay_factor)  # 按天衰减
            
            final_score = score * time_factor
            scored_memories.append((memory, final_score))
        
        # 按最终分数排序
        scored_memories.sort(key=lambda x: x[1], reverse=True)
        return [memory for memory, score in scored_memories[:20]]  # 最多20条
    
    def score_memory(self, query: str, memory: MemoryItem) -> float:
        """时间策略的评分"""
        # 时间策略也考虑基本的相关性
        keywords = query.split()[:3]  # 只检查前3个词
        
        if not keywords:
            return 0.5  # 无查询词时返回中等分数
        
        content_lower = memory.content.lower()
        matches = 0
        for keyword in keywords:
            if keyword.lower() in content_lower:
                matches += 1
        
        # 基础相关性分数
        base_score = matches / len(keywords)
        
        # 结合记忆重要性
        return base_score * (0.3 + memory.importance * 0.7)

class RelevanceRetrieval(RetrievalStrategy):
    """相关性检索策略"""
    def __init__(self, similarity_threshold: float = 0.2):
        self.similarity_threshold = similarity_threshold
        self.similarity_cache = {}  # 简单的缓存
    
    def retrieve(self, query: str, memories: List[MemoryItem]) -> List[MemoryItem]:
        """基于相关性的检索"""
        scored_memories = []
        
        for memory in memories:
            score = self.score_memory(query, memory)
            if score >= self.similarity_threshold:
                scored_memories.append((memory, score))
        
        # 按相关性分数排序
        scored_memories.sort(key=lambda x: x[1], reverse=True)
        return [memory for memory, score in scored_memories]
    
    def score_memory(self, query: str, memory: MemoryItem) -> float:
        """基于语义相似度的评分"""
        # 缓存键
        cache_key = f"{query[:50]}_{memory.content[:50]}"
        if cache_key in self.similarity_cache:
            return self.similarity_cache[cache_key]
        
        # 简化实现：使用Jaccard相似度
        query_words = set(self._tokenize(query))
        memory_words = set(self._tokenize(memory.content))
        
        if not query_words or not memory_words:
            similarity = 0.0
        else:
            intersection = query_words.intersection(memory_words)
            union = query_words.union(memory_words)
            similarity = len(intersection) / len(union)
        
        # 根据记忆类型和重要性调整
        type_factor = 1.0
        if hasattr(memory, 'memory_type'):
            if memory.memory_type.value == "long_term":
                type_factor = 1.2  # 长期记忆更相关
            elif memory.memory_type.value == "working":
                type_factor = 1.1  # 工作记忆次之
        
        adjusted_similarity = similarity * type_factor * (0.5 + memory.importance * 0.5)
        final_score = min(adjusted_similarity, 1.0)
        
        # 缓存结果
        self.similarity_cache[cache_key] = final_score
        return final_score
    
    def _tokenize(self, text: str) -> List[str]:
        """分词"""
        # 移除标点，分割单词
        clean_text = re.sub(r'[^\w\u4e00-\u9fff\s]', ' ', text)
        tokens = clean_text.lower().split()
        
        # 过滤停用词
        stop_words = {"the", "a", "an", "and", "or", "but", "in", "on", "at", "to", 
                     "for", "of", "with", "by", "的", "了", "在", "是", "我", "有", "和"}
        return [token for token in tokens if token not in stop_words and len(token) > 1]

class HybridRetrieval(RetrievalStrategy):
    """混合检索策略"""
    def __init__(self, strategies: List[RetrievalStrategy] = None, 
                 weights: Dict[str, float] = None):
        if strategies is None:
            self.strategies = [
                KeywordRetrieval(min_score_threshold=0.1),
                TemporalRetrieval(time_decay_factor=0.5),
                RelevanceRetrieval(similarity_threshold=0.2),
            ]
        else:
            self.strategies = strategies
        
        # 默认权重
        default_weights = {
            "KeywordRetrieval": 0.4,
            "TemporalRetrieval": 0.3,
            "RelevanceRetrieval": 0.3,
        }
        
        if weights is None:
            self.weights = default_weights
        else:
            self.weights = {**default_weights, **weights}  # 合并权重
    
    def retrieve(self, query: str, memories: List[MemoryItem]) -> List[MemoryItem]:
        """混合检索"""
        if not memories:
            return []
        
        # 收集所有策略的结果
        all_scores = {}  # memory -> total_score
        
        for strategy in self.strategies:
            strategy_name = strategy.__class__.__name__
            weight = self.weights.get(strategy_name, 0.2)
            
            strategy_results = strategy.retrieve(query, memories)
            
            # 为每个结果分配分数
            for i, memory in enumerate(strategy_results):
                # 排名分数（越靠前分数越高）
                rank_score = 1.0 - (i / len(strategy_results)) if strategy_results else 0.0
                
                # 策略特定分数
                strategy_score = strategy.score_memory(query, memory)
                
                # 综合分数
                combined_score = (rank_score * 0.3 + strategy_score * 0.7) * weight
                
                if memory not in all_scores:
                    all_scores[memory] = 0.0
                
                all_scores[memory] += combined_score
        
        # 转换为列表并排序
        scored_memories = [(memory, score) for memory, score in all_scores.items()]
        scored_memories.sort(key=lambda x: x[1], reverse=True)
        
        return [memory for memory, score in scored_memories]
    
    def score_memory(self, query: str, memory: MemoryItem) -> float:
        """混合评分"""
        scores = []
        total_weight = 0.0
        
        for strategy in self.strategies:
            strategy_name = strategy.__class__.__name__
            weight = self.weights.get(strategy_name, 0.2)
            
            score = strategy.score_memory(query, memory)
            scores.append(score * weight)
            total_weight += weight
        
        if total_weight == 0:
            return 0.0
        
        return sum(scores) / total_weight
```

```python
def calculate_topic_similarity(topic1: str, topic2: str) -> float:
    """计算主题相似度"""
    # 使用词向量或简单的关键词重叠
    words1 = set(topic1.lower().split())
    words2 = set(topic2.lower().split())
    if not words1 or not words2:
        return 0.0
    return len(words1.intersection(words2)) / len(words1.union(words2))

def retrieve_related_topics(current_topic: str, learning_topics: List[LearningTopic]) -> List[LearningTopic]:
```

### 3.2 性能优化设计

**瓶颈分析**:
1. **检索性能**: 随着记忆项增加，线性搜索效率低下
2. **内存使用**: 大量记忆项占用内存，可能影响系统性能
3. **并发查询**: 多用户同时查询可能导致资源竞争

**优化策略**:

#### 策略1: 建立高效索引
```python
class MemoryIndex:
    """内存索引系统"""
    
    def __init__(self):
        self.keyword_index = defaultdict(set)  # 关键词 → 记忆项ID集合
        self.temporal_index = SortedDict()     # 时间戳 → 记忆项ID集合
        self.importance_index = SortedDict()   # 重要性 → 记忆项ID集合
    
    def add_memory(self, memory: MemoryItem):
        """添加记忆到索引"""
        # 关键词索引
        for keyword in self._extract_keywords(memory.content):
            self.keyword_index[keyword].add(memory.id)
        
        # 时间索引
        self.temporal_index.setdefault(memory.timestamp, set()).add(memory.id)
        
        # 重要性索引
        importance_key = round(memory.importance, 1)  # 四舍五入到0.1
        self.importance_index.setdefault(importance_key, set()).add(memory.id)
    
    def search_by_keywords(self, keywords: List[str]) -> Set[str]:
        """关键词搜索（使用倒排索引）"""
        if not keywords:
            return set()
        
        result_sets = []
        for keyword in keywords:
            if keyword in self.keyword_index:
                result_sets.append(self.keyword_index[keyword])
        
        if not result_sets:
            return set()
        
        # 求交集（AND搜索）或并集（OR搜索）
        return set.intersection(*result_sets) if len(result_sets) > 1 else result_sets[0]
```

```python
class MultiLevelCache:
    """多层缓存系统"""
    
    def __init__(self):
        self.l1_cache = {}  # L1: 内存缓存，存储热点数据
        self.l2_cache = {}  # L2: 磁盘缓存，存储次热点数据
        self.l1_max_size = 1000
        self.l2_max_size = 10000
        self.access_stats = defaultdict(int)  # 访问统计
    
    def get(self, key: str):
        """获取缓存数据"""
        # L1缓存命中
        if key in self.l1_cache:
            self.access_stats[key] += 1
            return self.l1_cache[key]
        
        # L2缓存命中
        if key in self.l2_cache:
            value = self.l2_cache[key]
            # 提升到L1缓存
            self._promote_to_l1(key, value)
            self.access_stats[key] += 1
            return value
        
        # 缓存未命中
        return None
    
    def _promote_to_l1(self, key: str, value: Any):
        """提升数据到L1缓存"""
        if len(self.l1_cache) >= self.l1_max_size:
            # 淘汰L1中最少使用的项
            lru_key = min(self.l1_cache.keys(), key=lambda k: self.access_stats.get(k, 0))
            demoted_value = self.l1_cache.pop(lru_key)
            # 降级到L2缓存
            self._demote_to_l2(lru_key, demoted_value)
        
        self.l1_cache[key] = value
    
    def _demote_to_l2(self, key: str, value: Any):
        """降级数据到L2缓存"""
        if len(self.l2_cache) >= self.l2_max_size:
            # 淘汰L2中最少使用的项
            lru_key = min(self.l2_cache.keys(), key=lambda k: self.access_stats.get(k, 0))
            self.l2_cache.pop(lru_key)
        
        self.l2_cache[key] = value
```

```python
import asyncio
from concurrent.futures import ThreadPoolExecutor

class AsyncMemorySystem:
    """异步内存系统"""
    
    def __init__(self, max_workers: int = 4):
        self.executor = ThreadPoolExecutor(max_workers=max_workers)
        self.batch_queue = asyncio.Queue()
        self.batch_size = 10
        self.batch_timeout = 0.1  # 秒
    
    async def add_memory_batch(self, memories: List[MemoryItem]):
        """批量添加记忆（异步）"""
        if len(memories) >= self.batch_size:
            # 直接处理完整批次
            await self._process_batch(memories)
        else:
            # 添加到队列，等待累积或超时
            await self.batch_queue.put(memories)
    
    async def _process_batch(self, memories: List[MemoryItem]):
        """处理批次"""
        # 在线程池中执行耗时的索引操作
        loop = asyncio.get_event_loop()
        await loop.run_in_executor(
            self.executor, 
            self._index_memories, 
            memories
        )
    
    def _index_memories(self, memories: List[MemoryItem]):
        """索引记忆（同步，在线程池中执行）"""
        for memory in memories:
            # 执行索引操作
            self.index.add_memory(memory)
        
        print(f"已索引 {len(memories)} 个记忆项")
```

**权衡分析**:
1. **索引优化**:
   - 优点: 大幅提升检索速度（从O(n)到O(log n)或O(1)）
   - 缺点: 增加存储开销，索引维护成本
   - 适用场景: 记忆项数量大（>1000），检索频率高

2. **多层缓存**:
   - 优点: 提升热点数据的访问速度，减少重复计算
   - 缺点: 缓存一致性维护复杂，内存占用增加
   - 适用场景: 访问模式有明显热点，重复查询多

3. **异步处理**:

```python
from cryptography.fernet import Fernet
import base64

class SecureMemoryStorage:
    """安全记忆存储"""
    
    def __init__(self, encryption_key: str = None):
        if encryption_key:
            self.cipher = Fernet(base64.urlsafe_b64encode(encryption_key.encode()))
        else:
            self.cipher = Fernet.generate_key()
            self.cipher = Fernet(self.cipher)
    
    def encrypt_memory(self, memory: MemoryItem) -> EncryptedMemory:
        """加密记忆"""
        # 序列化记忆项
        memory_data = json.dumps(memory.to_dict()).encode()
        
        # 加密数据
        encrypted_data = self.cipher.encrypt(memory_data)
        
        # 创建加密记忆项
        return EncryptedMemory(
            id=memory.id,
            encrypted_data=encrypted_data,
            metadata={
                "content_hash": hashlib.sha256(memory.content.encode()).hexdigest(),
                "encryption_time": time.time(),
                "importance": memory.importance  # 重要性不加密，用于检索
            }
        )
    
    def decrypt_memory(self, encrypted_memory: EncryptedMemory) -> MemoryItem:
        """解密记忆"""
        # 解密数据
        decrypted_data = self.cipher.decrypt(encrypted_memory.encrypted_data)
        
        # 反序列化
        memory_dict = json.loads(decrypted_data.decode())
        
        # 验证完整性
        content_hash = hashlib.sha256(memory_dict["content"].encode()).hexdigest()
        if content_hash != encrypted_memory.metadata["content_hash"]:
            raise SecurityError("记忆内容完整性验证失败")
        
        return MemoryItem.from_dict(memory_dict)
```

```python
                await task()

                break
            except Exception as e:

        if customer_id:
            self.customer_index[customer_id].append(conversation.id)

        if conversation.solution_effective is not None:
            solution_id = conversation.solution_id
            if solution_id:
                current_effectiveness = self.solution_library.solution_effectiveness.get(solution_id, 0.5)
                usage_count = self.solution_library.solution_usage_count.get(solution_id, 0) + 1
                
                # 更新有效性评分（指数加权移动平均）
                new_effectiveness = current_effectiveness * 0.7 + conversation.solution_effective * 0.3
```

```python
class PrivacyPreservingLearningMemory(PersonalLearningMemory):
    """隐私保护的学习记忆系统"""
    
    def __init__(self, user_id: str, encryption_key: str = None):
        super().__init__(user_id)
        
        # 本地存储
        self.local_storage = LocalStorage()
        
        # 数据加密
        self.encryption = MemoryEncryption(encryption_key)
        
        # 隐私设置
        self.privacy_settings = {
            "data_collection": True,  # 允许数据收集
            "data_analysis": True,    # 允许数据分析
            "cloud_sync": False,      # 禁止云端同步（默认）
            "data_sharing": False,    # 禁止数据共享
            "data_retention_days": 90,  # 数据保留90天
        }
    
    def save_locally(self):
        """保存到本地"""
        # 序列化数据
        data = {
            "learning_goals": self.learning_goals,
            "completed_goals": self.completed_goals,
            "study_patterns": self.study_patterns.to_dict(),
            "knowledge_graph": self.knowledge_graph.to_dict(),
        }
        
        # 加密敏感数据
        encrypted_data = self.encryption.encrypt_sensitive_fields(data)
        
        # 保存到本地文件
        self.local_storage.save(self.user_id, encrypted_data)
    
    def load_from_local(self):
        """从本地加载"""
        # 从本地文件读取
        encrypted_data = self.local_storage.load(self.user_id)
        
        if encrypted_data:
            # 解密数据
            data = self.encryption.decrypt_sensitive_fields(encrypted_data)
            
            # 恢复状态
            self.learning_goals = data.get("learning_goals", [])
            self.completed_goals = data.get("completed_goals", [])
            self.study_patterns.from_dict(data.get("study_patterns", {}))
            self.knowledge_graph.from_dict(data.get("knowledge_graph", {}))
    
    def export_data(self, format: str = "json") -> str:
        """导出数据（用户控制）"""
        if not self.privacy_settings["data_sharing"]:
            raise PermissionError("数据共享被禁用")
        
        data = self._prepare_export_data()
        
        # 根据隐私设置过滤数据
        filtered_data = self._apply_privacy_filters(data)
        
        # 格式转换
        if format == "json":
            return json.dumps(filtered_data, ensure_ascii=False, indent=2)
        elif format == "csv":
            return self._convert_to_csv(filtered_data)
        else:
            raise ValueError(f"不支持的格式: {format}")
    
    def delete_data(self, days_old: int = None):
        """删除数据"""
        if days_old is None:
            days_old = self.privacy_settings["data_retention_days"]
        
        # 删除指定天数前的数据
        cutoff_time = time.time() - days_old * 24 * 3600
        self._delete_old_data(cutoff_time)
        
        # 清理本地存储
        self.local_storage.cleanup(self.user_id, cutoff_time)
        
        print(f"已删除 {days_old} 天前的数据")
```

```python
class TeamPermissionSystem:
    """团队权限系统"""
    
    def __init__(self):
        self.roles = {
            "owner": {"read": True, "write": True, "delete": True, "admin": True},
            "admin": {"read": True, "write": True, "delete": True, "admin": True},
            "member": {"read": True, "write": True, "delete": False, "admin": False},
            "guest": {"read": True, "write": False, "delete": False, "admin": False},
        }
        
        self.resource_permissions = defaultdict(dict)  # 资源ID → {用户ID: 权限}
        self.audit_log = AuditLog()
    
    def check_resource_permission(self, user_id: str, resource_type: str, 
                                 resource_id: str, action: str) -> bool:
        """检查资源权限"""
        # 获取用户角色
        user_role = self.get_user_role(user_id, resource_id)
        
        # 检查角色基础权限
        if not self.roles[user_role][action]:
            self.audit_log.log_access(user_id, resource_id, action, False, "角色权限不足")
            return False
        
        # 检查资源特定权限
        resource_key = f"{resource_type}:{resource_id}"
        if resource_key in self.resource_permissions:
            resource_perms = self.resource_permissions[resource_key]
            if user_id in resource_perms:
                if not resource_perms[user_id].get(action, True):
                    self.audit_log.log_access(user_id, resource_id, action, False, "资源权限不足")
                    return False
        
        # 记录成功的访问
        self.audit_log.log_access(user_id, resource_id, action, True)
        return True
    
    def set_resource_permission(self, resource_type: str, resource_id: str, 
                               user_id: str, permissions: Dict[str, bool]):
        """设置资源权限"""
        resource_key = f"{resource_type}:{resource_id}"
        self.resource_permissions[resource_key][user_id] = permissions
        
        # 记录权限变更
        self.audit_log.log_permission_change(
            admin_id="system",  # 或实际管理员ID
            resource_id=resource_id,
            user_id=user_id,
            permissions=permissions
        )
```

```python
class KnowledgeSharingSystem:
    """知识共享系统"""
    
    def __init__(self):
        self.knowledge_base = KnowledgeBase()
        self.workflow_integrations = {}
        self.search_engine = KnowledgeSearchEngine()
    
    def integrate_with_workflow(self, workflow_type: str, config: Dict[str, Any]):
        """集成工作流"""
        if workflow_type == "jira":
            self.workflow_integrations["jira"] = JiraIntegration(config)
        elif workflow_type == "slack":
            self.workflow_integrations["slack"] = SlackIntegration(config)
        elif workflow_type == "github":
            self.workflow_integrations["github"] = GitHubIntegration(config)
        elif workflow_type == "notion":
            self.workflow_integrations["notion"] = NotionIntegration(config)
        else:
            raise ValueError(f"不支持的工作流类型: {workflow_type}")
        
        print(f"已集成 {workflow_type} 工作流")
    
    def capture_workflow_knowledge(self, workflow_type: str, event: Dict[str, Any]):
        """捕获工作流知识"""
        integration = self.workflow_integrations.get(workflow_type)
        if not integration:
            print(f"未找到 {workflow_type} 集成")
            return
        
        # 从工作流事件中提取知识
        knowledge = integration.extract_knowledge(event)
        
        if knowledge:
            # 添加到知识库
            self.knowledge_base.add_knowledge(knowledge)
            
            # 通知相关团队成员
            self._notify_team_members(knowledge)
            
            print(f"已捕获知识: {knowledge.title}")
    
    def search_knowledge(self, query: str, filters: Dict[str, Any] = None) -> List[KnowledgeItem]:
        """搜索知识"""
        results = self.search_engine.search(query, filters)
        
        # 按相关性排序
        results.sort(key=lambda x: x.relevance_score, reverse=True)
        
        return results
    
    def recommend_related_knowledge(self, context: Dict[str, Any]) -> List[KnowledgeItem]:
        """推荐相关知识"""
        recommendations = []
        
        # 基于上下文的推荐
        if "current_task" in context:
            task_knowledge = self._find_task_related_knowledge(context["current_task"])
            recommendations.extend(task_knowledge)
        
        if "current_project" in context:
            project_knowledge = self._find_project_related_knowledge(context["current_project"])
            recommendations.extend(project_knowledge)
        
        if "team_members" in context:
            member_knowledge = self._find_member_related_knowledge(context["team_members"])
            recommendations.extend(member_knowledge)
        
        # 去重和排序
        unique_recommendations = list({k.id: k for k in recommendations}.values())
        unique_recommendations.sort(key=lambda x: x.relevance_score, reverse=True)
        
        return unique_recommendations[:5]  # 返回前5个
```
