## 🧠 第一部分：概念理解与选择 - 答案

### 1.1 多项选择题答案

**1. 技能缓存的主要目的是什么？**
**答案: B) 提高技能执行性能和减少外部调用**
**解析**: 技能缓存的核心目的是性能优化，通过存储中间结果或外部API调用的结果，避免重复计算或调用，从而显著提高技能执行速度并减少对外部系统的依赖。

**2. 在技能缓存设计中，TTL（Time To Live）策略指的是什么？**
**答案: B) 缓存条目从创建到过期的时间**
**解析**: TTL（Time To Live）策略定义了缓存条目从创建到自动过期的时间长度，适用于时效性要求较高的数据，确保缓存数据不会过时。

**3. 技能编排器(SkillOrchestrator)的核心职责不包括以下哪项？**
**答案: C) 提供技能开发IDE**
**解析**: 技能编排器主要负责技能执行管理、数据传递、错误恢复和状态监控，不提供技能开发IDE（集成开发环境），这是开发工具的责任。

**4. 组合技能(Composite Skill)最适合以下哪种场景？**
**答案: B) 将多个独立技能组合成复杂功能**
**解析**: 组合技能设计模式允许将多个独立的技能组合起来形成更复杂的功能，同时对外提供统一的接口，是构建复杂业务流程的理想选择。

**5. 在技能工程化中，以下哪项不是代码质量的重要指标？**
**答案: B) 代码行数越多越好**
**解析**: 代码质量的重要指标包括可读性、模块化程度、错误处理完整性、测试覆盖率等，代码行数多并不意味着质量好，反而可能表示代码冗余或结构不良。

**6. 异步技能执行相比同步执行的主要优势是什么？**
**答案: B) 更好的资源利用和并发性能**
**解析**: 异步执行允许在等待I/O操作（如网络请求、文件读写）时释放CPU资源，从而在同一时间内处理更多请求，显著提高系统并发性能和资源利用率。

**7. 技能性能监控不应该关注以下哪个指标？**
**答案: C) 技能开发者的年龄**
**解析**: 技能性能监控应关注执行时间、缓存命中率、内存使用量、错误频率等与性能直接相关的指标，技能开发者的年龄与性能无关。

**8. 对于需要频繁调用的外部API的技能，哪种缓存策略最合适？**
**答案: B) TTL策略，设置为API更新频率**
**解析**: 对于频繁调用的外部API，应根据API数据的更新频率设置TTL（Time To Live），既能有效减少API调用次数，又能确保数据的时效性。

**9. 组合技能设计应该遵循哪个设计模式？**
**答案: C) 组合模式**
**解析**: 组合技能设计遵循组合模式（Composite Pattern），这种模式允许以统一的方式处理单个对象和对象组合，非常适合构建层次化的技能系统。

**10. 技能编排器的错误恢复机制中，重试策略的主要考虑因素是什么？**
**答案: B) 错误类型和可能恢复性**
**解析**: 重试策略应根据错误类型（网络错误可以重试，逻辑错误不应重试）和错误的可能恢复性来设计，盲目重试可能导致系统雪崩或无限循环。

### 1.2 判断题答案

**11. 技能缓存可以完全消除所有外部API调用。**
**答案: ×**  
**解析**: 技能缓存可以减少但不完全消除外部API调用，特别是对于首次请求或缓存过期后的请求，仍然需要进行API调用。

**12. 技能编排器应该负责技能的具体业务逻辑实现。**
**答案: ×**  
**解析**: 技能编排器负责技能的执行管理、数据传递和错误恢复，但不应该包含具体的业务逻辑，业务逻辑应由各个技能自身实现。

**13. 组合技能的子技能之间应该是完全独立的。**
**答案: √**  
**解析**: 组合技能的子技能应该保持独立性，这样每个子技能都可以单独使用、测试和复用，提高系统的模块化程度。

**14. 异步技能执行总是比同步执行更快。**
**答案: ×**  
**解析**: 异步执行在I/O密集型任务中通常更快，但对于CPU密集型任务，异步可能不会带来性能提升，甚至可能因为上下文切换开销而变慢。

**15. 所有技能都应该实现缓存机制，无论调用频率如何。**
**答案: ×**  
**解析**: 缓存机制适用于频繁调用或计算代价高的技能，对于极少调用或简单的技能，缓存可能带来不必要的复杂性和内存开销。

**16. 技能编排器需要支持技能执行的暂停和恢复。**
**答案: √**  
**解析**: 对于长时间运行的技能链或需要人工干预的场景，技能编排器应该支持执行暂停和恢复，提高系统的灵活性和可控性。

**17. 组合技能可以包含其他组合技能，形成嵌套结构。**
**答案: √**  
**解析**: 组合模式支持嵌套结构，一个组合技能可以包含其他组合技能，形成层次化的技能系统，提供更强大的抽象能力。

**18. 技能监控只需要关注错误率，不需要关注性能指标。**
**答案: ×**  
**解析**: 技能监控应该全面关注性能指标（执行时间、资源使用、吞吐量）和错误率，两者都是评估技能健康状态的重要维度。

**19. TTL缓存策略适用于所有类型的技能。**
**答案: ×**  
**解析**: TTL策略适用于数据具有明显时效性的场景，对于静态数据或更新不频繁的数据，LRU（最近最少使用）策略可能更合适。

**20. 技能工程化的最佳实践不包括编写单元测试。**
**答案: ×**  
**解析**: 编写单元测试是技能工程化的核心最佳实践之一，确保代码质量、减少回归错误、提高系统可靠性。

**解析**: 执行时间反映单个请求的性能，吞吐量反映系统处理能力，错误率反映系统稳定性，三者是性能监控的基础指标。

**26. 技能编排器的错误恢复机制通常包括 ______、______ 和 ______。**
**答案: 重试（Retry），降级（Fallback），熔断（Circuit Breaker）**
**解析**: 重试用于暂时性错误，降级用于提供基本功能，熔断用于防止系统雪崩，是微服务架构中常用的三种错误恢复机制。

**27. 技能缓存失效的常见原因包括 ______、______ 和 ______。**

**解析**: 时间过期是TTL策略的必然结果，容量淘汰是缓存满时的处理机制，主动失效是数据更新时的主动清理。

**解析**: 模块化提高复用性，可测试性确保质量，可维护性降低长期成本，性能优化提升用户体验，安全性保护系统安全。

**29. 组合技能中，子技能之间的通信方式有 ______ 和 ______。**

**解析**: 共享数据上下文是同步通信方式，事件驱动是异步通信方式，两种方式各有适用场景，可以结合使用。

**解析**: 就绪状态等待执行，执行中状态正在运行技能，完成状态表示执行结束（成功或失败），是状态机的基本状态。

### 2.1 新闻摘要技能实现

**完整实现代码**:
```python
import asyncio
import re
import time
from typing import Dict, Any, Optional, List
from dataclasses import dataclass, field
from enum import Enum
from collections import OrderedDict

# 技能基类定义
class Skill:
    def __init__(self, name: str, description: str, version: str):
        self.name = name
        self.description = description
        self.version = version
    
    async def execute(self, **kwargs) -> Dict[str, Any]:
        raise NotImplementedError("子类必须实现execute方法")
    
    def validate_input(self, **kwargs) -> bool:
        raise NotImplementedError("子类必须实现validate_input方法")

# 缓存策略枚举
class CachePolicy(Enum):
    LRU = "lru"  # 最近最少使用
    TTL = "ttl"  # 时间过期

# LRU缓存实现
class LRUCache:
    def __init__(self, capacity: int = 50):
        self.capacity = capacity
        self.cache = OrderedDict()
    
    def get(self, key: str) -> Optional[Any]:
        if key not in self.cache:
            return None
        # 移动到最近使用位置
        self.cache.move_to_end(key)
        return self.cache[key]
    
    def set(self, key: str, value: Any):
        if key in self.cache:
            # 更新现有值并移动到最近使用位置
            self.cache[key] = value
            self.cache.move_to_end(key)
        else:
            # 添加新值
            self.cache[key] = value
            # 如果超过容量，移除最久未使用的
            if len(self.cache) > self.capacity:
                self.cache.popitem(last=False)
    
    def clear(self):
        self.cache.clear()
    
    def size(self) -> int:
        return len(self.cache)

# 新闻来源枚举
class NewsSource(Enum):
    RSS = "rss"
    API = "api"
    WEB = "web"
    SOCIAL = "social"

# 新闻数据类
@dataclass
class NewsItem:
    url: str
    title: str
    content: str
    source: NewsSource
    published_at: float
    author: Optional[str] = None
    category: Optional[str] = None

# 摘要结果类
@dataclass
class SummaryResult:
    news_url: str
    summary: str
    key_points: List[str]
    source: NewsSource
    summary_length: int
    processing_time: float
    cached: bool = False

# 新闻摘要技能实现
class NewsSummarySkill(Skill):
    def __init__(self):
        super().__init__(
            name="NewsSummarySkill",
            description="新闻内容摘要生成技能",
            version="1.0.0"
        )
        self.cache = LRUCache(capacity=50)
        self.url_pattern = re.compile(
            r'^https?://(?:www\.)?[a-zA-Z0-9-]+\.[a-zA-Z]{2,}(?:/[^\s]*)?$'
        )
    
    def validate_input(self, **kwargs) -> bool:
        """验证输入参数"""
        # 检查必需的参数
        if 'url' not in kwargs:
            raise ValueError("缺少必需的参数: url")
        
        url = kwargs['url']
        
        # 验证URL格式
        if not isinstance(url, str) or not self.url_pattern.match(url):
            raise ValueError(f"无效的URL格式: {url}")
        
        # 验证可选参数
        if 'source' in kwargs:
            source = kwargs['source']
            if not isinstance(source, NewsSource):
                raise ValueError(f"无效的新闻来源: {source}")
        
        # 验证内容参数（如果提供）
        if 'content' in kwargs and not isinstance(kwargs['content'], str):
            raise ValueError("content参数必须是字符串")
        
        return True
    
    async def _fetch_news_content(self, url: str, source: NewsSource) -> str:
        """模拟获取新闻内容"""
        # 模拟不同来源的获取逻辑
        if source == NewsSource.RSS:
            await asyncio.sleep(0.1)  # 模拟网络延迟
            return f"RSS新闻内容: {url} - 这是来自RSS源的示例内容..."
        elif source == NewsSource.API:
            await asyncio.sleep(0.2)
            return f"API新闻内容: {url} - 这是来自新闻API的示例内容..."
        elif source == NewsSource.WEB:
            await asyncio.sleep(0.3)
            return f"网页新闻内容: {url} - 这是从网页抓取的示例内容..."
        else:
            await asyncio.sleep(0.15)
            return f"社交媒体新闻内容: {url} - 这是来自社交媒体的示例内容..."
    
    def _generate_summary(self, content: str) -> SummaryResult:
        """生成新闻摘要（简化实现）"""
        # 在实际应用中，这里会使用NLP模型进行文本摘要
        # 这里使用简单的文本处理作为示例
        
        # 提取关键句子（模拟）
        sentences = content.split('. ')
        if len(sentences) > 3:
            key_sentences = sentences[:3]
        else:
            key_sentences = sentences
        
        # 生成摘要
        summary = '. '.join(key_sentences) + '.'
        
        # 提取关键点（模拟）
        key_points = []
        for i, sentence in enumerate(key_sentences[:5]):
            key_points.append(f"关键点{i+1}: {sentence[:50]}...")
        
        return SummaryResult(
            news_url="模拟URL",
            summary=summary,
            key_points=key_points,
            source=NewsSource.API,
            summary_length=len(summary),
            processing_time=0.1
        )
    
    async def execute(self, **kwargs) -> Dict[str, Any]:
        """执行新闻摘要生成"""
        start_time = time.time()
        
        try:
            # 1. 验证输入
            self.validate_input(**kwargs)
            
            url = kwargs['url']
            source = kwargs.get('source', NewsSource.API)
            content = kwargs.get('content')
            
            # 2. 检查缓存
            cache_key = f"{url}:{source.value}"
            cached_result = self.cache.get(cache_key)
            
            if cached_result is not None:
                # 返回缓存结果
                cached_result['cached'] = True
                cached_result['processing_time'] = time.time() - start_time
                return cached_result
            
            # 3. 获取新闻内容（如果未提供）
            if content is None:
                content = await self._fetch_news_content(url, source)
            
            # 4. 生成摘要
            summary_result = self._generate_summary(content)
            summary_result.processing_time = time.time() - start_time
            
            # 5. 缓存结果
            result_dict = {
                'success': True,
                'summary_result': summary_result,
                'cached': False,
                'processing_time': summary_result.processing_time,
                'cache_key': cache_key
            }
            
            self.cache.set(cache_key, result_dict.copy())
            
            return result_dict
            
        except Exception as e:
            # 错误处理
            return {
                'success': False,
                'error': str(e),
                'error_type': type(e).__name__,
                'processing_time': time.time() - start_time
            }

# 运行测试
```

**实现要点解析**:
1. **缓存设计**: 使用LRU策略，容量为50，通过OrderedDict实现最近最少使用淘汰
2. **输入验证**: 包括URL格式验证、参数类型检查、必需参数验证
3. **错误处理**: 使用try-except捕获异常，返回结构化的错误信息
4. **异步执行**: 使用async/await处理潜在的I/O操作（如网络请求）
5. **模块化设计**: 将不同功能拆分为独立方法，提高可测试性和可维护性
6. **结构化输出**: 使用dataclass定义清晰的数据结构，便于理解和扩展

### 2.2 技能编排器实现

**完整实现代码**:
```python
import asyncio
import time
from enum import Enum
from typing import List, Dict, Any, Optional, Callable
from dataclasses import dataclass, field
from collections import defaultdict

# 编排器状态枚举
class OrchestratorState(Enum):
    IDLE = "idle"          # 空闲状态
    EXECUTING = "executing"  # 执行中
    PAUSED = "paused"      # 已暂停
    COMPLETED = "completed"  # 执行完成
    FAILED = "failed"      # 执行失败

# 技能执行上下文
@dataclass
class ExecutionContext:
    skill_name: str
    input_data: Dict[str, Any]
    output_data: Optional[Dict[str, Any]] = None
    error: Optional[str] = None
    execution_time: float = 0.0
    retry_count: int = 0
    status: str = "pending"
    timestamp: float = field(default_factory=time.time)

# 技能执行结果
@dataclass
class SkillExecutionResult:
    skill_name: str
    success: bool
    output: Optional[Dict[str, Any]] = None
    error: Optional[str] = None
    execution_time: float = 0.0
    cached: bool = False

# 新闻处理编排器
class NewsProcessingOrchestrator:
    def __init__(
        self,
        max_retries: int = 3,
        retry_delay: float = 2.0,
        timeout: float = 30.0,
        enable_monitoring: bool = True
    ):
        self.max_retries = max_retries
        self.retry_delay = retry_delay
        self.timeout = timeout
        self.enable_monitoring = enable_monitoring
        
        # 状态管理
        self.state = OrchestratorState.IDLE
        self.execution_contexts: List[ExecutionContext] = []
        self.current_skill_index = 0
        
        # 统计信息
        self.stats = {
            "total_executions": 0,
            "successful_executions": 0,
            "failed_executions": 0,
            "total_execution_time": 0.0,
            "average_execution_time": 0.0,
            "cache_hits": 0,
            "cache_misses": 0
        }
        
        # 回调函数
        self.on_skill_start: Optional[Callable] = None
        self.on_skill_complete: Optional[Callable] = None
        self.on_error: Optional[Callable] = None
        self.on_state_change: Optional[Callable] = None
    
    def _update_state(self, new_state: OrchestratorState):
        """更新编排器状态"""
        old_state = self.state
        self.state = new_state
        
        # 触发状态变更回调
        if self.on_state_change:
            self.on_state_change(old_state, new_state)
    
    def _update_stats(self, result: SkillExecutionResult):
        """更新统计信息"""
        self.stats["total_executions"] += 1
        
        if result.success:
            self.stats["successful_executions"] += 1
        else:
            self.stats["failed_executions"] += 1
        
        self.stats["total_execution_time"] += result.execution_time
        self.stats["average_execution_time"] = (
            self.stats["total_execution_time"] / self.stats["total_executions"]
        )
        
        if result.cached:
            self.stats["cache_hits"] += 1
        else:
            self.stats["cache_misses"] += 1
    
    async def _execute_skill_with_retry(
        self,
        skill,
        context: ExecutionContext,
        skill_name: str
    ) -> SkillExecutionResult:
        """执行单个技能，支持重试"""
        start_time = time.time()
        retry_count = 0
        
        while retry_count <= self.max_retries:
            try:
                # 触发技能开始回调
                if self.on_skill_start:
                    self.on_skill_start(skill_name, context.input_data)
                
                # 执行技能（带超时控制）
                execution_task = asyncio.create_task(
                    skill.execute(**context.input_data)
                )
                
                try:
                    result = await asyncio.wait_for(execution_task, timeout=self.timeout)
                except asyncio.TimeoutError:
                    execution_task.cancel()
                    raise TimeoutError(f"技能执行超时: {skill_name}")
                
                execution_time = time.time() - start_time
                
                # 构建执行结果
                if result.get('success', False):
                    skill_result = SkillExecutionResult(
                        skill_name=skill_name,
                        success=True,
                        output=result,
                        execution_time=execution_time,
                        cached=result.get('cached', False)
                    )
                else:
                    skill_result = SkillExecutionResult(
                        skill_name=skill_name,
                        success=False,
                        error=result.get('error', '未知错误'),
                        execution_time=execution_time
                    )
                
                # 触发技能完成回调
                if self.on_skill_complete:
                    self.on_skill_complete(skill_name, skill_result)
                
                return skill_result
                
            except Exception as e:
                retry_count += 1
                context.retry_count = retry_count
                
                # 判断是否应该重试
                should_retry = (
                    retry_count <= self.max_retries and 
                    self._is_retryable_error(e)
                )
                
                if not should_retry:
                    # 最终失败
                    execution_time = time.time() - start_time
                    
                    # 触发错误回调
                    if self.on_error:
                        self.on_error(skill_name, e, retry_count)
                    
                    return SkillExecutionResult(
                        skill_name=skill_name,
                        success=False,
                        error=str(e),
                        execution_time=execution_time
                    )
                
                # 等待重试延迟
                await asyncio.sleep(self.retry_delay)
        
        # 理论上不会执行到这里
        return SkillExecutionResult(
            skill_name=skill_name,
            success=False,
            error="重试次数耗尽",
            execution_time=time.time() - start_time
        )
    
    def _is_retryable_error(self, error: Exception) -> bool:
        """判断错误是否可重试"""
        retryable_errors = [
            TimeoutError,
            ConnectionError,
            asyncio.TimeoutError
        ]
        
        # 网络相关错误通常可以重试
        error_name = type(error).__name__.lower()
        retryable_keywords = ['timeout', 'connection', 'network', 'temporarily']
        
        for keyword in retryable_keywords:
            if keyword in error_name:
                return True
        
        return any(isinstance(error, err_type) for err_type in retryable_errors)
    
    def _create_execution_plan(
        self,
        skills: List[Any],
        initial_data: Dict[str, Any]
    ) -> List[ExecutionContext]:
        """创建执行计划"""
        contexts = []
        current_data = initial_data.copy()
        
        for i, skill in enumerate(skills):
            context = ExecutionContext(
                skill_name=getattr(skill, 'name', f"skill_{i}"),
                input_data=current_data.copy()
            )
            contexts.append(context)
            
            # 更新数据传递（模拟）
            # 在实际应用中，会根据技能输出更新current_data
        
        return contexts
    
    async def execute_pipeline(
        self,
        skills: List[Any],
        initial_data: Dict[str, Any],
        enable_pause: bool = False
    ) -> Dict[str, Any]:
        """执行技能管道"""
        if self.state != OrchestratorState.IDLE:
            raise RuntimeError(f"编排器当前状态为 {self.state.value}，无法执行")
        
        self._update_state(OrchestratorState.EXECUTING)
        
        try:
            # 1. 创建执行计划
            self.execution_contexts = self._create_execution_plan(skills, initial_data)
            self.current_skill_index = 0
            
            # 2. 按顺序执行技能
            all_results = []
            execution_data = initial_data.copy()
            
            for i, (skill, context) in enumerate(zip(skills, self.execution_contexts)):
                self.current_skill_index = i
                
                # 检查是否需要暂停
                if enable_pause and self.state == OrchestratorState.PAUSED:
                    # 等待恢复
                    while self.state == OrchestratorState.PAUSED:
                        await asyncio.sleep(0.1)
                
                # 执行技能
                skill_name = getattr(skill, 'name', f"skill_{i}")
                result = await self._execute_skill_with_retry(skill, context, skill_name)
                
                # 更新执行上下文
                context.output_data = result.output
                context.error = result.error
                context.execution_time = result.execution_time
                context.status = "completed" if result.success else "failed"
                
                # 更新统计
                self._update_stats(result)
                
                # 更新执行数据（用于传递到下一个技能）
                if result.output:
                    execution_data.update(result.output)
                
                all_results.append(result)
                
                # 如果技能失败且不可恢复，停止执行
                if not result.success and not self._is_retryable_error(
                    Exception(result.error) if result.error else Exception()
                ):
                    break
            
            # 3. 执行完成
            success_count = sum(1 for r in all_results if r.success)
            total_count = len(all_results)
            
            if success_count == total_count:
                self._update_state(OrchestratorState.COMPLETED)
            else:
                self._update_state(OrchestratorState.FAILED)
            
            # 返回最终结果
            return {
                'success': success_count == total_count,
                'total_skills': total_count,
                'successful_skills': success_count,
                'failed_skills': total_count - success_count,
                'results': all_results,
                'stats': self.stats.copy(),
                'total_execution_time': sum(r.execution_time for r in all_results)
            }
            
        except Exception as e:
            self._update_state(OrchestratorState.FAILED)
            raise
    
    def pause(self):
        """暂停执行"""
        if self.state == OrchestratorState.EXECUTING:
            self._update_state(OrchestratorState.PAUSED)
    
    def resume(self):
        """恢复执行"""
        if self.state == OrchestratorState.PAUSED:
            self._update_state(OrchestratorState.EXECUTING)
    
    def cancel(self):
        """取消执行"""
        self._update_state(OrchestratorState.IDLE)
        self.execution_contexts.clear()
        self.current_skill_index = 0
    
    def get_execution_summary(self) -> Dict[str, Any]:
        """获取执行摘要"""
        return {
            'state': self.state.value,
            'current_skill_index': self.current_skill_index,
            'total_contexts': len(self.execution_contexts),
            'stats': self.stats.copy(),
            'contexts': [
                {
                    'skill_name': ctx.skill_name,
                    'status': ctx.status,
                    'execution_time': ctx.execution_time,
                    'retry_count': ctx.retry_count
                }
                for ctx in self.execution_contexts
            ]
        }
```

**实现要点解析**:
1. **状态管理**: 使用状态机模式管理编排器的生命周期，支持暂停和恢复
2. **重试机制**: 实现智能重试策略，根据错误类型决定是否重试
3. **超时控制**: 使用asyncio.wait_for实现技能执行超时控制
4. **数据传递**: 通过执行上下文在技能链中传递数据
5. **监控统计**: 收集详细的执行统计，便于性能分析和优化
6. **回调机制**: 提供事件回调，方便集成监控和日志系统
7. **错误隔离**: 单个技能失败不影响其他技能执行（可配置）
8. **执行计划**: 支持动态创建执行计划，灵活适应不同场景

### 2.3 组合技能实现

**完整实现代码**:
```python
import asyncio
import time
from typing import List, Dict, Any, Optional, Callable
from dataclasses import dataclass, field
from enum import Enum

# 子技能执行模式
class SubSkillExecutionMode(Enum):
    SEQUENTIAL = "sequential"    # 顺序执行
    PARALLEL = "parallel"        # 并行执行
    CONDITIONAL = "conditional"  # 条件执行

# 子技能配置
@dataclass
class SubSkillConfig:
    skill: Any
    enabled: bool = True
    timeout: Optional[float] = None
    retries: int = 0
    condition: Optional[Callable[[Dict[str, Any]], bool]] = None

# 组合技能执行上下文
@dataclass
class CompositeExecutionContext:
    sub_skill_name: str
    input_data: Dict[str, Any]
    output_data: Optional[Dict[str, Any]] = None
    error: Optional[str] = None
    execution_time: float = 0.0
    skipped: bool = False
    timestamp: float = field(default_factory=time.time)

# 组合技能基类
class CompositeSkill:
    def __init__(self, name: str, description: str):
        self.name = name
        self.description = description
        self.version = "1.0.0"
        self.sub_skills: List[SubSkillConfig] = []
        self.execution_mode = SubSkillExecutionMode.SEQUENTIAL
        self.enable_error_isolation = True
        self.enable_performance_monitoring = True
        
        # 性能监控
        self.performance_stats = {
            'total_executions': 0,
            'average_execution_time': 0.0,
            'sub_skill_stats': {}
        }
    
    def add_sub_skill(
        self,
        skill: Any,
        enabled: bool = True,
        timeout: Optional[float] = None,
        retries: int = 0,
        condition: Optional[Callable[[Dict[str, Any]], bool]] = None
    ):
        """添加子技能"""
        config = SubSkillConfig(
            skill=skill,
            enabled=enabled,
            timeout=timeout,
            retries=retries,
            condition=condition
        )
        self.sub_skills.append(config)
    
    def remove_sub_skill(self, skill_name: str):
        """移除子技能"""
        self.sub_skills = [
            config for config in self.sub_skills
            if getattr(config.skill, 'name', '') != skill_name
        ]
    
    def update_sub_skill_config(
        self,
        skill_name: str,
        enabled: Optional[bool] = None,
        timeout: Optional[float] = None,
        retries: Optional[int] = None
    ):
        """更新子技能配置"""
        for config in self.sub_skills:
            if getattr(config.skill, 'name', '') == skill_name:
                if enabled is not None:
                    config.enabled = enabled
                if timeout is not None:
                    config.timeout = timeout
                if retries is not None:
                    config.retries = retries
                break
    
    def _should_execute_sub_skill(
        self,
        config: SubSkillConfig,
        context_data: Dict[str, Any]
    ) -> bool:
        """判断是否应该执行子技能"""
        if not config.enabled:
            return False
        
        if config.condition and not config.condition(context_data):
            return False
        
        return True
    
    async def _execute_sub_skill_with_retry(
        self,
        config: SubSkillConfig,
        context: CompositeExecutionContext,
        execution_data: Dict[str, Any]
    ) -> Dict[str, Any]:
        """执行单个子技能，支持重试"""
        skill_name = getattr(config.skill, 'name', 'unknown')
        timeout = config.timeout or 30.0
        retry_count = 0
        
        while retry_count <= config.retries:
            try:
                start_time = time.time()
                
                # 执行子技能（带超时控制）
                execution_task = asyncio.create_task(
                    config.skill.execute(**execution_data)
                )
                
                try:
                    result = await asyncio.wait_for(execution_task, timeout=timeout)
                except asyncio.TimeoutError:
                    execution_task.cancel()
                    raise TimeoutError(f"子技能执行超时: {skill_name}")
                
                execution_time = time.time() - start_time
                
                # 更新执行上下文
                context.output_data = result
                context.execution_time = execution_time
                context.skipped = False
                
                # 更新性能统计
                self._update_performance_stats(skill_name, execution_time, True)
                
                return result
                
            except Exception as e:
                retry_count += 1
                
                if retry_count > config.retries:
                    # 最终失败
                    context.error = str(e)
                    context.execution_time = time.time() - start_time if 'start_time' in locals() else 0
                    
                    # 更新性能统计
                    self._update_performance_stats(skill_name, context.execution_time, False)
                    
                    if self.enable_error_isolation:
                        # 错误隔离模式：返回错误信息但不终止
                        return {
                            'success': False,
                            'error': str(e),
                            'skill_name': skill_name,
                            'retry_count': retry_count
                        }
                    else:
                        # 非隔离模式：抛出异常
                        raise
                
                # 等待重试
                await asyncio.sleep(1.0)
        
        # 理论上不会执行到这里
        return {'success': False, 'error': '未知错误'}
    
    def _update_performance_stats(
        self,
        skill_name: str,
        execution_time: float,
        success: bool
    ):
        """更新性能统计"""
        if not self.enable_performance_monitoring:
            return
        
        # 初始化子技能统计
        if skill_name not in self.performance_stats['sub_skill_stats']:
            self.performance_stats['sub_skill_stats'][skill_name] = {
                'total_executions': 0,
                'successful_executions': 0,
                'failed_executions': 0,
                'total_execution_time': 0.0,
                'average_execution_time': 0.0
            }
        
        stats = self.performance_stats['sub_skill_stats'][skill_name]
        stats['total_executions'] += 1
        
        if success:
            stats['successful_executions'] += 1
        else:
            stats['failed_executions'] += 1
        
        stats['total_execution_time'] += execution_time
        stats['average_execution_time'] = (
            stats['total_execution_time'] / stats['total_executions']
        )
        
        # 更新整体统计
        self.performance_stats['total_executions'] += 1
        total_time = sum(
            s['total_execution_time']
            for s in self.performance_stats['sub_skill_stats'].values()
        )
        self.performance_stats['average_execution_time'] = (
            total_time / self.performance_stats['total_executions']
            if self.performance_stats['total_executions'] > 0 else 0
        )
    
    async def _execute_sequential(
        self,
        execution_data: Dict[str, Any],
        contexts: List[CompositeExecutionContext]
    ) -> Dict[str, Any]:
        """顺序执行子技能"""
        results = []
        
        for config, context in zip(self.sub_skills, contexts):
            # 检查是否应该执行
            if not self._should_execute_sub_skill(config, execution_data):
                context.skipped = True
                continue
            
            # 执行子技能
            skill_result = await self._execute_sub_skill_with_retry(
                config, context, execution_data.copy()
            )
            
            # 更新执行数据（传递给下一个子技能）
            if skill_result.get('success', False):
                execution_data.update(skill_result)
            
            results.append({
                'skill_name': getattr(config.skill, 'name', 'unknown'),
                'result': skill_result,
                'context': context
            })
        
        return {
            'success': True,
            'results': results,
            'execution_data': execution_data
        }
    
    async def _execute_parallel(
        self,
        execution_data: Dict[str, Any],
        contexts: List[CompositeExecutionContext]
    ) -> Dict[str, Any]:
        """并行执行子技能"""
        tasks = []
        task_configs = []
        
        # 创建执行任务
        for config, context in zip(self.sub_skills, contexts):
            # 检查是否应该执行
            if not self._should_execute_sub_skill(config, execution_data):
                context.skipped = True
                continue
            
            # 创建任务
            task = asyncio.create_task(
                self._execute_sub_skill_with_retry(config, context, execution_data.copy())
            )
            tasks.append(task)
            task_configs.append((config, context))
        
        # 等待所有任务完成
        task_results = await asyncio.gather(*tasks, return_exceptions=True)
        
        # 处理结果
        results = []
        combined_data = execution_data.copy()
        
        for (config, context), task_result in zip(task_configs, task_results):
            if isinstance(task_result, Exception):
                # 任务执行异常
                skill_result = {
                    'success': False,
                    'error': str(task_result)
                }
                context.error = str(task_result)
            else:
                # 正常结果
                skill_result = task_result
                context.output_data = task_result
            
            results.append({
                'skill_name': getattr(config.skill, 'name', 'unknown'),
                'result': skill_result,
                'context': context
            })
            
            # 合并执行数据
            if skill_result.get('success', False):
                combined_data.update(skill_result)
        
        return {
            'success': True,
            'results': results,
            'execution_data': combined_data
        }
    
    async def execute(self, **kwargs) -> Dict[str, Any]:
        """执行组合技能"""
        start_time = time.time()
        
        try:
            # 1. 验证输入
            if not self._validate_input(**kwargs):
                return {
                    'success': False,
                    'error': '输入验证失败',
```

```python
class DistributedCache:
    def __init__(self, consistency_level="eventual"):
        self.consistency_level = consistency_level
        self.local_cache = LRUCache()
        self.redis_client = RedisCluster()
        self.version_store = VersionStore()
    
    async def get(self, key: str) -> Optional[Any]:
        # 1. 检查本地缓存
        local_value = self.local_cache.get(key)
        if local_value and not self._is_stale(local_value):
            return local_value['data']
        
        # 2. 检查分布式缓存
        redis_value = await self.redis_client.get(key)
        if redis_value:
            # 更新本地缓存
            self.local_cache.set(key, {
                'data': redis_value['data'],
                'version': redis_value['version'],
                'timestamp': time.time()
            })
            return redis_value['data']
        
        # 3. 回源加载
        data = await self._load_from_source(key)
        if data:
            # 异步更新缓存
            asyncio.create_task(self._update_cache(key, data))
        
        return data
    
    async def _update_cache(self, key: str, data: Any):
        """异步更新缓存（最终一致性）"""
        # 生成新版本
        new_version = self.version_store.increment(key)
        
        # 先更新分布式缓存
        await self.redis_client.set(key, {
            'data': data,
            'version': new_version,
            'timestamp': time.time()
        }, ttl=3600)
        
        # 广播更新通知（可选）
        await self._broadcast_update(key, new_version)
    
    def _is_stale(self, cached_item: Dict) -> bool:
        """检查缓存是否过期"""
        # 基于版本或时间戳判断
        current_version = self.version_store.get_version(cached_item['key'])
        return cached_item['version'] < current_version
```

```python
        # 1. 解析工作流定义
        nodes = self._parse_workflow(workflow)
        
        # 2. 构建执行图
        execution_graph = self._build_execution_graph(nodes)

        execution_order = self._topological_sort(execution_graph)
        
        # 4. 执行节点
        context = ExecutionContext()

            result = await self._execute_node(node, context)
            
            # 更新执行上下文

            # 检查后置条件
            if not self._check_postconditions(node, result):
```

```python
class DialogStateMachine:
    def __init__(self):
        self.states = {
            "greeting": self._handle_greeting,
            "intent_recognition": self._handle_intent_recognition,
            "slot_filling": self._handle_slot_filling,
            "skill_execution": self._handle_skill_execution,
            "confirmation": self._handle_confirmation,
            "completion": self._handle_completion
        }
        self.current_state = "greeting"
        self.context = DialogContext()
    
    async def process_message(self, message: str) -> str:
        # 获取当前状态的处理函数
        handler = self.states.get(self.current_state)
        if not handler:
            return "系统错误: 未知状态"
        
        # 执行状态处理
        result = await handler(message)
        
        # 更新状态
        if result.next_state:
            self.current_state = result.next_state
        
        return result.response
    
    async def _handle_intent_recognition(self, message: str):
        # 调用意图识别技能
        intent_result = await self.intent_skill.execute(message=message)
        
        # 更新对话上下文
        self.context.intent = intent_result['intent']
        self.context.confidence = intent_result['confidence']
        
        # 确定下一个状态
        if intent_result['requires_slots']:
            next_state = "slot_filling"
        else:
            next_state = "skill_execution"
        
        return DialogResult(
            response=intent_result['response'],
            next_state=next_state
        )
```

```python
class RuleEngine:
    def __init__(self):
        self.rules = RuleRepository()

    async def evaluate_transaction(self, transaction: Dict) -> RiskResult:
        # 1. 规则匹配
        matched_rules = await self.rules.match_rules(transaction)
        
        # 2. 规则执行
        rule_results = []
        for rule in matched_rules:
            result = await self.executor.execute_rule(rule, transaction)
            rule_results.append(result)
        
        # 3. 结果聚合
        risk_score = self._aggregate_results(rule_results)
        risk_level = self._determine_risk_level(risk_score)
        
        # 4. 生成处置建议
        action = self._generate_action(risk_level, transaction)
        
        return RiskResult(
            risk_score=risk_score,
            risk_level=risk_level,
            action=action,
            rule_details=rule_results
        )
```

```python
class ExplainableRiskModel:
    def __init__(self, model, explainer):
        self.model = model
        self.explainer = explainer  # SHAP、LIME等
    
    async def predict_with_explanation(self, features: Dict):
        # 1. 模型预测
        prediction = await self.model.predict(features)
        
        # 2. 生成解释
        explanation = await self.explainer.explain(features, prediction)
        
        # 3. 转换为业务可理解的格式
        business_explanation = self._to_business_terms(explanation)
        
        return {
            'prediction': prediction,
            'explanation': business_explanation,
            'confidence': explanation['confidence'],
            'key_factors': explanation['key_factors']
        }
    
    def _to_business_terms(self, technical_explanation: Dict) -> Dict:
        """将技术解释转换为业务术语"""
        business_terms = {}
        
        for factor, importance in technical_explanation['factors'].items():
            # 映射技术特征到业务概念
            business_concept = self.feature_mapping.get(factor, factor)
            business_terms[business_concept] = {
                'importance': importance,
                'direction': self._get_direction(factor, importance),
                'business_impact': self._get_business_impact(factor, importance)
            }
        
        return business_terms
```
