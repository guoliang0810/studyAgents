## 🧠 第一部分：概念理解与选择 - 答案

### 1.1 多项选择题答案

**1. 中间件执行顺序对系统行为的影响主要体现在哪些方面？**
**答案: B) 影响请求处理流程、安全性、性能和错误处理**
**解析**: 中间件执行顺序直接影响：1) 请求处理流程 - 决定中间件执行的先后关系；2) 安全性 - 认证、验证等安全中间件的执行位置；3) 性能 - 缓存、限流等中间件的执行时机；4) 错误处理 - 错误中间件的处理顺序。合理的执行顺序设计是中间件链编排的核心。

**2. MiddlewareChain类设计中，前置处理链和后置处理链的执行顺序分别是？**
**答案: C) 前置顺序执行，后置逆序执行**
**解析**: 前置处理链采用顺序执行（从第一个到最后一个），确保请求按照设计流程逐步处理；后置处理链采用逆序执行（从最后一个到第一个），确保响应处理与请求处理形成对称的"栈"结构，这种设计符合责任链模式的最佳实践。

**3. 滑动时间窗口限流算法的核心思想是什么？**
**答案: C) 在每个固定时间窗口内限制请求数量，窗口随时间滑动**
**解析**: 滑动时间窗口限流算法的核心是：1) 定义固定大小的时间窗口（如60秒）；2) 统计每个用户在窗口内的请求数量；3) 当请求超过阈值时拒绝请求；4) 窗口随时间滑动，自动淘汰过期请求。这种算法比固定窗口更平滑，比令牌桶更简单。

**4. 动态中间件调度器的主要价值体现在哪里？**
**答案: C) 根据请求特征动态调整中间件执行顺序和启用状态，优化性能和安全性**
**解析**: 动态调度器的主要价值：1) 根据请求复杂度调整中间件链 - 简单请求跳过某些中间件提高性能；2) 根据时间特征调整 - 高峰期启用严格限流，低峰期禁用；3) 根据用户特征调整 - VIP用户放宽限制；4) 实时优化系统性能和资源利用率。

**5. 在中间件链中，认证中间件通常应该放在哪个位置？为什么？**
**答案: B) 最先执行，避免无效请求占用后续中间件资源**
**解析**: 认证中间件应该最先执行，因为：1) 安全优先原则 - 尽早拒绝未认证请求；2) 资源保护 - 避免无效请求占用限流、验证、业务处理等资源；3) 性能优化 - 减少不必要的中间件执行；4) 审计跟踪 - 所有请求都经过认证检查，便于审计。

**6. 缓存中间件在中间件链中的理想执行位置是？**
**答案: C) 在认证和验证之后，业务逻辑之前，避免缓存未经验证的请求**
**解析**: 缓存中间件的理想位置：1) 在认证之后 - 避免缓存未认证用户的请求；2) 在验证之后 - 避免缓存格式错误的请求；3) 在业务逻辑之前 - 缓存命中时直接返回，避免执行昂贵的业务逻辑；4) 这种位置设计平衡了性能和安全性。

**7. 限流中间件返回None（终止执行）时，后续中间件应该如何处理？**
**答案: C) 停止执行，直接返回限流响应**
**解析**: 当限流中间件返回None（终止执行）时：1) 中间件链应该立即停止执行；2) 直接返回限流响应给客户端；3) 不执行后续中间件（包括业务逻辑）；4) 这样可以节省系统资源，快速响应限流结果。

**8. 中间件链性能分析的主要指标不包括？**
**答案: D) 服务器硬件型号**
**解析**: 中间件链性能分析的主要指标：1) 每个中间件的执行时间；2) 中间件链整体执行时间；3) 中间件启用/禁用状态统计；4) 错误率和错误类型分析。服务器硬件型号是基础设施信息，不是性能分析的核心指标。

**9. 中间件编排最佳实践中，以下哪项不是重要原则？**
**答案: C) 中间件数量越多越好**
**解析**: 重要原则包括：1) 安全中间件优先执行；2) 性能敏感中间件后执行；3) 错误处理要完善；4) 执行顺序要合理设计。中间件数量应根据业务需求合理设计，不是越多越好，过多的中间件会增加系统复杂性和性能开销。

**10. 动态调度器根据请求特征调度中间件时，考虑的特征不包括？**
**答案: D) 开发者姓名**
**解析**: 动态调度器考虑的请求特征：1) 消息长度和复杂度；2) 用户身份和权限；3) 请求时间（高峰期/低峰期）；4) 请求元数据复杂度。开发者姓名与请求处理无关，不是调度决策的依据。

### 1.2 判断题答案

**11. 中间件链的前置处理和后置处理必须是相同的中间件集合。**
**答案: ×**  
**解析**: 前置处理和后置处理可以是不同的中间件集合。有些中间件只参与前置处理（如认证、验证），有些只参与后置处理（如响应格式化、日志记录），有些两者都参与（如缓存、限流统计）。

**12. 限流中间件应该放在认证中间件之前，以保护认证系统不被恶意请求攻击。**
**答案: ×**  
**解析**: 限流中间件应该放在认证中间件之后。原因：1) 限流通常基于用户ID，未认证请求没有用户ID；2) 认证系统本身应该有防护措施；3) 限流算法需要用户上下文；4) 先认证可以更精确地限流。

**13. 动态调度器可以完全替代固定的中间件执行顺序设计。**
**答案: ×**  
**解析**: 动态调度器不能完全替代固定顺序设计。固定顺序提供了基础架构和默认行为，动态调度在其基础上进行优化。两者结合使用：固定顺序确保基本功能，动态调度提供智能优化。

**14. 缓存中间件应该缓存所有请求的响应，包括认证失败的请求。**
**答案: ×**  
**解析**: 缓存中间件不应该缓存认证失败的请求响应。原因：1) 认证失败可能是暂时的（如令牌过期）；2) 缓存失败响应可能泄露系统信息；3) 浪费缓存空间；4) 应该只缓存成功的、可重用的响应。

**15. 中间件执行顺序设计时，日志中间件通常优先级较低，最后执行前置处理。**
**答案: √**  
**解析**: 日志中间件通常优先级较低，最后执行前置处理，因为：1) 日志需要记录完整的请求信息（包括其他中间件处理后的结果）；2) 避免日志记录影响关键中间件的性能；3) 确保日志的准确性和完整性。

**16. 限流算法的滑动时间窗口大小是固定的，不能动态调整。**
**答案: ×**  
**解析**: 滑动时间窗口大小可以动态调整。高级限流系统支持：1) 根据系统负载动态调整窗口大小；2) 根据用户行为模式调整限流策略；3) 根据时间特征调整（高峰期/低峰期）；4) 自适应限流算法。

**17. 中间件链执行过程中，一个中间件出错应该终止整个链的执行。**
**答案: ×**  
**解析**: 中间件链错误处理策略：1) 关键中间件（如认证）出错应终止执行；2) 非关键中间件（如性能监控）出错可跳过继续执行；3) 错误应该被记录和报告；4) 系统应提供错误恢复机制。

**18. 动态调度器可以根据当前系统负载自动调整限流阈值。**
**答案: √**  
**解析**: 高级动态调度器支持：1) 监控系统负载（CPU、内存、请求队列）；2) 根据负载动态调整限流阈值；3) 实施弹性限流策略；4) 保证系统稳定性的同时最大化资源利用率。

**19. 所有中间件都必须实现before_agent和after_agent方法。**
**答案: ×**  
**解析**: 中间件可以根据需要实现before_agent、after_agent或两者。例如：1) 认证中间件通常只实现before_agent；2) 响应格式化中间件只实现after_agent；3) 日志中间件两者都实现。

**20. 中间件编排的可视化工具对于生产系统是必需的。**
**答案: ×**  
**解析**: 可视化工具对于复杂中间件编排系统非常有价值，但不是绝对必需的。小型系统可以通过配置文件和日志监控。可视化工具主要提供：1) 配置管理；2) 运行监控；3) 故障诊断；4) 性能分析。

### 2.1 基础中间件链实现 - 参考答案

**完整实现代码**:

```python
from typing import List, Optional, Dict, Any, Callable
import asyncio
import time
from enum import Enum
from collections import defaultdict
import json

class MiddlewareExecutionOrder(Enum):
    FIXED_ORDER = "fixed_order"
    DYNAMIC_ORDER = "dynamic_order"
    PRIORITY_BASED = "priority_based"

class AgentMiddleware:
    """中间件基类"""
    
    def __init__(self, name: str, priority: int = 10):
        self.name = name
        self.priority = priority
        self.enabled = True
        self.execution_count = 0
        self.total_execution_time = 0.0
    
    async def before_agent(self, request: Dict[str, Any]) -> Optional[Dict[str, Any]]:
        """前置处理方法 - 子类实现"""
        raise NotImplementedError(f"{self.name} must implement before_agent method")
    
    async def after_agent(self, request: Dict[str, Any], response: Dict[str, Any]) -> Optional[Dict[str, Any]]:
        """后置处理方法 - 子类实现"""
        raise NotImplementedError(f"{self.name} must implement after_agent method")
    
    async def on_error(self, request: Dict[str, Any], error: Exception) -> Optional[Dict[str, Any]]:
        """错误处理方法 - 子类可重写"""
        return None
    
    def get_stats(self) -> Dict[str, Any]:
        """获取统计信息"""
        avg_time = self.total_execution_time / self.execution_count if self.execution_count > 0 else 0
        return {
            "name": self.name,
            "priority": self.priority,
            "enabled": self.enabled,
            "execution_count": self.execution_count,
            "total_execution_time": self.total_execution_time,
            "average_execution_time": avg_time
        }

class MiddlewareChain:
    """中间件链编排引擎"""
    
    def __init__(self, name: str, execution_order: MiddlewareExecutionOrder = MiddlewareExecutionOrder.FIXED_ORDER):
        self.name = name
        self.execution_order = execution_order
        self.middlewares: List[AgentMiddleware] = []
        self._sorted_middlewares: List[AgentMiddleware] = []
        self._needs_sorting = True
        self.stats = {
            "total_executions": 0,
            "successful_executions": 0,
            "failed_executions": 0,
            "total_execution_time": 0.0
        }
    
    def add_middleware(self, middleware: AgentMiddleware, position: Optional[int] = None) -> None:
        """添加中间件到链中"""
        if position is None:
            self.middlewares.append(middleware)
        else:
            if position < 0 or position > len(self.middlewares):
                raise ValueError(f"Invalid position: {position}")
            self.middlewares.insert(position, middleware)
        
        self._needs_sorting = True
    
    def remove_middleware(self, middleware_name: str) -> bool:
        """从链中移除中间件"""
        for i, mw in enumerate(self.middlewares):
            if mw.name == middleware_name:
                self.middlewares.pop(i)
                self._needs_sorting = True
                return True
        return False
    
    def _sort_middlewares(self) -> None:
        """根据执行顺序策略对中间件排序"""
        if self.execution_order == MiddlewareExecutionOrder.FIXED_ORDER:
            # 固定顺序 - 按照添加顺序
            self._sorted_middlewares = self.middlewares.copy()
        elif self.execution_order == MiddlewareExecutionOrder.PRIORITY_BASED:
            # 基于优先级 - 优先级数值越小越先执行
            self._sorted_middlewares = sorted(self.middlewares, key=lambda m: m.priority)
        else:
            # 动态顺序 - 保持原始顺序
            self._sorted_middlewares = self.middlewares.copy()
        
        self._needs_sorting = False
    
    def get_sorted_middlewares(self) -> List[AgentMiddleware]:
        """获取排序后的中间件列表"""
        if self._needs_sorting:
            self._sort_middlewares()
        return self._sorted_middlewares
    
    async def execute_before_chain(self, request: Dict[str, Any]) -> Optional[Dict[str, Any]]:
        """执行前置中间件链（顺序执行）"""
        middlewares = self.get_sorted_middlewares()
        current_request = request
        
        for middleware in middlewares:
            if not middleware.enabled:
                continue
            
            start_time = time.time()
            try:
                result = await middleware.before_agent(current_request)
                execution_time = time.time() - start_time
                
                # 更新统计信息
                middleware.execution_count += 1
                middleware.total_execution_time += execution_time
                
                if result is None:
                    # 中间件返回None表示终止执行
                    return None
                
                current_request = result
                
            except Exception as e:
                execution_time = time.time() - start_time
                middleware.execution_count += 1
                middleware.total_execution_time += execution_time
                
                # 调用中间件的错误处理方法
                error_response = await middleware.on_error(current_request, e)
                if error_response is not None:
                    # 中间件处理了错误，返回响应
                    return error_response
                else:
                    # 中间件未处理错误，继续传播
                    raise
        
        return current_request
    
    async def execute_after_chain(self, request: Dict[str, Any], response: Dict[str, Any]) -> Dict[str, Any]:
        """执行后置中间件链（逆序执行）"""
        middlewares = list(reversed(self.get_sorted_middlewares()))
        current_response = response
        
        for middleware in middlewares:
            if not middleware.enabled:
                continue
            
            start_time = time.time()
            try:
                result = await middleware.after_agent(request, current_response)
                execution_time = time.time() - start_time
                
                # 更新统计信息
                middleware.execution_count += 1
                middleware.total_execution_time += execution_time
                
                if result is not None:
                    current_response = result
                
            except Exception as e:
                execution_time = time.time() - start_time
                middleware.execution_count += 1
                middleware.total_execution_time += execution_time
                
                # 调用中间件的错误处理方法
                error_response = await middleware.on_error(request, e)
                if error_response is not None:
                    current_response = error_response
        
        return current_response
    
    async def execute_full_chain(self, request: Dict[str, Any], agent_func: Callable) -> Dict[str, Any]:
        """执行完整的中间件链"""
        chain_start_time = time.time()
        
        try:
            # 1. 执行前置中间件链
            processed_request = await self.execute_before_chain(request)
            
            if processed_request is None:
                # 前置中间件链终止了执行
                self.stats["failed_executions"] += 1
                return {
                    "status": "terminated",
                    "message": "请求被中间件终止",
                    "timestamp": time.time()
                }
            
            # 2. 执行Agent
            agent_start_time = time.time()
            try:
                agent_response = await agent_func(processed_request)
                agent_time = time.time() - agent_start_time
            except Exception as e:
                self.stats["failed_executions"] += 1
                agent_response = {
                    "status": "error",
                    "message": f"Agent执行失败: {str(e)}",
                    "timestamp": time.time()
                }
            
            # 3. 执行后置中间件链
            final_response = await self.execute_after_chain(processed_request, agent_response)
            
            # 更新统计信息
            self.stats["total_executions"] += 1
            self.stats["successful_executions"] += 1
            self.stats["total_execution_time"] += time.time() - chain_start_time
            
            return final_response
            
        except Exception as e:
            self.stats["total_executions"] += 1
            self.stats["failed_executions"] += 1
            self.stats["total_execution_time"] += time.time() - chain_start_time
            raise
    
    def visualize_chain(self) -> str:
        """生成中间件链的可视化表示（ASCII图）"""
        middlewares = self.get_sorted_middlewares()
        
        lines = []
        lines.append(f"中间件链: {self.name}")
        lines.append("=" * 60)
        
        # 前置处理链
        lines.append("前置处理链 (顺序执行):")
        lines.append("┌─────────────────────────────────────┐")
        for i, mw in enumerate(middlewares):
            status = "✓" if mw.enabled else "✗"
            lines.append(f"│ {i+1:2d}. [{status}] {mw.name:<25} (优先级: {mw.priority:2d}) │")
        lines.append("└─────────────────────────────────────┘")
        
        # Agent执行
        lines.append("\n     ↓")
        lines.append("   [Agent]")
        lines.append("     ↓")
        lines.append("")
        
        # 后置处理链
        lines.append("后置处理链 (逆序执行):")
        lines.append("┌─────────────────────────────────────┐")
        for i, mw in enumerate(reversed(middlewares)):
            status = "✓" if mw.enabled else "✗"
            lines.append(f"│ {i+1:2d}. [{status}] {mw.name:<25} (优先级: {mw.priority:2d}) │")
        lines.append("└─────────────────────────────────────┘")
        
        # 统计信息
        lines.append("\n统计信息:")
        lines.append(f"  总执行次数: {self.stats['total_executions']}")
        lines.append(f"  成功次数: {self.stats['successful_executions']}")
        lines.append(f"  失败次数: {self.stats['failed_executions']}")
        if self.stats['total_executions'] > 0:
            success_rate = self.stats['successful_executions'] / self.stats['total_executions'] * 100
            avg_time = self.stats['total_execution_time'] / self.stats['total_executions']
            lines.append(f"  成功率: {success_rate:.1f}%")
            lines.append(f"  平均执行时间: {avg_time:.4f}秒")
        
        return "\n".join(lines)
    
    def get_chain_stats(self) -> Dict[str, Any]:
        """获取链统计信息"""
        middleware_stats = [mw.get_stats() for mw in self.middlewares]
        
        return {
            "chain_name": self.name,
            "execution_order": self.execution_order.value,
            "middleware_count": len(self.middlewares),
            "enabled_middleware_count": sum(1 for mw in self.middlewares if mw.enabled),
            "chain_stats": self.stats.copy(),
            "middleware_stats": middleware_stats
        }
```

```python
from typing import Dict, Any, Optional, Tuple, List
import time
from collections import deque, defaultdict

class RateLimitMiddleware(AgentMiddleware):
    """滑动时间窗口限流中间件"""
    
    def __init__(self, window_size_seconds: int = 60, max_requests_per_window: int = 10):
        super().__init__("rate_limit_middleware", priority=2)
        self.window_size_seconds = window_size_seconds
        self.max_requests_per_window = max_requests_per_window
        
        # 存储每个用户的请求时间戳
        self.user_requests: Dict[str, deque] = defaultdict(deque)
        
        # 统计信息
        self.stats = {
            "total_requests": 0,
            "limited_requests": 0,
            "current_active_users": 0,
            "peak_request_rate": 0.0
        }
        
        # 动态调整参数
        self.adaptive_mode = False
        self.min_window_size = window_size_seconds // 2
        self.max_window_size = window_size_seconds * 2
        self.min_max_requests = max_requests_per_window // 2
        self.max_max_requests = max_requests_per_window * 2
    
    def _clean_old_requests(self, user_id: str, current_time: float) -> None:
        """清理过期的请求记录"""
        if user_id not in self.user_requests:
            return
        
        window_start = current_time - self.window_size_seconds
        
        # 移除时间窗口之外的请求时间戳
        while (self.user_requests[user_id] and 
               self.user_requests[user_id][0] < window_start):
            self.user_requests[user_id].popleft()
    
    def _check_rate_limit(self, user_id: str, current_time: float) -> Tuple[bool, float, int]:
        """
        检查是否触发限流
        
        Returns:
            (is_limited, wait_time_seconds, current_count)
        """
        if not user_id:
            # 没有用户ID，不进行限流检查
            return False, 0.0, 0
        
        self._clean_old_requests(user_id, current_time)
        
        # 检查当前时间窗口内的请求数量
        request_count = len(self.user_requests[user_id])
        
        if request_count >= self.max_requests_per_window:
            # 计算需要等待的时间
            oldest_request_time = self.user_requests[user_id][0]
            window_end = oldest_request_time + self.window_size_seconds
            wait_time = max(0, window_end - current_time)
            
            return True, wait_time, request_count
        
        return False, 0.0, request_count
    
    async def before_agent(self, request: Dict[str, Any]) -> Optional[Dict[str, Any]]:
        """限流检查"""
        user_id = request.get("user_id")
        current_time = time.time()
        
        # 更新统计
        self.stats["total_requests"] += 1
        
        # 检查限流
        is_limited, wait_time, current_count = self._check_rate_limit(user_id, current_time)
        
        if is_limited:
            # 触发限流
            self.stats["limited_requests"] += 1
            
            # 更新请求元数据
            request["rate_limited"] = True
            request["wait_time_seconds"] = wait_time
            request["retry_after"] = current_time + wait_time
            request["current_request_count"] = current_count
            request["max_requests_per_window"] = self.max_requests_per_window
            
            return None  # 终止执行
        
        # 记录当前请求时间
        if user_id:
            self.user_requests[user_id].append(current_time)
            
            # 更新活跃用户统计
            self.stats["current_active_users"] = len(self.user_requests)
            
            # 计算当前请求率
            recent_requests = 0
            for req_time in self.user_requests[user_id]:
                if current_time - req_time < 10:  # 最近10秒
                    recent_requests += 1
            
            current_rate = recent_requests / 10.0  # 每秒请求数
            self.stats["peak_request_rate"] = max(self.stats["peak_request_rate"], current_rate)
        
        # 添加限流信息到请求元数据
        request["rate_limit_info"] = {
            "window_size_seconds": self.window_size_seconds,
            "max_requests": self.max_requests_per_window,
            "current_request_count": current_count + 1 if user_id else 0,
            "window_start": current_time - self.window_size_seconds,
            "window_end": current_time
        }
        
        return request
    
    async def after_agent(self, request: Dict[str, Any], response: Dict[str, Any]) -> Optional[Dict[str, Any]]:
        """记录限流统计信息"""
        if request.get("rate_limited"):
            # 如果是被限流的请求，添加限流响应信息
            response["status"] = "rate_limited"
            response["message"] = "请求频率超过限制"
            response["wait_time_seconds"] = request.get("wait_time_seconds", 0)
            response["retry_after"] = request.get("retry_after", 0)
            response["current_request_count"] = request.get("current_request_count", 0)
            response["max_requests_per_window"] = request.get("max_requests_per_window", 0)
        
        # 添加限流统计信息到响应
        response.setdefault("rate_limit_stats", {}).update({
            "total_requests": self.stats["total_requests"],
            "limited_requests": self.stats["limited_requests"],
            "limit_rate": self.stats["limited_requests"] / max(1, self.stats["total_requests"]),
            "current_active_users": self.stats["current_active_users"],
            "peak_request_rate": self.stats["peak_request_rate"]
        })
        
        return response
    
    def get_rate_limit_stats(self, user_id: Optional[str] = None) -> Dict[str, Any]:
        """获取限流统计信息"""
        stats = self.stats.copy()
        
        if user_id:
            current_time = time.time()
            self._clean_old_requests(user_id, current_time)
            
            user_stats = {
                "user_id": user_id,
                "current_request_count": len(self.user_requests.get(user_id, [])),
                "recent_requests": []
            }
            
            # 获取最近请求时间
            if user_id in self.user_requests:
                for req_time in self.user_requests[user_id]:
                    if current_time - req_time < 300:  # 最近5分钟
                        user_stats["recent_requests"].append({
                            "timestamp": req_time,
                            "age_seconds": current_time - req_time
                        })
            
            stats["user_stats"] = user_stats
        
        return stats
    
    def adjust_rate_limit(self, new_window_size: Optional[int] = None, new_max_requests: Optional[int] = None):
        """动态调整限流参数"""
        if new_window_size is not None:
            if self.adaptive_mode:
                # 自适应模式下，限制调整范围
                new_window_size = max(self.min_window_size, min(self.max_window_size, new_window_size))
            self.window_size_seconds = new_window_size
        
        if new_max_requests is not None:
            if self.adaptive_mode:
                new_max_requests = max(self.min_max_requests, min(self.max_max_requests, new_max_requests))
            self.max_requests_per_window = new_max_requests
        
        # 清理旧的请求记录（因为窗口大小可能改变了）
        current_time = time.time()
        for user_id in list(self.user_requests.keys()):
            self._clean_old_requests(user_id, current_time)
            
            # 如果用户没有活跃请求，删除记录
            if not self.user_requests[user_id]:
                del self.user_requests[user_id]
    
    def enable_adaptive_mode(self, min_window_size: Optional[int] = None, max_window_size: Optional[int] = None,
                           min_max_requests: Optional[int] = None, max_max_requests: Optional[int] = None):
        """启用自适应限流模式"""
        self.adaptive_mode = True
        
        if min_window_size:
            self.min_window_size = min_window_size
        if max_window_size:
            self.max_window_size = max_window_size
        if min_max_requests:
            self.min_max_requests = min_max_requests
        if max_max_requests:
            self.max_max_requests = max_max_requests
    
    def auto_adjust_based_on_load(self, current_load: float, max_load: float = 0.8):
        """基于当前负载自动调整限流参数"""
        if not self.adaptive_mode:
            return
        
        load_ratio = current_load / max_load
        
        if load_ratio > 1.2:
            # 负载过高，收紧限流
            new_window_size = int(self.window_size_seconds * 0.8)  # 缩小窗口
            new_max_requests = int(self.max_requests_per_window * 0.7)  # 减少最大请求数
        elif load_ratio > 1.0:
            # 负载偏高，适度收紧
            new_window_size = int(self.window_size_seconds * 0.9)
            new_max_requests = int(self.max_requests_per_window * 0.85)
        elif load_ratio < 0.5:
            # 负载很低，放宽限流
            new_window_size = int(self.window_size_seconds * 1.2)
            new_max_requests = int(self.max_requests_per_window * 1.5)
        elif load_ratio < 0.8:
            # 负载适中，适度放宽
            new_window_size = int(self.window_size_seconds * 1.1)
            new_max_requests = int(self.max_requests_per_window * 1.2)
        else:
            # 负载正常，保持不变
            return
        
        self.adjust_rate_limit(new_window_size, new_max_requests)
```

```python
from typing import Dict, Any, List, Optional
import time
from datetime import datetime

class RequestFeatureAnalyzer:
    """请求特征分析器"""
    
    def __init__(self):
        # 特征权重配置
        self.feature_weights = {
            "message_length": 0.2,
            "has_user_id": 0.3,
            "has_session_id": 0.2,
            "request_time": 0.1,
            "metadata_complexity": 0.2
        }
        
        # 特征统计
        self.stats = {
            "total_requests": 0,
            "feature_distribution": {},
            "request_type_distribution": {}
        }
    
    def analyze(self, request: Dict[str, Any]) -> Dict[str, Any]:
        """分析请求特征"""
        features = {}
        
        # 消息长度特征（归一化到0-1）
        message = str(request.get("message", ""))
        features["message_length"] = min(len(message) / 1000.0, 1.0)  # 假设最大1000字符
        
        # 用户ID特征
        features["has_user_id"] = 1.0 if request.get("user_id") else 0.0
        
        # 会话ID特征
        features["has_session_id"] = 1.0 if request.get("session_id") else 0.0
        
        # 请求时间特征（转换为一天中的小时，归一化）
        timestamp = request.get("timestamp", time.time())
        request_time = datetime.fromtimestamp(timestamp)
        features["request_time"] = request_time.hour / 24.0
        
        # 元数据复杂度特征（基于元数据大小）
        metadata = request.get("metadata", {})
        features["metadata_complexity"] = min(len(str(metadata)) / 5000.0, 1.0)  # 假设最大5000字符
        
        # 计算总体复杂度分数
        complexity_score = 0.0
        for feature_name, weight in self.feature_weights.items():
            if feature_name in features:
                complexity_score += features[feature_name] * weight
        
        features["complexity_score"] = complexity_score
        
        # 请求类型分类
        if complexity_score > 0.7:
            request_type = "complex"
        elif complexity_score > 0.4:
            request_type = "medium"
        else:
            request_type = "simple"
        
        features["request_type"] = request_type
        
        # 时间特征分类
        hour = request_time.hour
        if 9 <= hour <= 17:  # 工作时间
            time_feature = "peak_hours"
        elif 18 <= hour <= 22:  # 晚上
            time_feature = "evening"
        elif 23 <= hour or hour <= 5:  # 深夜
            time_feature = "off_peak"
        else:  # 早晨
            time_feature = "morning"
        
        features["time_feature"] = time_feature
        
        # 用户类型分类（基于元数据）
        user_role = request.get("metadata", {}).get("user_role", "regular")
        features["user_role"] = user_role
        
        # 更新统计
        self._update_stats(features)
        
        return features
    
    def _update_stats(self, features: Dict[str, Any]) -> None:
        """更新特征统计"""
        self.stats["total_requests"] += 1
        
        # 更新请求类型分布
        request_type = features.get("request_type", "unknown")
        self.stats["request_type_distribution"][request_type] = \
            self.stats["request_type_distribution"].get(request_type, 0) + 1
        
        # 更新特征值分布（简化版）
        for feature_name, feature_value in features.items():
            if isinstance(feature_value, (int, float)):
                if feature_name not in self.stats["feature_distribution"]:
                    self.stats["feature_distribution"][feature_name] = {
                        "sum": 0.0,
                        "count": 0,
                        "min": float('inf'),
                        "max": float('-inf')
                    }
                
                dist = self.stats["feature_distribution"][feature_name]
                dist["sum"] += feature_value
                dist["count"] += 1
                dist["min"] = min(dist["min"], feature_value)
                dist["max"] = max(dist["max"], feature_value)
    
    def get_stats(self) -> Dict[str, Any]:
        """获取统计信息"""
        stats = self.stats.copy()
        
        # 计算平均值
        for feature_name, dist in stats["feature_distribution"].items():
            if dist["count"] > 0:
                dist["average"] = dist["sum"] / dist["count"]
        
        # 计算百分比
        total = stats["total_requests"]
        if total > 0:
            for request_type, count in stats["request_type_distribution"].items():
                stats["request_type_distribution"][request_type] = {
                    "count": count,
                    "percentage": count / total * 100
                }
        
        return stats
    
    def adjust_weights(self, performance_data: Dict[str, Any]) -> None:
        """根据性能数据调整特征权重"""
        # 简化的权重调整算法
        # 实际系统可以使用机器学习算法
        
        # 如果复杂请求处理时间过长，增加复杂度权重
        if performance_data.get("complex_avg_time", 0) > performance_data.get("simple_avg_time", 0) * 3:
            # 增加复杂度相关特征的权重
            self.feature_weights["message_length"] = min(self.feature_weights["message_length"] * 1.1, 0.4)
            self.feature_weights["metadata_complexity"] = min(self.feature_weights["metadata_complexity"] * 1.1, 0.4)
            
            # 减少其他特征权重以保持总和为1
            total = sum(self.feature_weights.values())
            if total > 1.0:
                scale = 1.0 / total
                for key in self.feature_weights:
                    self.feature_weights[key] *= scale

class DynamicMiddlewareScheduler:
    """动态中间件调度器"""
    
    def __init__(self, feature_analyzer: RequestFeatureAnalyzer):
        self.feature_analyzer = feature_analyzer
        self.scheduling_strategies = {
            "simple": self._simple_request_strategy,
            "medium": self._medium_request_strategy,
            "complex": self._complex_request_strategy,
            "peak_hours": self._peak_hours_strategy,
            "off_peak": self._off_peak_strategy,
            "vip_user": self._vip_user_strategy,
            "regular_user": self._regular_user_strategy
        }
        
        # 调度统计
        self.stats = {
            "total_schedules": 0,
            "strategy_usage": {},
            "performance_impact": {}
        }
    
    def _simple_request_strategy(self, middlewares: List[AgentMiddleware]) -> List[AgentMiddleware]:
        """简单请求调度策略"""
        scheduled = []
        
        for mw in middlewares:
            # 创建中间件副本（避免修改原始对象）
            mw_copy = self._create_middleware_copy(mw)
            
            # 简单请求：禁用部分中间件以提高性能
            if mw_copy.name in ["cache_middleware", "rate_limit_middleware", "detailed_logging_middleware"]:
                mw_copy.enabled = False
            
            # 降低验证中间件优先级
            if mw_copy.name == "validation_middleware":
                mw_copy.priority = 15  # 降低优先级
            
            scheduled.append(mw_copy)
        
        return scheduled
    
    def _medium_request_strategy(self, middlewares: List[AgentMiddleware]) -> List[AgentMiddleware]:
        """中等复杂度请求调度策略"""
        scheduled = []
        
        for mw in middlewares:
            mw_copy = self._create_middleware_copy(mw)
            
            # 中等请求：启用所有中间件，保持默认配置
            # 可能调整一些参数
            if mw_copy.name == "rate_limit_middleware":
                # 中等限流
                pass
            
            scheduled.append(mw_copy)
        
        return scheduled
    
    def _complex_request_strategy(self, middlewares: List[AgentMiddleware]) -> List[AgentMiddleware]:
        """复杂请求调度策略"""
        scheduled = []
        
        for mw in middlewares:
            mw_copy = self._create_middleware_copy(mw)
            
            # 复杂请求：启用所有中间件，提高安全性和验证优先级
            if mw_copy.name == "authentication_middleware":
                mw_copy.priority = 0  # 最高优先级
            elif mw_copy.name == "validation_middleware":
                mw_copy.priority = 1  # 次高优先级
            elif mw_copy.name == "rate_limit_middleware":
                mw_copy.priority = 2  # 提高限流优先级
            elif mw_copy.name == "detailed_logging_middleware":
                mw_copy.enabled = True  # 启用详细日志
            
            scheduled.append(mw_copy)
        
        return scheduled
    
    def _peak_hours_strategy(self, middlewares: List[AgentMiddleware]) -> List[AgentMiddleware]:
        """高峰期调度策略"""
        scheduled = []
        
        for mw in middlewares:
            mw_copy = self._create_middleware_copy(mw)
            
            # 高峰期：启用严格限流，提高性能监控
            if mw_copy.name == "rate_limit_middleware":
                mw_copy.enabled = True
                mw_copy.priority = 1  # 提高优先级
                # 实际系统中这里可以调整限流参数
            elif mw_copy.name == "performance_monitoring_middleware":
                mw_copy.enabled = True  # 启用性能监控
            elif mw_copy.name == "cache_middleware":
                mw_copy.enabled = True  # 启用缓存减轻负载
            
            scheduled.append(mw_copy)
        
        return scheduled
    
    def _off_peak_strategy(self, middlewares: List[AgentMiddleware]) -> List[AgentMiddleware]:
        """低峰期调度策略"""
        scheduled = []
        
        for mw in middlewares:
            mw_copy = self._create_middleware_copy(mw)
            
            # 低峰期：禁用限流，减少监控，提高响应速度
            if mw_copy.name == "rate_limit_middleware":
                mw_copy.enabled = False  # 禁用限流
            elif mw_copy.name == "detailed_logging_middleware":
                mw_copy.enabled = False  # 禁用详细日志
            elif mw_copy.name == "performance_monitoring_middleware":
                mw_copy.enabled = False  # 禁用性能监控
            
            scheduled.append(mw_copy)
        
        return scheduled
    
    def _vip_user_strategy(self, middlewares: List[AgentMiddleware]) -> List[AgentMiddleware]:
        """VIP用户调度策略"""
        scheduled = []
        
        for mw in middlewares:
            mw_copy = self._create_middleware_copy(mw)
            
            # VIP用户：放宽限流，提高优先级，启用高级功能
            if mw_copy.name == "rate_limit_middleware":
                # 放宽限流阈值（实际系统中需要调整参数）
                pass
            elif mw_copy.name == "cache_middleware":
                mw_copy.enabled = True  # 启用缓存
                mw_copy.priority = 3  # 提高缓存优先级
            elif mw_copy.name == "premium_features_middleware":
                mw_copy.enabled = True  # 启用高级功能
            
            scheduled.append(mw_copy)
        
        return scheduled
    
    def _regular_user_strategy(self, middlewares: List[AgentMiddleware]) -> List[AgentMiddleware]:
        """普通用户调度策略"""
        # 使用默认策略
        return self._medium_request_strategy(middlewares)
    
    def _create_middleware_copy(self, middleware: AgentMiddleware) -> AgentMiddleware:
        """创建中间件副本（避免修改原始对象）"""
        # 这里简化实现，实际系统需要深度复制
        mw_copy = type(middleware).__new__(type(middleware))
        mw_copy.__dict__ = middleware.__dict__.copy()
        return mw_copy
    
    def schedule_middlewares(self, request: Dict[str, Any], middlewares: List[AgentMiddleware]) -> List[AgentMiddleware]:
        """根据请求特征调度中间件"""
        # 分析请求特征
        features = self.feature_analyzer.analyze(request)
        
        # 确定主要调度策略
        request_type = features.get("request_type", "medium")
        time_feature = features.get("time_feature", "off_peak")
        user_role = features.get("user_role", "regular")
        
        # 应用调度策略
        scheduled = middlewares.copy()
        
        # 1. 首先应用时间策略
        if time_feature in self.scheduling_strategies:
            scheduled = self.scheduling_strategies[time_feature](scheduled)
        
        # 2. 应用请求类型策略
        if request_type in self.scheduling_strategies:
            scheduled = self.scheduling_strategies[request_type](scheduled)
        
        # 3. 应用用户角色策略
        if user_role == "vip" and "vip_user" in self.scheduling_strategies:
            scheduled = self.scheduling_strategies["vip_user"](scheduled)
        elif user_role == "regular" and "regular_user" in self.scheduling_strategies:
            scheduled = self.scheduling_strategies["regular_user"](scheduled)
        
        # 更新统计
        self._update_stats(request_type, time_feature, user_role)
        
        return scheduled
    
    def _update_stats(self, request_type: str, time_feature: str, user_role: str) -> None:
        """更新调度统计"""
        self.stats["total_schedules"] += 1
        
        # 更新策略使用统计
        key = f"{request_type}_{time_feature}_{user_role}"
        self.stats["strategy_usage"][key] = self.stats["strategy_usage"].get(key, 0) + 1
    
    def get_scheduling_stats(self) -> Dict[str, Any]:
        """获取调度统计信息"""
        stats = self.stats.copy()
        
        # 添加特征分析器统计
        stats["feature_analyzer_stats"] = self.feature_analyzer.get_stats()
        
        # 计算策略使用百分比
        total = stats["total_schedules"]
        if total > 0:
            for key, count in stats["strategy_usage"].items():
                stats["strategy_usage"][key] = {
                    "count": count,
                    "percentage": count / total * 100
                }
        
        return stats
    
    def optimize_strategies(self, performance_data: Dict[str, Any]) -> None:
```

**容错设计**:
1. **故障检测**: 心跳检测、超时机制、健康检查
2. **重试机制**: 指数退避、熔断器、限流
3. **降级策略**: 功能降级、优雅降级、服务降级
4. **备份恢复**: 数据备份、快照、灾难恢复
