# 学习助手ThreadState扩展设计文档

## 1. 业务需求分析
- **REQ-001**: 跟踪学习主题
  - 理由: 了解用户正在学习的内容，提供针对性教学
  - 状态含义: 需要存储当前学习主题
- **REQ-002**: 累计学习时长
  - 理由: 评估学习投入程度，调整学习计划
  - 状态含义: 需要累加学习时间
- **REQ-003**: 评估掌握程度
  - 理由: 了解学习效果，调整教学策略
  - 状态含义: 需要记录掌握程度分数
- **REQ-004**: 管理复习计划
  - 理由: 安排定期复习，避免遗忘
  - 状态含义: 需要存储复习计划列表

## 2. 状态字段设计
- **learning_topic** (str)
  - 来源需求: 跟踪学习主题
  - 默认值: 
  - 更新策略: latest
  - 描述: 当前学习主题
- **study_duration** (int)
  - 来源需求: 累计学习时长
  - 默认值: 0
  - 更新策略: accumulate
  - 描述: 累计学习时长（分钟）
- **mastery_level** (int)
  - 来源需求: 评估掌握程度
  - 默认值: 0
  - 更新策略: latest_with_range
  - 描述: 掌握程度（0-100）
- **review_schedule** (List[StudyRecord])
  - 来源需求: 管理复习计划
  - 默认值: []
  - 更新策略: list_merge
  - 描述: 复习计划列表
