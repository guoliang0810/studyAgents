## 📁 演示代码结构

### 主要文件
- `title_middleware_demo.py`: 完整的标题生成中间件实现和演示代码

### 代码结构概述
本演示代码采用四部分结构设计，全面展示标题生成中间件的各个方面：

1. **第一部分：标题生成基础与数据结构** - 展示标题生成策略(TitleGenerationStrategy)、意图类型(IntentType)、标题生成配置(TitleGenerationConfig)、生成的标题数据结构(GeneratedTitle)、Agent请求/响应类(AgentRequest/AgentResponse)
2. **第二部分：核心标题中间件实现** - 实现KeywordExtractor关键词提取器、IntentDetector意图检测器、BaseTitleGenerator基础标题生成器、TitleMiddleware核心中间件，包含标题生成、存储、编辑等核心功能
3. **第三部分：高级标题生成策略** - 实现AdvancedTitleGenerator高级标题生成器（支持对话历史分析、工具调用识别）、TitleQualityEvaluator标题质量评估器（多维度质量评估）
4. **第四部分：完整测试系统与演示** - 实现TitleMiddlewareTestSystem测试系统，包含基础功能测试、高级对话分析测试、性能测试、集成演示，提供完整的教学演示

## 🔧 技术要点

### 核心概念
1. **标题生成策略**: 六大策略（意图+关键词、消息截取、关键词组合、模板填充、对话分析、基于工具调用）及其选择逻辑
2. **意图识别体系**: 12种意图类型（搜索、创建、删除、修改、分析、询问、对话、请求、翻译、计算、安排、提醒）及其关键词映射
3. **关键词提取技术**: 停用词过滤、简单分词、关键词排序、缓存机制
4. **标题质量评估**: 五维度评估体系（简洁性、信息量、可读性、相关性、格式规范性）
5. **高级标题生成**: 对话历史分析、工具调用识别、多标题选择策略

### 关键技术
- 多语言支持：中英文停用词表和分词处理
- 意图置信度计算：基于关键词匹配的加权评分
- 标题长度控制：动态调整和截断策略
- 对话历史分析：多轮对话的语义聚合
- 工具调用识别：基于工具使用模式的标题生成
- 质量评估算法：多维度加权评分体系
- 缓存优化：避免重复计算的性能优化

## 💡 教学建议

### 课堂演示要点
1. **从问题引入**: 展示无标题对话系统（难以查找历史对话）vs 有标题对话系统（快速定位和组织）
2. **逐步构建**: 从简单的关键词提取开始，逐步构建完整的标题生成中间件
3. **策略对比**: 演示不同标题生成策略的效果差异（意图+关键词 vs 消息截取 vs 关键词组合）
4. **质量评估展示**: 展示标题质量评估的多维度分析，理解优质标题的特征
5. **高级功能演示**: 展示对话历史分析和工具调用识别的实际效果

### 学生常见问题
1. **策略选择**: 如何自动选择最合适的标题生成策略？有没有通用的选择规则？
2. **意图识别准确性**: 基于关键词的意图识别在复杂场景下如何提高准确性？
3. **中文分词**: 简单的中文分词方法有哪些局限性？专业分词工具（如jieba）如何集成？
4. **质量评估主观性**: 标题质量评估标准是否过于主观？如何建立客观的评估体系？
5. **性能优化**: 标题生成在实时系统中的性能要求是什么？如何进行优化？

### 拓展思考
1. **机器学习应用**: 如何使用机器学习提高意图识别和标题生成的准确性？
2. **个性化标题**: 如何根据用户偏好和历史行为生成个性化标题？
3. **多模态标题**: 在包含图像、文件等多模态内容的对话中，如何生成标题？
4. **A/B测试优化**: 如何通过A/B测试优化标题生成策略，提升用户满意度？
5. **标题编辑协作**: 如何设计用户与AI协作编辑标题的交互机制？
6. **标题搜索优化**: 如何优化标题以便更好地支持对话搜索功能？
7. **跨语言标题**: 在多语言对话系统中，如何生成跨语言一致的标题？

### 技能掌握标准

- **中级掌握**: 能够实现功能完整的TitleMiddleware，理解策略选择逻辑
- **高级掌握**: 能够设计支持高级功能的标题生成系统（对话历史分析、质量评估、个性化生成）

### 项目应用评估
1. **集成能力**: 能否将标题生成中间件集成到现有对话系统中
2. **标题质量**: 生成的标题是否简洁、准确、有代表性
3. **用户体验**: 标题生成是否提升了对话查找和管理的便利性
4. **系统性能**: 标题生成是否对系统响应时间有明显影响
5. **可维护性**: 标题生成系统是否易于配置、监控和优化
