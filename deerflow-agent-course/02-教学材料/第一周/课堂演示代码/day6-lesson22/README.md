## 🔧 技术要点

### 核心概念
1. **四种限制维度**: 深度限制（防止无限递归）、并发限制（控制同时运行数量）、时间限制（防止执行超时）、资源限制（内存/CPU使用控制）
2. **子代理状态跟踪**: 实时跟踪子代理的创建、运行、完成状态，维护父子关系树
3. **线程安全设计**: 多线程环境下的并发控制，使用锁保护共享状态
4. **限制策略配置**: 通过YAML配置文件定义限制规则，支持白名单/黑名单工具管理
5. **防御性编程**: 优雅处理各种边界情况和异常场景，防止系统崩溃

### 关键技术
- **深度计算算法**: 基于父子关系的嵌套深度计算，防止深度攻击
- **并发计数器**: 线程安全的活跃子代理计数，支持超时等待
- **时间跟踪**: 精确测量子代理执行时间，支持超时中断
- **资源监控**: 集成psutil库监控系统资源使用（内存、CPU、线程等）
- **YAML配置解析**: 使用PyYAML库解析限制策略配置文件
- **自定义异常体系**: 针对不同限制维度的专用异常类型
- **统计信息收集**: 实时收集中间件运行统计，支持监控和调试

### 系统设计模式
1. **限制器模式**: 每种限制维度独立实现，通过组合形成完整限制系统
2. **中间件模式**: 在Agent执行流程中插入限制检查，保持架构清晰
3. **状态跟踪模式**: 集中管理子代理状态，提供全局视图
4. **策略模式**: 支持运行时动态更新限制策略
5. **观察者模式**: 实时监控子代理执行状态，触发限制检查
