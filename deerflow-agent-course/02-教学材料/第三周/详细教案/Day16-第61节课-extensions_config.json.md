# 🎓 详细教案模板 - 45分钟课堂

## 📋 课程基本信息
- **课程名称**: Day 16 - 第61节课：extensions_config.json
- **授课日期**: 第三周，第16天
- **上课时间**: 45分钟（建议安排在上午时段，学生思维清晰）
- **授课教师**: 张老师（10年AI系统架构经验，DeerFlow核心贡献者）
- **学生背景**: Python基础一般，已学习沙箱与技能配置，了解配置系统基本概念
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线，支持实时扩展配置演示

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. **扩展配置架构**: 理解扩展配置的多层结构设计，包括MCP服务器、监控系统、缓存系统等模块
2. **JSON配置格式**: 掌握JSON格式在扩展配置中的应用，理解其与YAML配置的差异和选择
3. **动态扩展加载**: 了解ExtensionLoader的设计原理和工作流程，理解动态导入和初始化的机制
4. **环境变量注入**: 理解配置中环境变量替换在扩展配置中的实现原理和应用场景

### 技能目标（学生将能够）
1. **设计扩展配置**: 能够设计合理的扩展配置JSON结构，支持多种扩展类型
2. **实现扩展加载器**: 能够实现ExtensionLoader类，支持动态扩展加载和初始化
3. **配置扩展模块**: 能够配置MCP服务器、监控系统、缓存系统等扩展模块
4. **管理扩展依赖**: 能够管理扩展间的依赖关系和启动顺序

### 情感/态度目标
1. **培养扩展思维**: 树立系统扩展性意识，理解扩展配置对系统灵活性的重要性
2. **增强模块思维**: 提高模块化设计能力，重视系统的可扩展性和可维护性
3. **树立标准意识**: 重视配置格式标准化，理解JSON在配置管理中的优势

## 📚 教学重点与难点
- **教学重点**: 
  1. 扩展配置的JSON结构设计和字段含义
  2. ExtensionLoader的动态加载和初始化实现
  3. 扩展模块的配置策略和管理方法

- **教学难点**: 
  1. 动态模块导入的路径解析和错误处理
  2. 扩展间依赖关系的解析和启动顺序控制
  3. 环境变量在JSON配置中的动态替换实现

- **突破方法**: 
  1. 使用流程图展示扩展加载的动态流程
  2. 提供逐步调试的模块导入示例
  3. 使用实际场景演示扩展配置的重要性
