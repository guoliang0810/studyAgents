# 🎓 详细教案 - Day 21 第84节课：边界测试

## 📋 课程基本信息
- **课程名称**: 边界测试与极限条件验证
- **授课日期**: 2024年4月14日（周日）
- **上课时间**: 下午12:00-12:45（第84节课）
- **授课教师**: 张老师（10年AI系统架构经验，DeerFlow核心贡献者）
- **学生背景**: Python基础一般，完成了Day 21前3节课学习，掌握了测试策略、夹具系统和Mock技术
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. **理解边界测试的核心概念**，包括边界值分析、等价类划分、极限条件验证
2. **掌握AI Agent系统的边界场景**，包括输入长度、并发请求、异常输入、性能极限
3. **了解安全边界测试的重要性**，包括注入防护、速率限制、错误恢复机制

### 技能目标（学生将能够）
1. **设计全面的边界测试套件**，覆盖输入、性能、安全、恢复等多个维度
2. **实现性能边界测试**，包括响应时间、内存使用、并发处理能力验证
3. **编写安全边界测试**，防护SQL注入、XSS攻击、路径遍历等安全威胁

### 情感/态度目标
1. **培养极限测试思维**，理解边界条件对系统稳定性的关键影响
2. **建立安全测试意识**，认识到安全边界测试是生产系统的必备保障
3. **增强工程严谨性**，通过掌握边界测试提升作为架构师的全面能力

## 📚 教学重点与难点
- **教学重点**: 
  1. 边界条件测试的设计模式和实现技巧
  2. 性能边界测试的指标设定和验证方法
  3. 安全边界测试的威胁模型和防护验证
  
- **教学难点**: 
  1. 并发测试的时序控制和结果验证
  2. 性能基准的合理设定和动态调整
  3. 安全测试的全面性和误报处理
  
- **突破方法**: 
  1. 使用asyncio.gather实现并发测试
  2. 通过基准测试建立性能标准
  3. 采用OWASP Top 10作为安全测试参考

## 🎭 师生互动设计

### 提问策略
1. **导入提问**: "小王，你遇到过系统在高并发下的表现问题吗？"（激活实际痛点）
2. **引导提问**: "为什么边界测试能发现正常测试无法发现的问题？"（引导思考深度）
3. **挑战提问**: "如果边界测试过于严格导致误报怎么办？"（激发问题解决思维）
4. **应用提问**: "在你的项目中，哪些边界场景最值得测试？"（促进知识迁移）

### 讨论活动
1. **小组讨论**: 3-4人小组，讨论不同边界测试的优先级策略（10分钟）
2. **头脑风暴**: 集体创意，设计智能边界测试生成算法（5分钟）
3. **案例分析**: 分析边界测试失败的典型案例，学习教训（8分钟）
4. **代码审查**: 互相review边界测试实现，验证全面性（7分钟）

### 反馈机制
1. **即时反馈**: 课堂问答，及时纠正理解偏差
2. **过程反馈**: 练习指导，持续改进测试设计
3. **成果反馈**: 作业批改，总结提升边界测试能力
4. **同伴反馈**: 学生互评测试设计，互相学习最佳实践

## 📊 评估方式

### 形成性评估（课堂内）
1. **观察评估**: 观察学生参与讨论的积极性和思考深度
2. **提问评估**: 通过提问检验边界测试概念理解程度
3. **练习评估**: 检查边界测试设计的全面性和合理性
4. **自评互评**: 学生自我评估设计质量，互相评价方案优劣

### 总结性评估（课堂后）
1. **作业评估**: 批改内存系统边界测试作业，评分反馈
2. **测验评估**: 单元测验检验边界测试知识点掌握
3. **项目评估**: 在周项目中评估边界测试设计质量和使用效果
4. **综合评估**: 结合课堂表现、作业质量、项目贡献综合评价

### 评估标准
- **优秀（90-100分）**: 全面掌握边界测试原理，能设计复杂系统的完整边界测试架构
- **良好（80-89分）**: 基本掌握边界测试概念，能实现合理的边界测试套件
- **合格（60-79分）**: 理解核心概念，需要指导完成边界测试设计
- **需改进（<60分）**: 需要重新学习边界测试基础和极限场景概念

## 📝 教学反思

### 成功之处
1. **实用导向**: 边界测试示例贴近实际生产问题
2. **渐进设计**: 从输入边界到安全边界的示例合理

## 任务描述
为文件上传服务设计完整的边界测试套件，服务接口规范如下：

4. 异常输入边界：超大文件、恶意文件、畸形元数据

## 要求
- [ ] 实现完整的边界测试类

import asyncio

import pytest


class BoundaryTests:
    """边界条件测试套件"""
    
    @pytest.mark.parametrize("prompt_length", [1, 10, 100, 1000, 10000])
    async def test_prompt_length_boundaries(self, deerflow_app, prompt_length):
        """测试不同长度的提示"""
        prompt = "A" * prompt_length
        
        try:
            response = await deerflow_app.process(prompt)
            assert response is not None
            assert len(response) > 0
        except Exception as e:
            # 允许超长提示失败，但要有合理的错误
            if prompt_length > 8000:
                assert "too long" in str(e).lower() or "exceed" in str(e).lower()
            else:
                raise
    
    @pytest.mark.parametrize("concurrent_requests", [1, 10, 50, 100])
    async def test_concurrency_boundaries(self, deerflow_app, concurrent_requests):
        """测试并发请求"""
        import asyncio
        
        async def make_request(i):
            response = await deerflow_app.process(f"Request {i}")
            return response
        
        # 并发发送请求
        tasks = [make_request(i) for i in range(concurrent_requests)]
        results = await asyncio.gather(*tasks, return_exceptions=True)
        
        # 统计成功和失败
        successes = [r for r in results if not isinstance(r, Exception)]
        failures = [r for r in results if isinstance(r, Exception)]
        
        # 允许少量失败（由于资源限制）
        success_rate = len(successes) / concurrent_requests
        assert success_rate > 0.9, f"Success rate too low: {success_rate}"
    
    @pytest.mark.parametrize("invalid_input", [
        None,
        "",
        " " * 100,
        "<script>alert('xss')</script>",
        "../../etc/passwd",
        "A" * 1000000,  # 非常大的输入
    ])
    async def test_invalid_input_handling(self, deerflow_app, invalid_input):
        """测试无效输入处理"""
        try:
            response = await deerflow_app.process(invalid_input)
            
            # 如果成功处理，验证输出是安全的
            if response:
                # 检查没有脚本标签
                assert "<script>" not in response.lower()
                # 检查没有路径遍历
                assert "../" not in response
        except Exception as e:
            # 无效输入应该抛出异常
            assert isinstance(e, (ValueError, ValidationError))

            "1' OR '1'='1",

            "test; rm -rf /",
            "$(cat /etc/passwd)",

            "..\\..\\windows\\system32\\config",
            
            # XSS
            "<script>alert('xss')</script>",
            "<img src=x onerror=alert(1)>",
            
            # JSON注入
            '{"__proto__": {"isAdmin": true}}',
            '{"constructor": {"prototype": {"isAdmin": true}}}',
        ]
        
        for attempt in injection_attempts:
            try:
                response = await deerflow_app.process(attempt)
                
                # 验证响应是安全的
                self.assert_safe_response(response)
                
            except SecurityError:
                # 预期会抛出安全错误
                pass

        # 检查没有脚本标签
        assert "<script>" not in response.lower()
        
        # 检查没有危险命令
        dangerous_patterns = ["rm -rf", "format", "shutdown", "reboot"]
        for pattern in dangerous_patterns:
            assert pattern not in response.lower()
        
        # 检查没有路径遍历
        assert "../" not in response
        assert "..\\" not in response
    
    async def test_rate_limiting_boundaries(self, deerflow_app):

            start_time = time.time()

            for i in range(rps):
                task = asyncio.create_task(
                    deerflow_app.process(f"Request {i}")
                )
                tasks.append(task)
            
            # 等待所有请求完成
            results = await asyncio.gather(*tasks, return_exceptions=True)
            
            elapsed = time.time() - start_time
            
            for result in results:
                if isinstance(result, RateLimitError):
                    rate_limited += 1
                elif isinstance(result, Exception):
                    # 其他错误
                    pass
                else:
                    successful += 1
            
            # 验证速率限制行为
            if rps > 100:  # 假设限制是100 RPS

                rate_limit_ratio = rate_limited / rps
                assert 0.1 < rate_limit_ratio < 0.9, f"Rate limiting ratio abnormal: {rate_limit_ratio}"
