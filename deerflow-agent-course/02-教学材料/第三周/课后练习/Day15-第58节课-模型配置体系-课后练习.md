### 练习1：模型配置类实现

**目标**：实现完整的模型配置类，支持序列化和反序列化。

**要求**：
1. 创建 `ModelConfig` 类，包含以下字段：
   - `provider` (str): 提供者名称
   - `model_name` (str): 模型名称
   - `api_key` (Optional[str]): API密钥
   - `base_url` (Optional[str]): 基础URL
   - `timeout` (float): 请求超时时间
   - `max_retries` (int): 最大重试次数
   - `temperature` (float): 温度参数
   - `max_tokens` (Optional[int]): 最大输出token数
   - `capabilities` (Set[str]): 能力标签集合
   - `cost_config` (Dict[str, Any]): 成本配置

2. 实现以下方法：
   - `to_dict()`: 将配置转换为字典
   - `from_dict(data)`: 从字典创建配置
   - `has_capability(capability)`: 检查是否支持特定能力
   - `matches_capabilities(required_capabilities)`: 检查是否满足所有必需能力
   - `estimate_cost(input_tokens, output_tokens)`: 估算成本

3. 添加验证逻辑：
   - 必需字段验证（provider, model_name）
   - 数值范围验证（timeout > 0, temperature 0-2, max_retries >= 0）
   - 能力标签格式验证

**测试用例**：
```python
def test_model_config():
    # 创建配置
    config = ModelConfig(
        provider="openai",
        model_name="gpt-4",
        timeout=30.0,
        capabilities={"text_generation", "code_generation"}
    )
    
    # 测试序列化
    config_dict = config.to_dict()
    assert config_dict["provider"] == "openai"
    
    # 测试反序列化
    config2 = ModelConfig.from_dict(config_dict)
    assert config2.model_name == "gpt-4"
    
    # 测试能力检查
    assert config.has_capability("text_generation") == True
    assert config.has_capability("image_generation") == False
    
    # 测试能力匹配
    assert config.matches_capabilities({"text_generation"}) == True
    assert config.matches_capabilities({"image_generation"}) == False
    
    print("所有测试通过")
```

### 练习2：能力标签系统

**目标**：实现标准化的能力标签系统。

**要求**：
1. 创建 `ModelCapability` 枚举，包含以下能力标签：
   - 文本相关：TEXT_GENERATION, CODE_GENERATION, TRANSLATION, SUMMARIZATION
   - 视觉相关：IMAGE_GENERATION, IMAGE_UNDERSTANDING
   - 音频相关：AUDIO_GENERATION, AUDIO_TRANSCRIPTION
   - 质量相关：REASONING, MATH, HIGH_ACCURACY, LONG_CONTEXT, LOW_LATENCY, LOW_COST
   - 功能相关：CHAT, FUNCTION_CALLING

2. 实现能力标签工具类：
   - `capability_from_string(name)`: 从字符串转换
   - `get_capability_group(capability)`: 获取能力所属分组
   - `get_related_capabilities(capability)`: 获取相关能力
   - `capabilities_to_string(capabilities)`: 能力集合转字符串

3. 实现能力匹配算法：
   - 精确匹配：所有必需能力都必须满足
   - 相似匹配：允许使用具有相似能力的不同模型
   - 降级匹配：当没有完全匹配时，选择满足部分核心能力的模型

**测试用例**：
```python
def test_capability_system():
    # 测试枚举
    cap = ModelCapability.from_string("TEXT_GENERATION")
    assert cap == ModelCapability.TEXT_GENERATION
    
    # 测试分组
    group = get_capability_group(ModelCapability.TEXT_GENERATION)
    assert group == "text"
    
    # 测试相关能力
    related = get_related_capabilities(ModelCapability.CODE_GENERATION)
    assert ModelCapability.TEXT_GENERATION in related
    
    # 测试能力匹配
    model_caps = {ModelCapability.TEXT_GENERATION, ModelCapability.CODE_GENERATION}
    required = {ModelCapability.TEXT_GENERATION}
    assert matches_capabilities(model_caps, required, strict=True) == True
    
    print("能力标签系统测试通过")
```

   - 批量操作支持

**实现提示**：
```python
class ModelRegistry:
    def __init__(self):
        self.models = {}  # model_id -> ModelConfig
        self.capability_index = {}  # capability -> [model_id]
        self.provider_index = {}  # provider -> [model_id]
    
    def register(self, model_id, config):
        # 注册模型
        self.models[model_id] = config
        
        # 更新索引
        for capability in config.capabilities:
            if capability not in self.capability_index:
                self.capability_index[capability] = []
            self.capability_index[capability].append(model_id)
        
        # 更新提供者索引
        if config.provider not in self.provider_index:
            self.provider_index[config.provider] = []
        self.provider_index[config.provider].append(model_id)
    
    def find_by_capabilities(self, required_capabilities):
        # 使用倒排索引快速查找
        candidate_models = set()
        for capability in required_capabilities:
            if capability in self.capability_index:
                if not candidate_models:
                    candidate_models = set(self.capability_index[capability])
                else:
                    candidate_models.intersection_update(self.capability_index[capability])
        
        results = []
        for model_id in candidate_models:
            config = self.models[model_id]
            if config.matches_capabilities(required_capabilities):
                results.append((model_id, config))
        
        return results
```

```python
class ModelFactory:
    def __init__(self):
        self.providers = {}
        self.model_cache = {}  # 模型实例缓存
        self.provider_health = {}  # 提供者健康状态
    
    def create_model(self, config, use_cache=True):
        provider_name = config.provider
        
        # 检查提供者健康状态
        if not self._is_provider_healthy(provider_name):
            raise ModelCreationError(f"提供者 {provider_name} 不健康")
        
        # 检查缓存
        cache_key = f"{provider_name}:{config.model_name}"
        if use_cache and cache_key in self.model_cache:
            return self.model_cache[cache_key]
        
        # 创建新实例
        provider = self.providers.get(provider_name)
        if not provider:
            raise ModelCreationError(f"未知提供者: {provider_name}")
        
        try:
            model = provider.create_model(config)
            
            # 缓存实例
            if use_cache:
                self.model_cache[cache_key] = model
            
            return model
        except Exception as e:
            # 记录提供者错误
            self._record_provider_error(provider_name)
            raise ModelCreationError(f"创建模型失败: {str(e)}")
    
    def create_model_by_capabilities(self, registry, required_capabilities, **constraints):
        # 查找候选模型
        candidates = registry.find_by_capabilities(required_capabilities)
        
        if not candidates:
            raise ModelCreationError("未找到满足能力要求的模型")
        
        # 应用约束（成本、延迟、提供者偏好等）
        filtered = self._apply_constraints(candidates, constraints)
        
        if not filtered:
            raise ModelCreationError("未找到满足约束的模型")
        
        # 选择最佳模型
        best_model_id, best_config = self._select_best_model(filtered, constraints)
        
        # 创建模型实例
        return self.create_model(best_config)
```

2. **延迟加载**：按需加载配置，减少启动时间
3. **索引优化**：为常用查找字段建立索引（能力标签、提供者）

### 工厂系统优化
1. **连接池**：复用模型连接，减少建立连接开销
2. **实例缓存**：缓存模型实例，避免重复创建
3. **异步创建**：支持异步模型创建，提高并发性能
4. **健康检查**：定期检查提供者健康状态，快速失败

1. **内存优化**：使用共享内存或内存映射文件存储大量配置
2. **查询优化**：使用倒排索引加速能力标签查找
3. **持久化优化**：增量保存配置变更，减少IO
4. **并发控制**：支持并发访问，使用读写锁优化

## 🚨 常见错误和调试

### 配置相关错误
1. **配置解析失败**
   - 检查YAML/JSON格式
   - 验证必需字段是否存在
   - 检查字段类型是否正确

2. **配置验证失败**
   - 检查数值范围（timeout > 0, temperature 0-2）
   - 验证能力标签格式
   - 检查成本配置合理性

### 工厂相关错误
1. **模型创建失败**
   - 检查API密钥和网络连接
   - 验证提供者健康状态
   - 检查模型名称是否支持

2. **提供者注册失败**
   - 检查提供者类是否实现正确接口
   - 验证提供者名称唯一性
   - 检查提供者依赖是否正确安装

### 性能问题
1. **响应时间慢**
   - 检查网络延迟
   - 检查模型负载
   - 优化查询算法

2. **内存使用高**
   - 检查实例缓存大小
   - 优化配置存储
   - 使用延迟加载
