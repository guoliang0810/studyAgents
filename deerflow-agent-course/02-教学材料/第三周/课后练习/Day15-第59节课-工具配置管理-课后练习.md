### 练习1：工具配置类设计

**目标**：实现完整的工具配置类，支持所有工具类型和安全配置。

**要求**：
1. 创建 `ToolConfig` 类，包含以下字段：
   - `tool_id`：工具唯一标识（字符串，必填）
   - `tool_type`：工具类型（枚举：BUILTIN、CUSTOM、MCP、EXTERNAL、SCRIPT）
   - `name`：工具名称（字符串，必填）
   - `description`：工具描述（字符串，可选）
   - `version`：工具版本（字符串，默认"1.0.0"）
   - `author`：作者（字符串，可选）
   - `entry_point`：入口点（字符串，可选，对于内置工具）
   - `module_path`：模块路径（字符串，可选，对于自定义工具）
   - `class_name`：类名（字符串，可选，对于自定义工具）
   - `function_name`：函数名（字符串，可选，对于函数式工具）
   - `mcp_server_url`：MCP服务器URL（字符串，可选，对于MCP工具）
   - `command`：命令（字符串，可选，对于外部工具）
   - `script_content`：脚本内容（字符串，可选，对于脚本工具）
   - `environment_variables`：环境变量字典（Dict[str, str]，默认空字典）
   - `security_config`：安全配置（ToolSecurityConfig实例，必填）
   - `dependencies`：依赖项列表（List[ToolDependency]，默认空列表）
   - `metadata`：元数据字典（Dict[str, Any]，默认空字典）

2. 实现以下方法：
   - `to_dict()`：将配置转换为字典
   - `from_dict(data)`：从字典创建配置（类方法）
   - `validate()`：验证配置，返回错误列表
   - `resolve_environment_variables(env_vars)`：解析环境变量引用
   - `get_required_dependencies()`：获取必需的依赖工具ID列表

3. 环境变量解析支持以下格式：
   - `${VAR_NAME}`：引用环境变量
   - `${VAR_NAME:default_value}`：引用环境变量，如果未定义则使用默认值
   - 支持嵌套解析（环境变量值中可以包含其他环境变量引用）

**示例代码**：
```python
# 创建工具配置
config = ToolConfig(
    tool_id="python-interpreter",
    tool_type=ToolType.EXTERNAL,
    name="Python解释器",
    description="执行Python代码的外部工具",
    command="python ${SCRIPT_PATH:./script.py}",
    environment_variables={
        "PYTHONPATH": "${CUSTOM_PYTHON_PATH:/usr/local/lib/python3.12}",
        "API_KEY": "${OPENAI_API_KEY}"
    },
    security_config=security_config,
    dependencies=[
        ToolDependency(tool_id="file-reader", required=False)
    ]
)

# 解析环境变量
env_vars = {
    "OPENAI_API_KEY": "sk-test123",
    "SCRIPT_PATH": "/path/to/script.py"
}
resolved_config = config.resolve_environment_variables(env_vars)
print(f"解析后的命令: {resolved_config.command}")
print(f"解析后的环境变量: {resolved_config.environment_variables}")
```

### 练习2：安全配置类设计

**目标**：实现工具安全配置类，支持细粒度的安全策略。

**要求**：
1. 创建 `ToolSecurityConfig` 类，包含以下字段：
   - `security_level`：安全级别（枚举：TRUSTED、RESTRICTED、SANDBOXED、UNTRUSTED）
   - `allowed_commands`：允许的命令列表（List[str]，正则表达式模式）
   - `blocked_commands`：禁止的命令列表（List[str]，正则表达式模式）
   - `max_execution_time`：最大执行时间（float，秒，>0）
   - `max_memory_mb`：最大内存使用（int，MB，>0）
   - `network_access`：是否允许网络访问（bool）
   - `file_system_access`：是否允许文件系统访问（bool）
   - `environment_variables`：允许访问的环境变量列表（List[str]）
   - `allowed_network_hosts`：允许访问的网络主机列表（List[str]，可选）
   - `allowed_file_paths`：允许访问的文件路径列表（List[str]，可选）
   - `max_file_size_mb`：最大文件大小（int，MB，可选）
   - `max_process_count`：最大进程数（int，可选）

2. 实现以下方法：
   - `to_dict()`：将安全配置转换为字典
   - `from_dict(data)`：从字典创建安全配置（类方法）
   - `validate()`：验证安全配置，返回错误列表
   - `is_command_allowed(command)`：检查命令是否允许执行
   - `is_network_access_allowed(host)`：检查网络访问是否允许（如果支持）
   - `is_file_access_allowed(path)`：检查文件访问是否允许（如果支持）

3. 命令检查逻辑：
   - 首先检查是否在禁止列表中（如果匹配任何禁止模式，返回False）
   - 然后检查是否在允许列表中（如果允许列表为空，允许所有未禁止的命令）
   - 最后，根据安全级别进行额外检查

**示例代码**：
```python
# 创建安全配置
security_config = ToolSecurityConfig(
    security_level=SecurityLevel.RESTRICTED,
    allowed_commands=["^python$", "^echo.*$", "^curl\s+https://api\\.example\\.com"],
    blocked_commands=["^rm\s+", "^shutdown", "^dd\s+if="],
    max_execution_time=30.0,
    max_memory_mb=256,
    network_access=True,
    file_system_access=True,
    environment_variables=["PATH", "HOME", "TEMP"],
    allowed_network_hosts=["api.example.com", "download.example.com"],
    allowed_file_paths=["/tmp/", "/home/user/data/"],
    max_file_size_mb=10
)

# 命令检查
commands = ["python script.py", "rm -rf /", "curl https://api.example.com/data"]
for cmd in commands:
    allowed = security_config.is_command_allowed(cmd)
    print(f"{cmd}: {'允许' if allowed else '拒绝'}")

# 安全验证
errors = security_config.validate()
if errors:
    print(f"安全配置错误: {errors}")
else:
    print("安全配置有效")
```

```python
# 创建依赖配置
deps = [
    ToolDependency(tool_id="file-reader", version=">=1.0.0", required=True),
    ToolDependency(tool_id="logger", version="^2.0.0", required=False),

resolver = DependencyResolver()

# 检测循环依赖
```

```python
import asyncio

async def main():
    # 创建工具加载器
    loader = ToolLoader()
```

**要求**：

2. 实现以下具体工具类：

   - `CustomTool`：自定义工具，从模块导入类或函数
   - `MCPTool`：MCP工具，连接MCP服务器执行命令
   - `ExternalTool`：外部工具，执行外部命令
   - `ScriptTool`：脚本工具，在沙箱中执行脚本

3. 每种工具类型需要：
   - 正确的初始化逻辑
   - 安全的执行环境
   - 适当的资源清理
   - 错误处理和日志记录

**示例代码**：
```python
# 内置工具示例
class BuiltinTool(BaseTool):
    async def initialize(self):
        # 动态导入函数
        if self.config.function_name:
            module_path, func_name = self.config.entry_point.rsplit('.', 1)
            module = importlib.import_module(module_path)
            self.function = getattr(module, func_name)
        self.initialized = True
    
    async def execute(self, input_data):
        # 安全检查
        if not self.initialized:
            raise ToolNotInitializedError(self.tool_id)
        
        # 输入验证
        errors = self.validate_input(input_data)
        if errors:
            return {"error": f"输入验证失败: {errors}"}
        
        # 执行函数
        try:
            if asyncio.iscoroutinefunction(self.function):
                result = await self.function(**input_data)
            else:
                result = self.function(**input_data)
            
            self.record_usage()
            return {"success": True, "result": result}
        except Exception as e:
            logger.error(f"工具执行失败: {self.tool_id}, 错误: {e}")
            return {"error": f"执行失败: {str(e)}"}
    
    async def shutdown(self):
        self.function = None
        self.initialized = False

# 使用示例
async def use_builtin_tool():
    config = ToolConfig(
        tool_id="string-reverser",
        tool_type=ToolType.BUILTIN,
        name="字符串反转器",
        description="反转字符串的内置工具",
        entry_point="builtin_tools.string_ops.reverse_string"
    )
    
    tool = BuiltinTool(config)
    await tool.initialize()
    
    result = await tool.execute({"text": "Hello, World!"})
    print(f"反转结果: {result}")
    
    await tool.shutdown()
```

### 练习6：安全沙箱实现

**目标**：实现工具执行的沙箱环境，提供进程隔离和资源限制。

**要求**：
1. 创建 `Sandbox` 类，支持以下功能：
   - 进程隔离（使用subprocess或专用沙箱技术）
   - 资源限制（CPU、内存、磁盘、网络）
   - 文件系统隔离（chroot、namespaces）
   - 系统调用过滤（seccomp）
   - 环境变量过滤
   - 网络访问控制

2. 实现以下沙箱策略：
   - `TRUSTED`：无隔离，完全信任
   - `RESTRICTED`：轻度隔离，限制资源
   - `SANDBOXED`：完全隔离，严格限制
   - `UNTRUSTED`：禁止执行或超严格隔离

3. 集成到工具执行流程：
   - 根据安全级别选择沙箱策略
   - 在沙箱中执行外部工具和脚本工具
   - 收集执行结果和资源使用情况
   - 清理沙箱环境

**示例代码**：
```python
class Sandbox:
    def __init__(self, security_level: SecurityLevel):
        self.security_level = security_level
        self.isolation_method = self._select_isolation_method()
    
    async def execute(self, command: str, args: List[str], env: Dict[str, str]) -> Dict[str, Any]:
        """在沙箱中执行命令"""
        # 根据安全级别应用不同的隔离策略
        if self.security_level == SecurityLevel.SANDBOXED:
            return await self._execute_in_strict_sandbox(command, args, env)
        elif self.security_level == SecurityLevel.RESTRICTED:
            return await self._execute_in_restricted_sandbox(command, args, env)
        else:
            return await self._execute_without_sandbox(command, args, env)
    
    async def _execute_in_strict_sandbox(self, command, args, env):
        """在严格沙箱中执行"""
        # 使用Docker或Firejail创建完全隔离的环境
        sandbox_id = f"sandbox_{uuid.uuid4().hex[:8]}"
        
        # 创建临时目录
        temp_dir = tempfile.mkdtemp(prefix=f"sandbox_{sandbox_id}_")
        
        try:
            # 设置资源限制
            resource_limits = {
                "cpu_time": 30.0,
                "memory_mb": 100,
                "max_processes": 10,
                "max_files": 100
            }
            
            # 执行命令
            result = await self._run_in_container(
                command, args, env,
                temp_dir, resource_limits
            )
            
            return result
        finally:
            # 清理临时目录
            shutil.rmtree(temp_dir, ignore_errors=True)
```

   - 支持监控数据导出

**示例代码**：
```python
class ToolMonitor:
    def __init__(self, storage_backend="memory"):
        self.storage = self._create_storage(storage_backend)
        self.metrics = defaultdict(list)
    
    def record_execution(self, tool_id: str, start_time: float, 
                        end_time: float, success: bool, 
                        error: Optional[str] = None):
        """记录工具执行"""
        duration = end_time - start_time
        
        metric = {
            "tool_id": tool_id,
            "start_time": start_time,
            "end_time": end_time,
            "duration": duration,
            "success": success,
            "error": error,
            "timestamp": time.time()
        }
        
        self.metrics[tool_id].append(metric)
        
        # 存储到后端
        self.storage.store_metric(metric)
        
        # 检查异常
        if self._is_anomaly(tool_id, metric):
            self._trigger_alert(tool_id, metric)
    
    def get_tool_stats(self, tool_id: str, time_range: str = "24h") -> Dict[str, Any]:
        """获取工具统计信息"""
        metrics = self._get_metrics_in_range(tool_id, time_range)
        
        if not metrics:
            return {}
        
        durations = [m["duration"] for m in metrics if m["success"]]
        successes = [m for m in metrics if m["success"]]
        failures = [m for m in metrics if not m["success"]]
        
        return {
            "total_executions": len(metrics),
            "success_rate": len(successes) / len(metrics) if metrics else 0,
            "avg_duration": sum(durations) / len(durations) if durations else 0,
            "min_duration": min(durations) if durations else 0,
            "max_duration": max(durations) if durations else 0,
            "p95_duration": self._percentile(durations, 95) if durations else 0,
            "errors": [{"error": m["error"], "timestamp": m["timestamp"]} 
                      for m in failures[:10]],  # 最近10个错误
            "recent_executions": metrics[-10:]  # 最近10次执行
        }
    
    def generate_report(self, tool_ids: List[str], 
                       start_time: float, end_time: float) -> Dict[str, Any]:
        """生成性能报告"""
        report = {
            "period": {"start": start_time, "end": end_time},
            "tools": {},
            "summary": {}
        }
        
        for tool_id in tool_ids:
            tool_metrics = self._get_metrics_in_range(tool_id, start_time, end_time)
            report["tools"][tool_id] = self.get_tool_stats_from_metrics(tool_metrics)
        
        # 计算总体统计
        report["summary"] = self._calculate_summary(report["tools"])
        
        return report
```

**示例代码**：
```python
class DynamicToolLoader(ToolLoader):
    def __init__(self):
        super().__init__()
        self.tool_repository = ToolRepository()
        self.running_tools = {}  # 正在运行的工具实例
        self.tool_versions = {}  # 工具版本映射
    
    async def load_tool_from_repository(self, tool_id: str, version: str = "latest"):
        """从仓库加载工具"""
        # 获取工具元数据
        tool_meta = await self.tool_repository.get_tool_metadata(tool_id, version)
        
        # 验证工具签名
        if not await self._verify_tool_signature(tool_meta):
            raise ToolSecurityError(f"工具签名验证失败: {tool_id}")
        
        # 下载工具包
        tool_package = await self.tool_repository.download_tool(tool_id, version)
        
        # 安装工具依赖
        await self._install_dependencies(tool_package.dependencies)
        
        # 加载工具配置
        config = await self._load_tool_config(tool_package)
        
        # 创建工具实例
        tool = await self._create_tool_instance(config)
        
        # 如果已有旧版本运行，准备热升级
        if tool_id in self.running_tools:
            await self._prepare_hot_upgrade(tool_id, tool)
        
        # 初始化新工具
        await tool.initialize()
        
        # 切换到新版本
        self.tools[tool_id] = tool
        self.running_tools[tool_id] = tool
        self.tool_versions[tool_id] = version
        
        return tool
    
    async def hot_upgrade_tool(self, tool_id: str, new_version: str):
        """热升级工具"""
        old_tool = self.running_tools.get(tool_id)
        if not old_tool:
            raise ToolNotFoundError(tool_id)
        
        # 1. 加载新版本工具
        new_tool = await self.load_tool_from_repository(tool_id, new_version)
        
        # 2. 转移状态（如果支持）
        if hasattr(old_tool, 'get_state') and hasattr(new_tool, 'set_state'):
            state = await old_tool.get_state()
            await new_tool.set_state(state)
        
        # 3. 切换路由到新工具
        self.tools[tool_id] = new_tool
        
        # 4. 等待旧工具完成当前执行
        await self._wait_for_tool_idle(old_tool)
        
        # 5. 关闭旧工具
        await old_tool.shutdown()
        
        # 6. 更新运行记录
        self.running_tools[tool_id] = new_tool
        
        logger.info(f"工具热升级完成: {tool_id} {self.tool_versions[tool_id]} -> {new_version}")
```

```python
class ToolFederationSystem:
    def __init__(self, federation_nodes: List[str]):
        self.nodes = federation_nodes
        self.local_knowledge = KnowledgeBase()
        self.federation_client = FederationClient()
    
    async def record_tool_experience(self, tool_id: str, 
                                   input_data: Dict[str, Any],
                                   result: Dict[str, Any],
                                   execution_context: Dict[str, Any]):
        """记录工具执行经验"""
        experience = {
            "tool_id": tool_id,
            "input": input_data,
            "output": result,
            "context": execution_context,
            "timestamp": time.time(),
            "success": result.get("success", False),
            "performance": execution_context.get("performance_metrics", {})
        }
        
        # 存储到本地知识库
        self.local_knowledge.add_experience(experience)
        
        # 提取知识
        knowledge = self._extract_knowledge(experience)
        
        # 共享知识（隐私保护）
        if self._should_share_knowledge(knowledge):
            encrypted_knowledge = self._encrypt_for_federation(knowledge)
            await self.federation_client.share_knowledge(encrypted_knowledge)
    
    async def get_tool_recommendations(self, task_description: str, 
                                     constraints: Dict[str, Any]) -> List[Dict[str, Any]]:
        """获取工具推荐"""
        # 本地知识查询
        local_recommendations = self.local_knowledge.query_recommendations(
            task_description, constraints
        )
        
        # 联邦知识查询（隐私保护）
        encrypted_query = self._encrypt_query(task_description, constraints)
        federation_recommendations = await self.federation_client.query_recommendations(
            encrypted_query
        )
        
        # 合并和排序推荐
        all_recommendations = local_recommendations + federation_recommendations
        sorted_recommendations = self._rank_recommendations(all_recommendations)
        
        return sorted_recommendations[:10]  # 返回前10个推荐
    
    async def federated_learning_round(self):
        """执行联邦学习轮次"""
        # 1. 本地模型训练
        local_dataset = self.local_knowledge.get_training_dataset()
        local_model_update = await self._train_local_model(local_dataset)
        
        # 2. 加密模型更新
        encrypted_update = self._encrypt_model_update(local_model_update)
        
        # 3. 发送到联邦服务器
        await self.federation_client.submit_model_update(encrypted_update)
        
        # 4. 接收聚合模型
        aggregated_model = await self.federation_client.get_aggregated_model()
        
        # 5. 更新本地模型
        decrypted_model = self._decrypt_model(aggregated_model)
        await self._update_local_model(decrypted_model)
        
        logger.info("联邦学习轮次完成")
```
