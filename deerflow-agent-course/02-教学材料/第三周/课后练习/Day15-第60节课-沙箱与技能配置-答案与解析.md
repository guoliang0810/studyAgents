### 设计思路

1. **多层配置结构**：
   - `sandbox_defaults`：提供全局默认配置，所有提供者可以继承
   - `providers`：具体提供者配置，可以覆盖默认值
   - 使用`inherit_defaults: true`显式控制继承行为

2. **安全级别策略**：
   - `TRUSTED`：本地开发环境，权限较高
   - `RESTRICTED`：Docker生产环境，适度限制
   - `SANDBOXED`：高负载环境，严格隔离

3. **环境变量设计**：
   - 支持变量引用 `${VAR_NAME}`
   - 支持默认值 `${VAR_NAME:default_value}`
   - 分层设置：全局→提供者级别→具体配置

4. **提供者特有配置**：
   - LOCAL：工作目录、Python路径
   - DOCKER：镜像、卷、端口映射
   - AIO：并发限制、连接数、超时设置

### 关键要点

1. **配置继承**：合理使用继承减少重复配置
2. **安全边界**：不同安全级别对应不同的资源限制
3. **环境变量管理**：统一变量命名和引用格式
4. **元数据**：添加分类、优先级等信息便于管理

### 常见错误

1. **循环继承**：避免配置之间的循环依赖
2. **安全级别不匹配**：高风险操作使用低安全级别沙箱
3. **变量未解析**：确保环境变量在运行时被正确解析
4. **资源限制不合理**：避免过度限制或限制不足

```python
# -*- coding: utf-8 -*-
"""
配置加载器实现 - 任务3答案
功能：加载和验证沙箱与技能配置

import yaml

class ConfigError(Exception):
    """配置相关异常基类"""
    pass


class ValidationError(ConfigError):
    """配置验证错误"""
    pass


class SecurityIssueLevel(Enum):
    """安全问题等级"""
    CRITICAL = "CRITICAL"
    HIGH = "HIGH"
    MEDIUM = "MEDIUM"
    LOW = "LOW"


@dataclass
class SecurityIssue:
    """安全问题"""
    level: SecurityIssueLevel
    message: str
    location: str
    suggestion: str = ""


@dataclass
class SandboxProviderConfig:
    """沙箱提供者配置"""
    provider_type: str
    name: str
    description: str
    enabled: bool = True
    environment_variables: Dict[str, str] = field(default_factory=dict)
    security_config: Dict[str, Any] = field(default_factory=dict)
    metadata: Dict[str, Any] = field(default_factory=dict)
    
    def validate(self) -> List[SecurityIssue]:
        """验证沙箱配置"""
        issues = []
        
        # 检查必填字段
        if not self.name:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message="沙箱提供者名称不能为空",
                location=f"providers.{self.name}"
            ))
        
        if not self.provider_type:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message="沙箱提供者类型不能为空",
                location=f"providers.{self.name}"
            ))
        
        # 检查安全配置
        security_config = self.security_config or {}
        security_level = security_config.get('security_level', 'TRUSTED')
        
        # 特权模式检查
        if security_config.get('privileged', False) and security_level != 'TRUSTED':
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.HIGH,
                message=f"特权模式只能用于TRUSTED安全级别，当前级别：{security_level}",
                location=f"providers.{self.name}.security_config",
                suggestion="禁用特权模式或提升安全级别"
            ))
        
        # 资源限制检查
        cpu_limit = security_config.get('cpu_limit_percent', 100.0)
        if not 0.1 <= cpu_limit <= 100.0:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message=f"CPU限制必须在0.1%-100%之间，当前值：{cpu_limit}",
                location=f"providers.{self.name}.security_config.cpu_limit_percent",
                suggestion="调整CPU限制在合理范围内"
            ))
        
        memory_limit = security_config.get('memory_limit_mb', 1024)
        if memory_limit <= 0:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message=f"内存限制必须大于0，当前值：{memory_limit}",
                location=f"providers.{self.name}.security_config.memory_limit_mb",
                suggestion="设置正数的内存限制"
            ))
        
        return issues


@dataclass
class SkillDependency:
    """技能依赖"""
    skill_id: str
    version_constraint: str
    required: bool = True
    description: str = ""
    
    def is_version_satisfied(self, version: str) -> bool:
        """检查版本是否满足约束"""
        try:
            from packaging.version import parse as parse_version
            from packaging.specifiers import SpecifierSet
            
            spec = SpecifierSet(self.version_constraint)
            return spec.contains(parse_version(version))
        except Exception:
            # 如果解析失败，使用简单字符串比较
            return True  # 实际实现中应该更严谨


@dataclass
class SkillConfig:
    """技能配置"""
    skill_id: str
    name: str
    description: str
    version: str
    skill_type: str
    status: str = "ENABLED"
    dependencies: List[SkillDependency] = field(default_factory=list)
    config_params: Dict[str, Any] = field(default_factory=dict)
    security_config: Dict[str, Any] = field(default_factory=dict)
    metadata: Dict[str, Any] = field(default_factory=dict)
    
    def validate(self, available_skills: Set[str]) -> List[SecurityIssue]:
        """验证技能配置"""
        issues = []
        
        # 检查必填字段
        if not self.skill_id:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message="技能ID不能为空",
                location=f"skills.{self.skill_id}"
            ))
        
        # 检查版本格式
        version_pattern = r'^\d+\.\d+\.\d+$'
        if not re.match(version_pattern, self.version):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message=f"版本号格式不正确，应该使用语义化版本（如1.0.0），当前值：{self.version}",
                location=f"skills.{self.skill_id}.version",
                suggestion="使用语义化版本格式：主版本.次版本.修订号"
            ))
        
        # 检查依赖是否存在
        for dep in self.dependencies:
            if dep.required and dep.skill_id not in available_skills:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.HIGH,
                    message=f"依赖的技能不存在：{dep.skill_id}",
                    location=f"skills.{self.skill_id}.dependencies.{dep.skill_id}",
                    suggestion="移除不存在的依赖或添加对应的技能配置"
                ))
        
        # 检查安全配置
        security_config = self.security_config or {}
        
        if not security_config.get('sandbox_provider'):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message="技能必须指定沙箱提供者",
                location=f"skills.{self.skill_id}.security_config",
                suggestion="指定一个有效的沙箱提供者"
            ))
        
        # 高风险技能检查
        high_risk_skill_types = ['WEB_SCRAPER', 'API_CLIENT']
        if self.skill_type in high_risk_skill_types:
            required_level = security_config.get('required_security_level', 'TRUSTED')
            if required_level not in ['RESTRICTED', 'SANDBOXED']:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.HIGH,
                    message=f"高风险技能类型'{self.skill_type}'必须使用RESTRICTED或SANDBOXED安全级别，当前级别：{required_level}",
                    location=f"skills.{self.skill_id}.security_config.required_security_level",
                    suggestion="提升安全级别到RESTRICTED或SANDBOXED"
                ))
        
        return issues


class ConfigLoader:
    """主配置加载器"""
    
    def __init__(self, config_dir: str):
        self.config_dir = Path(config_dir)
        self.sandbox_config = None
        self.skill_system_config = None
        self.env_vars = {}
        self.loaded_files = {}
        
    async def load_all(self, env_vars: Dict[str, str] = None) -> bool:
        """加载所有配置"""
        try:
            self.env_vars = env_vars or {}
            
            # 1. 加载沙箱配置
            sandbox_config_path = self.config_dir / "sandbox_config.yaml"
            if sandbox_config_path.exists():
                self.sandbox_config = await self._load_sandbox_config(sandbox_config_path)
            else:
                raise ConfigError(f"沙箱配置文件不存在：{sandbox_config_path}")
            
            # 2. 加载技能配置
            skill_config_path = self.config_dir / "skills_config.yaml"
            if skill_config_path.exists():
                self.skill_system_config = await self._load_skill_system_config(skill_config_path)
            else:
                raise ConfigError(f"技能配置文件不存在：{skill_config_path}")
            
            # 3. 解析环境变量
            await self._resolve_environment_variables()
            
            # 4. 验证配置
            validation_errors = self.validate_all()
            if validation_errors:
                print(f"配置验证发现 {len(validation_errors)} 个问题：")
                for error in validation_errors:
                    print(f"  - {error}")
                return False
            
            return True
            
        except Exception as e:
            print(f"配置加载失败：{str(e)}")
            import traceback
            traceback.print_exc()
            return False
    
    async def _load_sandbox_config(self, config_path: Path) -> Dict[str, Any]:
        """加载沙箱配置"""
        with open(config_path, 'r', encoding='utf-8') as f:
            content = f.read()
            config = yaml.safe_load(content)
            self.loaded_files[str(config_path)] = hashlib.md5(content.encode()).hexdigest()
            return config
    
    async def _load_skill_system_config(self, config_path: Path) -> Dict[str, Any]:
        """加载技能系统配置"""
        with open(config_path, 'r', encoding='utf-8') as f:
            content = f.read()
            config = yaml.safe_load(content)
            self.loaded_files[str(config_path)] = hashlib.md5(content.encode()).hexdigest()
            return config
    
    async def _resolve_environment_variables(self):
        """解析环境变量"""
        if not self.env_vars:
            return
        
        def resolve_value(value: Any) -> Any:
            """递归解析值中的环境变量"""
            if isinstance(value, str):
                # 匹配 ${VAR_NAME} 或 ${VAR_NAME:default}
                pattern = r'\$\{([A-Za-z0-9_]+)(?::([^}]+))?\}'
                
                def replace_var(match):
                    var_name = match.group(1)
                    default_value = match.group(2)
                    
                    if var_name in self.env_vars:
                        return self.env_vars[var_name]
                    elif default_value is not None:
                        return default_value
                    else:
                        return match.group(0)  # 保持原样
                
                return re.sub(pattern, replace_var, value)
            elif isinstance(value, dict):
                return {k: resolve_value(v) for k, v in value.items()}
            elif isinstance(value, list):
                return [resolve_value(item) for item in value]
            else:
                return value
        
        # 解析沙箱配置中的环境变量
        if self.sandbox_config:
            self.sandbox_config = resolve_value(self.sandbox_config)
        
        # 解析技能配置中的环境变量
        if self.skill_system_config:
            self.skill_system_config = resolve_value(self.skill_system_config)
    
    def validate_all(self) -> List[str]:
        """验证所有配置"""
        errors = []
        
        # 验证沙箱配置
        if self.sandbox_config:
            sandbox_errors = self._validate_sandbox_config()
            errors.extend(sandbox_errors)
        
        # 验证技能配置
        if self.skill_system_config:
            skill_errors = self._validate_skill_system_config()
            errors.extend(skill_errors)
        
        # 验证配置一致性
        consistency_errors = self._validate_config_consistency()
        errors.extend(consistency_errors)
        
        return errors
    
    def _validate_sandbox_config(self) -> List[str]:
        """验证沙箱配置"""
        errors = []
        
        if not isinstance(self.sandbox_config, dict):
            errors.append("沙箱配置必须是字典格式")
            return errors
        
        # 检查默认提供者
        default_provider = self.sandbox_config.get('default_provider')
        if not default_provider:
            errors.append("必须指定默认沙箱提供者")
        
        # 检查提供者配置
        providers = self.sandbox_config.get('providers', {})
        if not providers:
            errors.append("必须配置至少一个沙箱提供者")
        
        if default_provider and default_provider not in providers:
            errors.append(f"默认提供者 '{default_provider}' 不存在于提供者列表中")
        
        # 检查每个提供者
        for provider_name, provider_config in providers.items():
            if not isinstance(provider_config, dict):
                errors.append(f"提供者 '{provider_name}' 配置必须是字典格式")
                continue
            
            # 检查必填字段
            required_fields = ['provider_type', 'name', 'description']
            for field in required_fields:
                if field not in provider_config:
                    errors.append(f"提供者 '{provider_name}' 缺少必填字段: {field}")
            
            # 检查启用状态
            enabled = provider_config.get('enabled', True)
            if not isinstance(enabled, bool):
                errors.append(f"提供者 '{provider_name}' 的enabled字段必须是布尔值")
        
        return errors
    
    def _validate_skill_system_config(self) -> List[str]:
        """验证技能系统配置"""
        errors = []
        
        if not isinstance(self.skill_system_config, dict):
            errors.append("技能系统配置必须是字典格式")
            return errors
        
        # 检查系统元数据
        system_config = self.skill_system_config.get('system', {})
        if not system_config:
            errors.append("必须配置系统元数据")
        else:
            required_system_fields = ['name', 'version', 'description']
            for field in required_system_fields:
                if field not in system_config:
                    errors.append(f"系统配置缺少必填字段: {field}")
        
        # 检查技能配置
        skills = self.skill_system_config.get('skills', {})
        if not skills:
            errors.append("必须配置至少一个技能")
        
        # 检查每个技能
        skill_ids = set()
        for skill_id, skill_config in skills.items():
            if not isinstance(skill_config, dict):
                errors.append(f"技能 '{skill_id}' 配置必须是字典格式")
                continue
            
            skill_ids.add(skill_id)
            
            # 检查必填字段
            required_fields = ['skill_id', 'name', 'description', 'version', 'skill_type']
            for field in required_fields:
                if field not in skill_config:
                    errors.append(f"技能 '{skill_id}' 缺少必填字段: {field}")
            
            # 检查版本格式
            version = skill_config.get('version', '')
            if version and not re.match(r'^\d+\.\d+\.\d+$', version):
                errors.append(f"技能 '{skill_id}' 版本号格式不正确: {version}")
            
            # 检查状态
            status = skill_config.get('status', 'ENABLED')
            if status not in ['ENABLED', 'DISABLED']:
                errors.append(f"技能 '{skill_id}' 状态必须是ENABLED或DISABLED")
        
        # 检查依赖关系
        for skill_id, skill_config in skills.items():
            dependencies = skill_config.get('dependencies', [])
            for dep in dependencies:
                if isinstance(dep, dict):
                    dep_skill_id = dep.get('skill_id')
                    if dep_skill_id and dep_skill_id not in skill_ids:
                        errors.append(f"技能 '{skill_id}' 依赖不存在的技能: {dep_skill_id}")
        
        return errors
    
    def _validate_config_consistency(self) -> List[str]:
        """验证配置一致性"""
        errors = []
        
        if not self.sandbox_config or not self.skill_system_config:
            return errors
        
        # 检查技能引用的沙箱提供者是否存在
        sandbox_providers = set(self.sandbox_config.get('providers', {}).keys())
        skills = self.skill_system_config.get('skills', {})
        
        for skill_id, skill_config in skills.items():
            security_config = skill_config.get('security_config', {})
            sandbox_provider = security_config.get('sandbox_provider')
            
            if sandbox_provider and sandbox_provider not in sandbox_providers:
                errors.append(f"技能 '{skill_id}' 引用了不存在的沙箱提供者: {sandbox_provider}")
        
        return errors
    
    def get_skill_dependency_tree(self, skill_id: str) -> Dict:
        """获取技能的依赖树"""
        if not self.skill_system_config:
            return {}
        
        skills = self.skill_system_config.get('skills', {})
        if skill_id not in skills:
            return {}
        
        skill_config = skills[skill_id]
        dependencies = skill_config.get('dependencies', [])
        
        result = {
            'skill_id': skill_id,
            'name': skill_config.get('name', ''),
            'version': skill_config.get('version', ''),
            'dependencies': []
        }
        
        for dep in dependencies:
            if isinstance(dep, dict):
                dep_skill_id = dep.get('skill_id')
                if dep_skill_id and dep_skill_id in skills:
                    # 递归获取依赖的依赖树
                    dep_tree = self.get_skill_dependency_tree(dep_skill_id)
                    result['dependencies'].append({
                        'skill_id': dep_skill_id,
                        'version_constraint': dep.get('version_constraint', ''),
                        'required': dep.get('required', True),
                        'description': dep.get('description', ''),
                        'sub_dependencies': dep_tree.get('dependencies', [])
                    })
        
        return result
    
    def save_backup(self, backup_dir: str):
        """保存配置备份"""
        backup_path = Path(backup_dir)
        backup_path.mkdir(parents=True, exist_ok=True)

            with open(sandbox_backup_path, 'w', encoding='utf-8') as f:
                yaml.dump(self.sandbox_config, f, default_flow_style=False, allow_unicode=True)
        
        # 保存技能配置
        if self.skill_system_config:
            skill_backup_path = backup_path / f"skills_config_{timestamp}.yaml"
            with open(skill_backup_path, 'w', encoding='utf-8') as f:
                yaml.dump(self.skill_system_config, f, default_flow_style=False, allow_unicode=True)
        
        # 保存加载状态
        status = {
            'timestamp': timestamp,
            'loaded_files': self.loaded_files,
            'env_vars': self.env_vars
        }
        
        status_path = backup_path / f"loader_status_{timestamp}.json"
        with open(status_path, 'w', encoding='utf-8') as f:
            json.dump(status, f, indent=2, ensure_ascii=False)
        
        return {
            'sandbox_config': sandbox_backup_path if self.sandbox_config else None,
            'skills_config': skill_backup_path if self.skill_system_config else None,
            'loader_status': status_path
        }
```

### 设计思路

1. **分层加载**：
   - `ConfigLoader`：主协调器
   - `_load_sandbox_config`：专门加载沙箱配置
   - `_load_skill_system_config`：专门加载技能配置
   - `_resolve_environment_variables`：统一解析环境变量

2. **异步设计**：
   - 使用`async/await`支持异步加载
   - 适合从网络或数据库加载配置的场景

3. **环境变量解析**：
   - 支持`${VAR_NAME}`格式
   - 支持默认值`${VAR_NAME:default}`
   - 递归解析嵌套结构

4. **验证机制**：
   - 字段必填检查
   - 格式验证（版本号、状态值等）
   - 引用一致性检查
   - 安全配置验证

5. **依赖树生成**：
   - 递归查找所有依赖
   - 支持必需和可选依赖
   - 生成结构化树形数据

### 关键要点

1. **错误处理**：详细的错误信息和异常处理
2. **配置备份**：自动备份和版本管理
3. **状态追踪**：记录加载的文件和哈希值
4. **可扩展性**：易于添加新的配置类型和验证规则

### 常见错误

1. **文件不存在**：检查配置文件路径
2. **YAML格式错误**：使用`yaml.safe_load`避免安全问题
3. **环境变量未解析**：确保提供正确的环境变量字典
4. **循环依赖**：依赖树生成时可能无限递归（需要检测）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
安全配置验证器 - 任务4答案
功能：验证沙箱和技能配置的安全策略
"""

import re
import psutil
from typing import Dict, List, Any, Optional
from dataclasses import dataclass, field
from enum import Enum


class SecurityIssueLevel(Enum):
    """安全问题等级"""
    CRITICAL = "CRITICAL"
    HIGH = "HIGH"
    MEDIUM = "MEDIUM"
    LOW = "LOW"


@dataclass
class SecurityIssue:
    """安全问题"""
    level: SecurityIssueLevel
    message: str
    location: str
    suggestion: str = ""
    
    def __str__(self):
        return f"[{self.level.value}] {self.location}: {self.message} ({self.suggestion})"


class SecurityValidator:
    """安全验证器基类"""
    
    def validate(self, config: Any) -> List[SecurityIssue]:
        """验证配置，返回安全问题列表"""
        raise NotImplementedError("子类必须实现validate方法")
    
    def calculate_security_score(self, issues: List[SecurityIssue]) -> int:
        """计算安全评分（0-100）"""
        if not issues:
            return 100
        
        # 权重：CRITICAL=10, HIGH=5, MEDIUM=2, LOW=1
        weights = {
            SecurityIssueLevel.CRITICAL: 10,
            SecurityIssueLevel.HIGH: 5,
            SecurityIssueLevel.MEDIUM: 2,
            SecurityIssueLevel.LOW: 1
        }
        
        total_weight = 0
        for issue in issues:
            total_weight += weights.get(issue.level, 1)
        
        # 扣分公式：每10权重扣1分，最多扣100分
        deduction = min(total_weight // 10, 100)
        return max(0, 100 - deduction)


class SandboxSecurityValidator(SecurityValidator):
    """沙箱安全验证器"""
    
    def validate(self, config: Dict[str, Any]) -> List[SecurityIssue]:
        """验证沙箱配置"""
        issues = []
        
        if not config or not isinstance(config, dict):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message="沙箱配置为空或格式不正确",
                location="sandbox_config",
                suggestion="提供有效的沙箱配置"
            ))
            return issues
        
        # 检查默认提供者
        issues.extend(self._check_default_provider(config))
        
        # 检查提供者配置
        providers = config.get('providers', {})
        for provider_name, provider_config in providers.items():
            issues.extend(self._validate_provider(provider_name, provider_config))
        
        # 检查沙箱级别配置
        issues.extend(self._check_sandbox_level_config(config))
        
        return issues
    
    def _check_default_provider(self, config: Dict[str, Any]) -> List[SecurityIssue]:
        """检查默认提供者"""
        issues = []
        
        default_provider = config.get('default_provider')
        if not default_provider:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="未指定默认沙箱提供者",
                location="sandbox_config.default_provider",
                suggestion="指定一个默认提供者，确保系统有默认的沙箱环境"
            ))
        
        providers = config.get('providers', {})
        if default_provider and default_provider not in providers:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.HIGH,
                message=f"默认提供者不存在: {default_provider}",
                location="sandbox_config.default_provider",
                suggestion="确保默认提供者在providers列表中定义"
            ))
        
        return issues
    
    def _validate_provider(self, provider_name: str, provider_config: Dict[str, Any]) -> List[SecurityIssue]:
        """验证单个提供者"""
        issues = []
        
        if not isinstance(provider_config, dict):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message=f"提供者配置必须是字典格式",
                location=f"providers.{provider_name}",
                suggestion="修正提供者配置格式"
            ))
            return issues
        
        # 检查启用状态
        enabled = provider_config.get('enabled', True)
        if not isinstance(enabled, bool):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="enabled字段必须是布尔值",
                location=f"providers.{provider_name}.enabled",
                suggestion="设置为true或false"
            ))
        
        # 检查安全配置
        security_config = provider_config.get('security_config', {})
        issues.extend(self._check_security_config(provider_name, security_config))
        
        # 检查环境变量
        env_vars = provider_config.get('environment_variables', {})
        issues.extend(self._check_environment_variables(provider_name, env_vars))
        
        # 检查提供者特定配置
        provider_type = provider_config.get('provider_type', '').upper()
        issues.extend(self._check_provider_specific_config(provider_name, provider_type, provider_config))
        
        return issues
    
    def _check_security_config(self, provider_name: str, security_config: Dict[str, Any]) -> List[SecurityIssue]:
        """检查安全配置"""
        issues = []
        
        # 检查安全级别
        security_level = security_config.get('security_level', 'TRUSTED')
        valid_levels = ['TRUSTED', 'RESTRICTED', 'SANDBOXED']
        if security_level not in valid_levels:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message=f"安全级别无效: {security_level}",
                location=f"providers.{provider_name}.security_config.security_level",
                suggestion=f"使用有效的安全级别: {', '.join(valid_levels)}"
            ))
        
        # 检查CPU限制
        cpu_limit = security_config.get('cpu_limit_percent', 100.0)
        if not isinstance(cpu_limit, (int, float)):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="CPU限制必须是数值",
                location=f"providers.{provider_name}.security_config.cpu_limit_percent",
                suggestion="设置为0.1到100.0之间的数值"
            ))
        elif not 0.1 <= cpu_limit <= 100.0:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.HIGH,
                message=f"CPU限制必须在0.1%-100%之间，当前值: {cpu_limit}",
                location=f"providers.{provider_name}.security_config.cpu_limit_percent",
                suggestion="调整CPU限制在合理范围内"
            ))
        
        # 检查内存限制
        memory_limit = security_config.get('memory_limit_mb', 1024)
        if not isinstance(memory_limit, (int, float)):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="内存限制必须是数值",
                location=f"providers.{provider_name}.security_config.memory_limit_mb",
                suggestion="设置为正数"
            ))
        elif memory_limit <= 0:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message=f"内存限制必须大于0，当前值: {memory_limit}",
                location=f"providers.{provider_name}.security_config.memory_limit_mb",
                suggestion="设置为正数的内存限制"
            ))
        else:
            # 检查是否超过系统可用内存
            try:
                available_memory = psutil.virtual_memory().available / (1024 * 1024)  # MB
                if memory_limit > available_memory * 0.8:  # 不超过可用内存的80%
                    issues.append(SecurityIssue(
                        level=SecurityIssueLevel.HIGH,
                        message=f"内存限制({memory_limit}MB)超过系统可用内存({available_memory:.0f}MB)的80%",
                        location=f"providers.{provider_name}.security_config.memory_limit_mb",
                        suggestion=f"降低内存限制，建议不超过{available_memory * 0.8:.0f}MB"
                    ))
            except Exception:
                pass  # 如果无法获取系统内存信息，跳过
        
        # 检查网络白名单
        network_whitelist = security_config.get('network_whitelist', [])
        issues.extend(self._check_network_whitelist(provider_name, network_whitelist))
        
        # 检查执行时间限制
        max_execution_time = security_config.get('max_execution_time_seconds', 60.0)
        if not isinstance(max_execution_time, (int, float)):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="执行时间限制必须是数值",
                location=f"providers.{provider_name}.security_config.max_execution_time_seconds",
                suggestion="设置为正数"
            ))
        elif max_execution_time <= 0:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.HIGH,
                message=f"执行时间限制必须大于0，当前值: {max_execution_time}",
                location=f"providers.{provider_name}.security_config.max_execution_time_seconds",
                suggestion="设置为正数的执行时间限制"
            ))
        elif max_execution_time > 3600:  # 超过1小时
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message=f"执行时间限制过长: {max_execution_time}秒（超过1小时）",
                location=f"providers.{provider_name}.security_config.max_execution_time_seconds",
                suggestion="限制执行时间，避免长时间占用资源"
            ))
        
        # 检查特权模式
        privileged = security_config.get('privileged', False)
        if privileged and security_level != 'TRUSTED':
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.HIGH,
                message="特权模式只能用于TRUSTED安全级别",
                location=f"providers.{provider_name}.security_config.privileged",
                suggestion="禁用特权模式或提升安全级别到TRUSTED"
            ))
        
        return issues
    
    def _check_network_whitelist(self, provider_name: str, whitelist: List[str]) -> List[SecurityIssue]:
        """检查网络白名单"""
        issues = []
        
        if not isinstance(whitelist, list):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="网络白名单必须是列表",
                location=f"providers.{provider_name}.security_config.network_whitelist",
                suggestion="使用列表格式"
            ))
            return issues
        
        for i, pattern in enumerate(whitelist):
            if not isinstance(pattern, str):
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message=f"白名单模式必须是字符串",
                    location=f"providers.{provider_name}.security_config.network_whitelist[{i}]",
                    suggestion="使用字符串格式的正则表达式"
                ))
                continue
            
            # 检查是否为有效的正则表达式
            try:
                re.compile(pattern)
            except re.error as e:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.HIGH,
                    message=f"无效的正则表达式: {pattern} ({str(e)})",
                    location=f"providers.{provider_name}.security_config.network_whitelist[{i}]",
                    suggestion="修正正则表达式语法"
                ))
        
        return issues
    
    def _check_environment_variables(self, provider_name: str, env_vars: Dict[str, str]) -> List[SecurityIssue]:
        """检查环境变量"""
        issues = []
        
        if not isinstance(env_vars, dict):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="环境变量必须是字典格式",
                location=f"providers.{provider_name}.environment_variables",
                suggestion="使用字典格式"
            ))
            return issues
        
        # 检查敏感信息
        sensitive_patterns = {
            'password': r'(?i)password',
            'secret': r'(?i)secret',
            'key': r'(?i)(api[_-]?key|access[_-]?key|private[_-]?key)',
            'token': r'(?i)token',
            'credential': r'(?i)credential'
        }
        
        for key, value in env_vars.items():
            if not isinstance(key, str) or not isinstance(value, str):
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message="环境变量的键和值必须是字符串",
                    location=f"providers.{provider_name}.environment_variables.{key}",
                    suggestion="使用字符串格式"
                ))
                continue
            
            # 检查是否包含敏感信息
            for pattern_name, pattern in sensitive_patterns.items():
                if re.search(pattern, key):
                    # 检查值是否看起来是明文密码/密钥
                    if value and not value.startswith('${') and not value.startswith('$'):
                        issues.append(SecurityIssue(
                            level=SecurityIssueLevel.CRITICAL,
                            message=f"环境变量可能包含明文{pattern_name}: {key}",
                            location=f"providers.{provider_name}.environment_variables.{key}",
                            suggestion="使用环境变量引用或加密存储敏感信息"
                        ))
        
        return issues
    
    def _check_provider_specific_config(self, provider_name: str, provider_type: str, 
                                       config: Dict[str, Any]) -> List[SecurityIssue]:
        """检查提供者特定配置"""
        issues = []
        
        if provider_type == 'DOCKER':
            # 检查Docker特定配置
            privileged = config.get('privileged', False)
            if privileged:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.HIGH,
                    message="Docker容器启用了特权模式",
                    location=f"providers.{provider_name}.privileged",
                    suggestion="除非必要，否则禁用特权模式以增强安全性"
                ))
            
            # 检查卷挂载
            volumes = config.get('volumes', [])
            for i, volume in enumerate(volumes):
                if isinstance(volume, dict):
                    mode = volume.get('mode', 'ro')
                    if mode not in ['ro', 'rw']:
                        issues.append(SecurityIssue(
                            level=SecurityIssueLevel.MEDIUM,
                            message=f"卷挂载模式无效: {mode}",
                            location=f"providers.{provider_name}.volumes[{i}].mode",
                            suggestion="使用'ro'（只读）或'rw'（读写）"
                        ))
        
        elif provider_type == 'AIO':
            # 检查异步I/O特定配置
            max_concurrent_tasks = config.get('max_concurrent_tasks', 10)
            if max_concurrent_tasks > 1000:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.HIGH,
                    message=f"并发任务数过高: {max_concurrent_tasks}",
                    location=f"providers.{provider_name}.max_concurrent_tasks",
                    suggestion="限制并发任务数，避免资源耗尽"
                ))
        
        return issues
    
    def _check_sandbox_level_config(self, config: Dict[str, Any]) -> List[SecurityIssue]:
        """检查沙箱级别配置"""
        issues = []
        
        # 检查默认安全配置
        defaults = config.get('sandbox_defaults', {})
        if defaults:
            security_config = defaults.get('security_config', {})
            if security_config:
                # 检查默认安全级别是否过高
                default_security_level = security_config.get('security_level', 'SANDBOXED')
                if default_security_level == 'SANDBOXED':
                    issues.append(SecurityIssue(
                        level=SecurityIssueLevel.LOW,
                        message="默认安全级别为SANDBOXED，可能过于严格",
                        location="sandbox_config.sandbox_defaults.security_config.security_level",
                        suggestion="考虑使用RESTRICTED作为默认级别，在需要时升级到SANDBOXED"
                    ))
        
        return issues


class SkillSecurityValidator(SecurityValidator):
    """技能安全验证器"""
    
    def __init__(self, available_sandbox_providers: List[str]):
        self.available_sandbox_providers = available_sandbox_providers
    
    def validate(self, config: Dict[str, Any]) -> List[SecurityIssue]:
        """验证技能配置"""
        issues = []
        
        if not config or not isinstance(config, dict):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message="技能配置为空或格式不正确",
                location="skill_system_config",
                suggestion="提供有效的技能配置"
            ))
            return issues
        
        # 检查系统配置
        system_config = config.get('system', {})
        issues.extend(self._check_system_config(system_config))
        
        # 检查技能配置
        skills = config.get('skills', {})
        for skill_id, skill_config in skills.items():
            issues.extend(self._validate_skill(skill_id, skill_config))
        
        # 检查全局依赖关系
        issues.extend(self._check_global_dependencies(skills))
        
        return issues
    
    def _check_system_config(self, system_config: Dict[str, Any]) -> List[SecurityIssue]:
        """检查系统配置"""
        issues = []
        
        if not system_config:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="缺少系统配置",
                location="skill_system_config.system",
                suggestion="添加系统元数据配置"
            ))
            return issues
        
        # 检查默认沙箱提供者
        default_sandbox_provider = system_config.get('default_sandbox_provider')
        if default_sandbox_provider:
            if default_sandbox_provider not in self.available_sandbox_providers:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.HIGH,
                    message=f"系统默认沙箱提供者不存在: {default_sandbox_provider}",
                    location="skill_system_config.system.default_sandbox_provider",
                    suggestion="指定一个有效的沙箱提供者"
                ))
        
        # 检查版本检查
        enable_version_checking = system_config.get('enable_version_checking', True)
        if not enable_version_checking:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="版本检查被禁用",
                location="skill_system_config.system.enable_version_checking",
                suggestion="启用版本检查以确保依赖兼容性"
            ))
        
        return issues
    
    def _validate_skill(self, skill_id: str, skill_config: Dict[str, Any]) -> List[SecurityIssue]:
        """验证单个技能"""
        issues = []
        
        if not isinstance(skill_config, dict):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message="技能配置必须是字典格式",
                location=f"skills.{skill_id}",
                suggestion="修正技能配置格式"
            ))
            return issues
        
        # 检查基本信息
        issues.extend(self._check_skill_basic_info(skill_id, skill_config))
        
        # 检查安全配置
        security_config = skill_config.get('security_config', {})
        issues.extend(self._check_skill_security_config(skill_id, skill_config, security_config))
        
        # 检查配置参数
        config_params = skill_config.get('config_params', {})
        issues.extend(self._check_skill_config_params(skill_id, skill_config.get('skill_type', ''), config_params))
        
        # 检查依赖关系
        dependencies = skill_config.get('dependencies', [])
        issues.extend(self._check_skill_dependencies(skill_id, dependencies))
        
        return issues
    
    def _check_skill_basic_info(self, skill_id: str, skill_config: Dict[str, Any]) -> List[SecurityIssue]:
        """检查技能基本信息"""
        issues = []
        
        # 检查必填字段
        required_fields = ['skill_id', 'name', 'description', 'version', 'skill_type']
        for field in required_fields:
            if field not in skill_config:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.CRITICAL,
                    message=f"缺少必填字段: {field}",
                    location=f"skills.{skill_id}.{field}",
                    suggestion="添加缺失的字段"
                ))
        
        # 检查版本格式
        version = skill_config.get('version', '')
        if version:
            version_pattern = r'^\d+\.\d+\.\d+$'
            if not re.match(version_pattern, version):
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message=f"版本号格式不正确: {version}",
                    location=f"skills.{skill_id}.version",
                    suggestion="使用语义化版本格式：主版本.次版本.修订号"
                ))
        
        # 检查状态
        status = skill_config.get('status', 'ENABLED')
        if status not in ['ENABLED', 'DISABLED']:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message=f"状态值无效: {status}",
                location=f"skills.{skill_id}.status",
                suggestion="使用ENABLED或DISABLED"
            ))
        
        return issues
    
    def _check_skill_security_config(self, skill_id: str, skill_config: Dict[str, Any], 
                                   security_config: Dict[str, Any]) -> List[SecurityIssue]:
        """检查技能安全配置"""
        issues = []
        
        # 检查沙箱提供者
        sandbox_provider = security_config.get('sandbox_provider')
        if not sandbox_provider:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.CRITICAL,
                message="未指定沙箱提供者",
                location=f"skills.{skill_id}.security_config.sandbox_provider",
                suggestion="指定一个沙箱提供者"
            ))
        elif sandbox_provider not in self.available_sandbox_providers:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.HIGH,
                message=f"指定的沙箱提供者不存在: {sandbox_provider}",
                location=f"skills.{skill_id}.security_config.sandbox_provider",
                suggestion="指定一个有效的沙箱提供者"
            ))
        
        # 检查安全级别
        required_security_level = security_config.get('required_security_level', 'TRUSTED')
        valid_levels = ['TRUSTED', 'RESTRICTED', 'SANDBOXED']
        if required_security_level not in valid_levels:
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message=f"安全级别无效: {required_security_level}",
                location=f"skills.{skill_id}.security_config.required_security_level",
                suggestion=f"使用有效的安全级别: {', '.join(valid_levels)}"
            ))
        
        # 高风险技能检查
        skill_type = skill_config.get('skill_type', '')
        high_risk_skill_types = ['WEB_SCRAPER', 'API_CLIENT']
        
        if skill_type in high_risk_skill_types:
            if required_security_level not in ['RESTRICTED', 'SANDBOXED']:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.HIGH,
                    message=f"高风险技能类型'{skill_type}'必须使用RESTRICTED或SANDBOXED安全级别",
                    location=f"skills.{skill_id}.security_config.required_security_level",
                    suggestion="提升安全级别到RESTRICTED或SANDBOXED"
                ))
            
            # 检查高风险技能的其他安全要求
            allowed_domains = security_config.get('allowed_domains', [])
            if not allowed_domains:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message="高风险技能未指定允许访问的域名",
                    location=f"skills.{skill_id}.security_config.allowed_domains",
                    suggestion="明确指定允许访问的域名列表"
                ))
        
        return issues
    
    def _check_skill_config_params(self, skill_id: str, skill_type: str, 
                                 config_params: Dict[str, Any]) -> List[SecurityIssue]:
        """检查技能配置参数"""
        issues = []
        
        if not isinstance(config_params, dict):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="配置参数必须是字典格式",
                location=f"skills.{skill_id}.config_params",
                suggestion="使用字典格式"
            ))
            return issues
        
        # 根据技能类型检查特定参数
        if skill_type == 'WEB_SCRAPER':
            # 检查超时设置
            timeout = config_params.get('timeout_seconds', 30)
            if not isinstance(timeout, (int, float)):
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message="超时设置必须是数值",
                    location=f"skills.{skill_id}.config_params.timeout_seconds",
                    suggestion="设置为正数"
                ))
            elif timeout <= 0:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.HIGH,
                    message=f"超时设置必须大于0，当前值: {timeout}",
                    location=f"skills.{skill_id}.config_params.timeout_seconds",
                    suggestion="设置为正数的超时值"
                ))
            elif timeout > 300:  # 超过5分钟
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message=f"超时设置过长: {timeout}秒（超过5分钟）",
                    location=f"skills.{skill_id}.config_params.timeout_seconds",
                    suggestion="限制超时时间，避免长时间等待"
                ))
            
            # 检查重试次数
            max_retries = config_params.get('max_retries', 3)
            if not isinstance(max_retries, int):
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message="重试次数必须是整数",
                    location=f"skills.{skill_id}.config_params.max_retries",
                    suggestion="设置为整数"
                ))
            elif max_retries < 0:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.HIGH,
                    message=f"重试次数不能为负数: {max_retries}",
                    location=f"skills.{skill_id}.config_params.max_retries",
                    suggestion="设置为0或正整数"
                ))
            elif max_retries > 10:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message=f"重试次数过多: {max_retries}",
                    location=f"skills.{skill_id}.config_params.max_retries",
                    suggestion="限制重试次数，避免无限重试"
                ))
        
        elif skill_type == 'CALCULATOR':
            # 检查计算限制
            max_computation_time = config_params.get('max_computation_time_seconds', 60)
            if max_computation_time > 600:  # 超过10分钟
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message=f"计算时间限制过长: {max_computation_time}秒（超过10分钟）",
                    location=f"skills.{skill_id}.config_params.max_computation_time_seconds",
                    suggestion="限制计算时间，避免资源耗尽"
                ))
        
        return issues
    
    def _check_skill_dependencies(self, skill_id: str, dependencies: List[Dict[str, Any]]) -> List[SecurityIssue]:
        """检查技能依赖关系"""
        issues = []
        
        if not isinstance(dependencies, list):
            issues.append(SecurityIssue(
                level=SecurityIssueLevel.MEDIUM,
                message="依赖关系必须是列表格式",
                location=f"skills.{skill_id}.dependencies",
                suggestion="使用列表格式"
            ))
            return issues
        
        for i, dep in enumerate(dependencies):
            if not isinstance(dep, dict):
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.MEDIUM,
                    message="依赖项必须是字典格式",
                    location=f"skills.{skill_id}.dependencies[{i}]",
                    suggestion="使用字典格式"
                ))
                continue
            
            # 检查必填字段
            dep_skill_id = dep.get('skill_id')
            if not dep_skill_id:
                issues.append(SecurityIssue(
                    level=SecurityIssueLevel.CRITICAL,
                    message="依赖项缺少skill_id字段",
                    location=f"skills.{skill_id}.dependencies[{i}]",
                    suggestion="添加skill_id字段"
                ))
            
            # 检查版本约束
            version_constraint = dep.get('version_constraint', '')
            if version_constraint:
                # 简单检查版本约束格式
                if not re.match(r'^[>=<~^]*\d+\.\d+\.\d+', version_constraint):
                    issues.append(SecurityIssue(
                        level=SecurityIssueLevel.MEDIUM,
                        message=f"版本约束格式不正确: {version_constraint}",
                        location=f"skills.{skill_id}.dependencies[{i}].version_constraint",
                        suggestion="使用有效的版本约束格式，如'>=1.0.0'、'^2.0.0'、'~3.1.0'"
                    ))
        
        return issues
    
    def _check_global_dependencies(self, skills: Dict[str, Dict[str, Any]]) -> List[SecurityIssue]:
        """检查全局依赖关系"""
        issues = []
        
        # 构建依赖图
        dependency_graph = {}
        for skill_id, skill_config in skills.items():
            dependencies = skill_config.get('dependencies', [])
            dependency_graph[skill_id] = []
            
            for dep in dependencies:
                if isinstance(dep, dict):
                    dep_skill_id = dep.get('skill_id')
                    if dep_skill_id:
                        dependency_graph[skill_id].append(dep_skill_id)
        
        # 检查循环依赖
        visited = set()
        recursion_stack = set()
        
        def dfs(current_skill: str, path: List[str]) -> bool:
            visited.add(current_skill)
            recursion_stack.add(current_skill)
            
            for neighbor in dependency_graph.get(current_skill, []):
                if neighbor not in dependency_graph:
                    continue  # 依赖的技能可能不存在于图中
                
                if neighbor in recursion_stack:
                    # 发现循环依赖
                    cycle_path = path[path.index(neighbor):] + [neighbor]
                    issues.append(SecurityIssue(
                        level=SecurityIssueLevel.HIGH,
                        message=f"发现循环依赖: {' -> '.join(cycle_path)}",
                        location=f"skills.{current_skill}.dependencies",
                        suggestion="重构依赖关系，消除循环依赖"
                    ))
                    return True
                
                if neighbor not in visited:
                    if dfs(neighbor, path + [neighbor]):
                        return True
            
            recursion_stack.remove(current_skill)
            return False
        
        # 从每个未访问的技能开始DFS
        for skill_id in dependency_graph:
            if skill_id not in visited:
                dfs(skill_id, [skill_id])
        
        return issues
```

### 设计思路

1. **分层验证**：
   - `SecurityValidator`：基类定义接口
   - `SandboxSecurityValidator`：专门验证沙箱配置
   - `SkillSecurityValidator`：专门验证技能配置

2. **安全等级分类**：
   - `CRITICAL`：必须立即修复的问题
   - `HIGH`：高风险问题，应尽快修复
   - `MEDIUM`：中等风险问题，建议修复
   - `LOW`：低风险问题，可选修复

3. **验证规则**：
   - 字段格式验证（类型、范围、格式）
   - 逻辑验证（依赖关系、引用一致性）
   - 安全策略验证（权限、资源限制）
   - 环境检查（系统资源、网络配置）

4. **评分系统**：
   - 基于问题数量和严重程度计算评分

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
依赖关系解析器 - 任务5答案
功能：解析技能依赖关系，检测循环依赖，拓扑排序，版本冲突检测
"""

from typing import Dict, List, Set, Tuple, Optional, Any
from dataclasses import dataclass, field
from enum import Enum
import re
from collections import deque, defaultdict
from packaging.version import parse as parse_version
from packaging.specifiers import SpecifierSet


class DependencyError(Exception):
    """依赖关系相关异常"""
    pass


class CircularDependencyError(DependencyError):
    """循环依赖错误"""
    pass


class VersionConflictError(DependencyError):
    """版本冲突错误"""
    pass


@dataclass
class VersionConflict:
    """版本冲突"""
    skill_id: str
    required_version: str
    actual_version: str
    conflict_type: str  # 'incompatible', 'missing', 'ambiguous'
    message: str


@dataclass
class SkillDependency:
    """技能依赖（简化版）"""
    skill_id: str
    version_constraint: str
    required: bool = True
    description: str = ""


@dataclass
class SkillConfig:
    """技能配置（简化版）"""
    skill_id: str
    name: str
    version: str
    dependencies: List[SkillDependency] = field(default_factory=list)


class DependencyResolver:
    """依赖关系解析器"""
    
    def __init__(self, skills: Dict[str, SkillConfig]):
        self.skills = skills
        self.dependency_graph = self._build_graph()
        self.reverse_graph = self._build_reverse_graph()
        
    def _build_graph(self) -> Dict[str, List[str]]:
        """构建依赖图"""
        graph = defaultdict(list)
        
        for skill_id, skill in self.skills.items():
            for dep in skill.dependencies:
                if dep.required:
                    graph[skill_id].append(dep.skill_id)
        
        return dict(graph)
    
    def _build_reverse_graph(self) -> Dict[str, List[str]]:
        """构建反向依赖图"""
        reverse_graph = defaultdict(list)
        
        for skill_id, dependencies in self.dependency_graph.items():
            for dep_id in dependencies:
                reverse_graph[dep_id].append(skill_id)
        
        return dict(reverse_graph)
    
    def detect_circular_dependencies(self) -> List[List[str]]:
        """检测循环依赖，返回所有循环路径"""
        visited = set()
        recursion_stack = set()
        cycles = []
        
        def dfs(current: str, path: List[str]) -> None:
            visited.add(current)
            recursion_stack.add(current)
            
            for neighbor in self.dependency_graph.get(current, []):
                if neighbor not in self.dependency_graph:
                    continue  # 依赖的技能可能不存在于图中
                
                if neighbor in recursion_stack:
                    # 发现循环依赖
                    cycle_start = path.index(neighbor)
                    cycle = path[cycle_start:] + [neighbor]
                    cycles.append(cycle)
                elif neighbor not in visited:
                    dfs(neighbor, path + [neighbor])
            
            recursion_stack.remove(current)
        
        # 从每个未访问的技能开始DFS
        for skill_id in self.dependency_graph:
            if skill_id not in visited:
                dfs(skill_id, [skill_id])
        
        # 去重：相同的循环可能被多次发现
        unique_cycles = []
        for cycle in cycles:
            # 规范化循环：找到最小表示
            min_index = cycle.index(min(cycle))
            normalized = tuple(cycle[min_index:] + cycle[:min_index])
            if normalized not in unique_cycles:
                unique_cycles.append(normalized)
        
        return [list(cycle) for cycle in unique_cycles]
    
    def topological_sort(self) -> List[str]:
        """拓扑排序，返回初始化顺序"""
        # 检查循环依赖
        cycles = self.detect_circular_dependencies()
        if cycles:
            raise CircularDependencyError(f"存在循环依赖，无法进行拓扑排序: {cycles}")
        
        # 计算入度
        indegree = defaultdict(int)
        for skill_id in self.dependency_graph:
            indegree[skill_id] = 0
        
        for skill_id, dependencies in self.dependency_graph.items():
            for dep_id in dependencies:
                if dep_id in indegree:
                    indegree[dep_id] += 1
        
        # Kahn算法
        queue = deque([skill_id for skill_id in indegree if indegree[skill_id] == 0])
        result = []
        
        while queue:
            current = queue.popleft()
            result.append(current)
            
            for neighbor in self.dependency_graph.get(current, []):
                if neighbor in indegree:
                    indegree[neighbor] -= 1
                    if indegree[neighbor] == 0:
                        queue.append(neighbor)
        
        # 检查是否所有节点都被处理
        if len(result) != len(self.dependency_graph):
            # 存在环但没被detect_circular_dependencies检测到的情况
            remaining = set(self.dependency_graph.keys()) - set(result)
            raise CircularDependencyError(f"无法解析所有依赖，可能存在环: {remaining}")
        
        return result
    
    def check_version_conflicts(self) -> List[VersionConflict]:
        """检查版本冲突"""
        conflicts = []
        
        # 收集每个技能的所有版本要求
        version_requirements = defaultdict(list)  # skill_id -> [(requirer, constraint)]
        
        for skill_id, skill in self.skills.items():
            # 记录技能自身的版本
            if skill_id not in version_requirements:
                version_requirements[skill_id].append((skill_id, f"=={skill.version}"))
            
            # 记录依赖的版本要求
            for dep in skill.dependencies:
                if dep.required:
                    version_requirements[dep.skill_id].append((skill_id, dep.version_constraint))
        
        # 检查每个技能的版本要求是否一致
        for skill_id, requirements in version_requirements.items():
            if skill_id not in self.skills:
                # 依赖的技能不存在
                conflicts.append(VersionConflict(
                    skill_id=skill_id,
                    required_version=requirements[0][1] if requirements else "any",
                    actual_version="missing",
                    conflict_type="missing",
                    message=f"技能 '{skill_id}' 不存在，但被 {[r[0] for r in requirements]} 依赖"
                ))
                continue
            
            actual_version = self.skills[skill_id].version
            
            # 检查所有版本约束是否满足
            for requirer, constraint in requirements:
                try:
                    spec = SpecifierSet(constraint)
                    if not spec.contains(parse_version(actual_version)):
                        conflicts.append(VersionConflict(
                            skill_id=skill_id,
                            required_version=constraint,
                            actual_version=actual_version,
                            conflict_type="incompatible",
                            message=f"技能 '{skill_id}' 版本 {actual_version} 不满足 '{requirer}' 的要求: {constraint}"
                        ))
                except Exception as e:
                    # 版本约束解析失败
                    conflicts.append(VersionConflict(
                        skill_id=skill_id,
                        required_version=constraint,
                        actual_version=actual_version,
                        conflict_type="ambiguous",
                        message=f"技能 '{skill_id}' 版本约束解析失败: {constraint} ({str(e)})"
                    ))
        
        return conflicts
    
    def get_skill_with_all_dependencies(self, skill_id: str) -> List[str]:
        """获取技能的所有依赖（递归）"""
        if skill_id not in self.skills:
            return []
        
        visited = set()
        result = []
        
        def collect_dependencies(current: str) -> None:
            if current in visited:
                return
            
            visited.add(current)
            
            # 先收集依赖的依赖
            for dep in self.skills[current].dependencies:
                if dep.required and dep.skill_id in self.skills:
                    collect_dependencies(dep.skill_id)
            
            # 然后添加当前技能（如果它不是起始技能）
            if current != skill_id:
                result.append(current)
        
        # 收集所有依赖
        for dep in self.skills[skill_id].dependencies:
            if dep.required and dep.skill_id in self.skills:
                collect_dependencies(dep.skill_id)
        
        return result
    
    def get_dependency_tree(self, skill_id: str) -> Dict[str, Any]:
        """获取依赖树结构"""
        if skill_id not in self.skills:
            return {}
        
        def build_tree(current: str, visited: Set[str]) -> Dict[str, Any]:
            if current in visited:
                return {"skill_id": current, "cyclic": True}
            
            visited.add(current)
            
            skill = self.skills[current]
            node = {
                "skill_id": current,
                "name": skill.name,
                "version": skill.version,
                "dependencies": []
            }
            
            for dep in skill.dependencies:
                if dep.required and dep.skill_id in self.skills:
                    dep_node = build_tree(dep.skill_id, visited.copy())
                    dep_node["constraint"] = dep.version_constraint
                    dep_node["required"] = dep.required
                    node["dependencies"].append(dep_node)
            
            return node
        
        return build_tree(skill_id, set())
    
    def get_impact_analysis(self, skill_id: str) -> Dict[str, Any]:
        """获取影响分析：哪些技能依赖于此技能"""
        if skill_id not in self.reverse_graph:
            return {"skill_id": skill_id, "direct_dependents": [], "transitive_dependents": []}
        
        # 直接依赖
        direct_dependents = self.reverse_graph.get(skill_id, [])
        
        # 传递依赖
        transitive_dependents = set()
        visited = set()
        
        def collect_transitive(current: str) -> None:
            if current in visited:
                return
            
            visited.add(current)
            
            for dependent in self.reverse_graph.get(current, []):
                transitive_dependents.add(dependent)
                collect_transitive(dependent)
        
        collect_transitive(skill_id)
        transitive_dependents -= set(direct_dependents)  # 移除直接依赖
        
        return {
            "skill_id": skill_id,
            "direct_dependents": direct_dependents,
            "transitive_dependents": list(transitive_dependents),
            "total_impact": len(direct_dependents) + len(transitive_dependents)
        }
```

### 设计思路

1. **图算法应用**：
   - 依赖图表示：技能为节点，依赖为边
   - DFS检测循环依赖
   - Kahn算法进行拓扑排序
   - 反向图用于影响分析

2. **版本冲突检测**：
   - 收集每个技能的所有版本要求
   - 使用`packaging`库解析语义化版本
   - 检查版本约束是否一致
   - 提供具体的冲突信息

3. **递归依赖收集**：
   - 深度优先收集所有传递依赖
   - 避免无限递归（检测环）
   - 生成结构化的依赖树

4. **影响分析**：
   - 直接依赖：直接引用此技能的技能
   - 传递依赖：通过其他技能间接依赖
   - 总影响：评估修改的影响范围

### 关键要点

1. **算法正确性**：确保图算法的正确实现
2. **性能考虑**：处理大规模依赖图的效率
3. **错误处理**：提供清晰的错误信息
4. **可视化支持**：生成结构化的依赖树

### 常见错误

1. **无限递归**：循环依赖导致的递归死循环
2. **算法复杂度**：大规模图的性能问题
3. **版本解析失败**：无效的版本约束格式
4. **缺失技能**：依赖的技能不存在
