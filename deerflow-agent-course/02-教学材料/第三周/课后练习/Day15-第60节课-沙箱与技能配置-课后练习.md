## 📝 练习任务

### 任务1：沙箱配置设计（20分钟）

**目标**：设计一个完整的沙箱配置系统，支持三种不同的沙箱提供者。

**要求**：
1. 创建`sandbox_config.yaml`文件，包含以下提供者：
   - **local-dev**：本地开发沙箱，使用LOCAL提供者类型
   - **docker-prod**：Docker生产沙箱，使用DOCKER提供者类型  
   - **aio-highload**：异步I/O高负载沙箱，使用AIO提供者类型

2. 每个提供者需要配置：
   - 基本属性：名称、描述、启用状态
   - 安全配置：安全级别、资源限制、网络访问控制
   - 环境变量：至少3个环境变量，其中1个使用变量引用 `${VAR_NAME}`
   - 提供者特有配置（如Docker的镜像、卷挂载等）

3. 沙箱配置需要包含：
   - 默认提供者设置为`local-dev`
   - 沙箱级别的环境变量和元数据
   - 默认安全配置作为所有提供者的基准

**提示**：
- 参考课堂演示代码中的`ExampleConfigGenerator.generate_sandbox_config()`方法
- 安全级别使用：TRUSTED（本地开发）、RESTRICTED（Docker生产）、SANDBOXED（高负载）
- 环境变量引用格式：`${API_KEY}` 或 `${LOG_LEVEL:INFO}`（带默认值）

### 任务2：技能系统配置（25分钟）

**目标**：设计一个技能系统，包含5个相互依赖的技能。

**要求**：
1. 创建`skills_config.yaml`文件，包含以下技能：
   - **data-fetcher**：数据获取技能（WEB_SCRAPER类型）
   - **data-cleaner**：数据清洗技能（TEXT_PROCESSOR类型）
   - **data-analyzer**：数据分析技能（CALCULATOR类型）
   - **result-exporter**：结果导出技能（FILE_CONVERTER类型）
   - **system-logger**：系统日志技能（TEXT_PROCESSOR类型）

2. 每个技能需要配置：
   - 基本信息：技能ID、名称、描述、版本（语义化版本号）
   - 技能类型和状态（至少1个技能为DISABLED状态）
   - 依赖关系（创建合理的依赖链）
   - 配置参数（根据技能类型设置合适的参数）
   - 安全配置（指定沙箱提供者和安全级别）

3. 依赖关系设计：
   ```
   data-fetcher → data-cleaner → data-analyzer → result-exporter
           ↳ system-logger（可选依赖）
   ```
   - `data-cleaner`依赖`data-fetcher`（必需）
   - `data-analyzer`依赖`data-cleaner`（必需）
   - `result-exporter`依赖`data-analyzer`（必需）
   - `system-logger`是所有技能的可选依赖

4. 技能系统配置需要包含：
   - 默认沙箱提供者
   - 启用自动依赖解析和版本检查
   - 系统元数据（名称、版本、环境）

**提示**：
- 版本号使用语义化版本：主版本.次版本.修订号
- 依赖版本约束：`>=1.0.0`、`^2.0.0`、`~3.1.0`等
- 安全配置与沙箱提供者匹配：高风险技能使用Docker沙箱

### 任务4：安全配置验证器（15分钟）

**目标**：实现一个安全配置验证器，确保配置符合安全策略。

**要求**：
1. 创建`security_validator.py`文件，实现以下类：
   - `SecurityValidator`：安全验证器基类
   - `SandboxSecurityValidator`：沙箱安全验证器
   - `SkillSecurityValidator`：技能安全验证器

2. 验证规则：
   **沙箱安全验证**：
   - CPU限制必须在1%-100%之间
   - 内存限制必须大于0且小于系统可用内存
   - 网络白名单必须使用有效的正则表达式
   - 特权模式只能用于TRUSTED安全级别
   - 执行时间限制必须合理（>0且<3600秒）

   **技能安全验证**：
   - 技能必须指定沙箱提供者
   - 高风险技能（WEB_SCRAPER、API_CLIENT）必须使用RESTRICTED或更高安全级别
   - 技能参数必须进行类型和范围验证
   - 依赖的技能必须存在且版本兼容

3. 实现方法：
   ```python

           """验证配置，返回安全问题列表"""
           pass

           """检查资源限制"""
           pass
       
       def _check_network_access(self, config) -> List[SecurityIssue]:
           """检查网络访问权限"""
           pass
       
       def _check_privilege_escalation(self, config) -> List[SecurityIssue]:
           """检查权限提升风险"""
           pass
   ```

4. 安全等级评估：
   - 根据验证结果计算安全评分（0-100）
   - 将安全问题分类：CRITICAL、HIGH、MEDIUM、LOW
   - 生成安全报告，包含改进建议

**提示**：
- 使用正则表达式验证网络白名单格式
- 考虑实际系统限制（如可用内存）
- 安全评分可以基于问题数量和严重程度计算
