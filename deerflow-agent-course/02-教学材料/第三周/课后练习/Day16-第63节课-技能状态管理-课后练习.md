## 🔍 调试技巧

### 常见问题及解决方案
1. **JSON序列化错误**：
   ```
   错误：TypeError: Object of type datetime is not JSON serializable
   解决方案：自定义JSON编码器，或使用dataclasses.asdict()
   ```

2. **并发更新冲突**：
   ```
   错误：多个线程同时修改状态导致数据不一致
   解决方案：使用锁机制（asyncio.Lock或threading.Lock）
   ```

3. **文件权限问题**：
   ```
   错误：PermissionError: [Errno 13] Permission denied
   解决方案：检查文件读写权限，或使用用户可写目录
   ```

4. **内存泄漏问题**：
   ```
   错误：内存使用持续增长
   解决方案：检查历史记录、事件订阅等资源是否及时释放
   ```

5. **性能瓶颈**：
   ```
   问题：状态保存频繁导致IO瓶颈
   解决方案：实现延迟保存、批量保存、增量更新
   ```

### 调试工具
1. **日志记录**：使用Python logging模块记录详细日志
2. **性能分析**：使用cProfile或py-spy分析性能瓶颈
3. **内存分析**：使用tracemalloc或objgraph分析内存使用
4. **异步调试**：使用asyncio调试工具分析异步任务
