# 🎓 详细教案模板 - 45分钟课堂

## 📋 课程基本信息
- **课程名称**: Day 13 - 第50节课：记忆提取流程实现
- **授课日期**: 第二周，第13天
- **上课时间**: 45分钟（建议安排在上午时段，学生思维清晰）
- **授课教师**: 张老师（10年AI系统架构经验，DeerFlow核心贡献者）
- **学生背景**: Python基础一般，已学习记忆系统架构设计，了解Fact数据模型和MemoryStore接口
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线，支持实时算法演示

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. **记忆提取算法**: 理解多级记忆提取算法的流程和设计原理
2. **相关性计算**: 掌握记忆相关性计算的多种方法（TF-IDF、向量相似度等）
3. **多级存储策略**: 理解会话记忆、短期记忆、长期记忆的不同提取策略
4. **优先级排序**: 掌握记忆优先级排序算法和权重分配原则

### 技能目标（学生将能够）
1. **实现提取算法**: 能够实现extract_memory函数，支持多级记忆提取
2. **计算相关性**: 能够实现Fact.relevance_score方法，计算记忆与查询的相关性
3. **设计提取策略**: 能够根据业务需求设计合适的记忆提取策略
4. **优化提取性能**: 能够分析和优化记忆提取流程的性能

### 情感/态度目标
1. **培养算法思维**: 建立算法设计思维，理解流程优化的重要性
2. **增强实践能力**: 提高动手实现能力，将设计转化为可运行代码
3. **树立质量意识**: 重视算法实现的正确性和性能

## 📚 教学重点与难点
- **教学重点**: 
  1. extract_memory函数的五步流程设计（搜索、合并、去重、排序、截断）
  2. 多级存储的不同提取策略和参数设置
  3. 相关性评分算法的实现和优化

- **教学难点**: 
  1. 异步编程在记忆提取中的正确使用
  2. 相关性计算算法的选择和实现复杂度
  3. 记忆去重算法的设计和实现

- **突破方法**: 
  1. 使用同步版本简化教学，逐步引入异步优化
  2. 提供多种相关性计算方法的对比和选择指南
  3. 使用可视化工具展示记忆提取流程的数据流

## 🎭 师生互动设计

### 提问策略
1. **导入提问**: "当Agent需要回答问题时，如何从记忆中提取相关信息？"（激活已有知识）
2. **引导提问**: "为什么需要从多级存储中分别提取记忆？"（引导学生思考设计原理）
3. **挑战提问**: "如果记忆量非常大，提取算法需要如何优化？"（激发深度思考）
4. **应用提问**: "在你们自己的项目中，记忆提取可能面临什么挑战？"（促进知识迁移）

1. **小组讨论**: 3-4人小组，讨论不同业务场景下的记忆提取策略

3. **案例分析**: 分析真实DeerFlow项目中的记忆提取实现
4. **算法评审**: 互相评审提取算法实现，提高代码质量

### 反馈机制
1. **即时反馈**: 课堂问答，及时纠正理解偏差

## 🔧 差异化教学

## 📊 评估方式

### 形成性评估（课堂内）
1. **观察评估**: 观察学生参与度、理解程度、练习完成情况
2. **提问评估**: 通过提问检验知识掌握，特别是算法设计原理
3. **练习评估**: 检查extract_memory优化实现的质量和性能
4. **自评互评**: 学生自我评估掌握程度，互相评价算法实现

### 总结性评估（课堂后）
1. **作业评估**: 批改相关性计算作业，评分反馈算法质量和性能
2. **测验评估**: 单元测验，检验记忆提取算法知识的掌握程度
3. **项目评估**: 在周项目中评估记忆提取功能的设计和实现
4. **综合评估**: 结合课堂表现、作业质量、项目贡献综合评价

### 评估标准
- **优秀（90-100分）**: 全面掌握提取算法原理，能独立设计高质量提取流程，算法性能优秀
- **良好（80-89分）**: 基本掌握核心算法，能完成指定优化任务，算法实现正确
- **合格（60-79分）**: 理解关键算法，需要指导完成优化任务，算法基本功能正常
- **需改进（<60分）**: 需要重新学习记忆提取核心算法
