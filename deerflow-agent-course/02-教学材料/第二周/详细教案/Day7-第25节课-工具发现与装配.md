# 🎓 详细教案 - 工具发现与装配

## 📋 课程基本信息
- **课程名称**: 工具发现与装配
- **授课日期**: 第7天 - 第1节课
- **上课时间**: 09:00-09:45（45分钟）
- **授课教师**: 张老师（高级架构师讲师）
- **学生背景**: 已完成前6天课程，掌握中间件和图片处理，了解工具系统基础概念
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解DeerFlow工具系统的五大设计原则及其重要性
2. 掌握动态工具发现机制的实现原理和技术细节
3. 理解工具装配系统的三层加载架构（内置、自定义、MCP）
4. 了解模块导入、类扫描和实例化过程中的安全考虑

### 技能目标（学生将能够）
1. 实现基于路径扫描的动态工具发现器
2. 编写支持多源工具加载的装配系统
3. 设计合理的工具配置过滤机制
4. 处理模块导入失败和类发现的异常情况

### 情感/态度目标
1. 培养系统安全性和可扩展性的设计意识
2. 建立插件化架构和动态加载的工程思维
3. 激发对模块化系统和插件生态的创新兴趣

## 📚 教学重点与难点
- **教学重点**: 
  1. 工具发现机制的路径扫描和模块导入
  2. 工具装配系统的三层加载架构
  3. 统一接口设计和工具实例化
- **教学难点**: 
  1. 动态导入的异常处理和错误恢复
  2. 模块名转换和相对路径计算
  3. 工具类识别和实例化策略
- **突破方法**: 
  1. 通过流程图展示发现和装配流程
  2. 分步骤实现关键算法
  3. 提供完整的错误处理示例

```markdown
# 课堂练习：实现路径到模块名转换方法

## 任务描述
在提供的ToolDiscovery类基础上，完善_path_to_module方法，实现以下功能：
1. 将文件系统路径转换为Python模块名
2. 正确处理相对路径和绝对路径
3. 移除.py扩展名并将路径分隔符转换为点号
4. 返回标准的模块导入字符串

## 要求
- [ ] 支持绝对路径和相对路径输入
- [ ] 正确处理不同操作系统路径分隔符（/或\）
- [ ] 移除.py扩展名（如果存在）
- [ ] 转换路径分隔符为点号（.）
- [ ] 处理当前工作目录的相对关系

## 步骤指导
1. 将输入路径转换为Path对象：path = Path(file_path)
2. 计算相对于当前工作目录的相对路径：relative = path.relative_to(Path.cwd())
3. 将路径对象转换为字符串：path_str = str(relative)
4. 替换路径分隔符：module_path = path_str.replace("/", ".").replace("\\", ".")
5. 移除.py扩展名：if module_path.endswith(".py"): module_path = module_path[:-3]
6. 返回转换后的模块名

## 提示与技巧
- 使用Path.cwd()获取当前工作目录
- Path.relative_to()计算相对路径，需要处理可能的ValueError
- 使用replace()处理不同操作系统的路径分隔符
- 注意处理没有.py扩展名的情况

## 检查点
- [ ] 测试1：相对路径 "tools/search.py" → "tools.search"
- [ ] 测试2：绝对路径 "/home/user/project/tools/calc.py" → "tools.calc"  
- [ ] 测试3：Windows路径 "tools\\search.py" → "tools.search"
- [ ] 测试4：无扩展名路径 "tools/search" → "tools.search"

## 扩展挑战（可选）
- 添加包内模块检测（__init__.py存在性检查）
- 支持嵌套包结构转换（如tools/submodule/calc.py）
- 添加模块名有效性验证（符合Python标识符规则）
```
