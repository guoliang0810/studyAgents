# 🎓 详细教案 - Sandbox工具集

## 📋 课程基本信息
- **课程名称**: Sandbox工具集
- **授课日期**: 第7天 - 第2节课
- **上课时间**: 10:00-10:45（45分钟）
- **授课教师**: 张老师（高级架构师讲师）
- **学生背景**: 已完成工具发现与装配课程，了解工具系统基础和安全概念
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解沙箱工具的安全设计原则和四大防护目标
2. 掌握BashTool和PythonTool的架构设计和实现原理
3. 理解沙箱提供者模式和配置管理机制
4. 了解代码安全检查、资源限制和异常处理策略

### 技能目标（学生将能够）
1. 实现安全的Bash命令执行工具
2. 编写支持模块白名单的Python代码执行工具
3. 设计合理的沙箱配置和资源管理策略
4. 处理命令执行失败和资源超时的异常情况

### 情感/态度目标
1. 培养系统安全性和防护意识
2. 建立安全第一的工程思维和实践习惯
3. 激发对系统安全和隔离技术的研究兴趣

## 📚 教学重点与难点
- **教学重点**: 
  1. 沙箱工具的四大安全设计原则
  2. BashTool和PythonTool的核心实现
  3. 沙箱配置和资源管理机制
- **教学难点**: 
  1. 代码导入安全检查算法
  2. 沙箱资源清理和异常处理
  3. 命令执行结果解析和错误处理
- **突破方法**: 
  1. 通过安全威胁模型讲解防护策略
  2. 分步骤实现关键安全功能
  3. 提供完整的异常处理示例

## 🎭 师生互动设计

### 提问策略
1. **导入提问**: "你见过哪些因为代码执行导致的安全事故？"（激活经验）
2. **引导提问**: "沙箱和容器有什么区别？各有什么优缺点？"（引导技术思考）
3. **挑战提问**: "如何防止通过系统调用绕过沙箱限制？"（激发深度思考）
4. **应用提问**: "在你的项目中，哪些代码需要沙箱执行？"（促进知识迁移）

### 讨论活动
1. **小组讨论**: 3人小组讨论"最佳沙箱安全策略"，5分钟后分享

3. **案例分析**: 分析真实云服务中的代码执行安全机制
4. **代码审查**: 互相review沙箱工具代码，提高代码质量

### 反馈机制
1. **即时反馈**: 课堂问答，及时纠正安全概念误解

4. **项目实战**: 将沙箱工具集成到实际代码执行平台中

### 针对中等水平学生
1. **渐进提升**: 从简单正则检测扩展到语法树分析
2. **榜样学习**: 学习优秀同学的异常处理和资源清理设计

4. **反馈激励**: 及时肯定安全加固和性能改进

## 📊 评估方式

### 形成性评估（课堂内）
1. **观察评估**: 观察学生编写安全工具代码的熟练程度
2. **提问评估**: 通过提问检验沙箱安全知识掌握
3. **练习评估**: 检查_check_imports方法实现正确性
4. **自评互评**: 学生自我评估代码质量，互相评估实现效果

### 总结性评估（课堂后）
1. **作业评估**: 批改沙箱工具集实现，评分反馈
2. **测验评估**: 单元测验，检验工具安全知识掌握
3. **项目评估**: 在周项目中评估安全执行模块质量
4. **综合评估**: 结合课堂表现、作业、测验综合评分

### 评估标准
- **优秀（90-100分）**: 实现完整功能，多层安全检测，资源管理完善，有创新点
- **良好（80-89分）**: 实现基本功能，代码清晰，通过所有安全测试
- **合格（60-79分）**: 实现核心功能，需要少量调试才能运行
- **需改进（<60分）**: 无法实现基本功能，需要重新学习核心概念

```markdown
# 课堂练习：实现Python代码导入安全检查

## 任务描述
在提供的PythonTool类基础上，完善_check_imports方法，实现以下功能：
1. 检查Python代码中的import和from语句
2. 验证导入的模块是否在允许的白名单中
3. 返回检查结果布尔值
4. 支持多行代码和复杂导入语句

## 要求
- [ ] 使用正则表达式匹配import和from语句
- [ ] 提取导入的模块名
- [ ] 检查模块名是否在self.allowed_modules中
- [ ] 处理import module和from module import ...两种格式
- [ ] 返回True（所有导入都允许）或False（发现不允许的导入）

## 步骤指导
1. 编译正则表达式模式：匹配import module和from module import
2. 将代码按行分割：lines = code.split('\n')
3. 遍历每一行，应用正则匹配
4. 如果匹配成功，提取模块名（group(1)或group(2)）
5. 检查模块名是否在允许列表中：module in self.allowed_modules
6. 如果发现不允许的模块，立即返回False
7. 所有行检查完毕，返回True

## 提示与技巧
- 正则模式：r'^\s*import\s+(\w+)|^\s*from\s+(\w+)'
- import语句可能在一行中有多个模块：import a, b, c
- from语句可能有子模块：from package.module import func
- 注意处理空行和注释行
- 考虑使用re.IGNORECASE标志忽略大小写

## 检查点
- [ ] 测试1：允许的导入（import math）返回True
- [ ] 测试2：不允许的导入（import os）返回False  
- [ ] 测试3：from语句（from datetime import datetime）返回True
- [ ] 测试4：多行代码混合导入正确检查

## 扩展挑战（可选）
- 支持import module as alias别名检查
- 添加对导入子模块的检查（如from os.path import join）
- 实现基于AST的深度语法分析
- 添加对第三方包依赖的自动检测
```
