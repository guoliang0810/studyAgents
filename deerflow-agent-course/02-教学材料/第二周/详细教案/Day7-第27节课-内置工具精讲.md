# 🎓 详细教案 - 内置工具精讲

## 📋 课程基本信息
- **课程名称**: 内置工具精讲
- **授课日期**: 第7天 - 第3节课
- **上课时间**: 11:00-11:45（45分钟）
- **授课教师**: 张老师（高级架构师讲师）
- **学生背景**: 已完成沙箱工具集课程，了解工具安全设计和实现基础
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解计算器工具的安全评估机制和字符白名单设计
2. 掌握搜索工具的缓存策略和结果格式化方法
3. 了解内置工具的设计模式和最佳实践
4. 理解工具参数验证、错误处理和用户体验设计

### 技能目标（学生将能够）
1. 实现安全的数学表达式评估工具
2. 编写支持缓存和结果格式化的搜索工具
3. 设计合理的工具接口和参数验证
4. 处理工具执行异常和提供友好的错误信息

### 情感/态度目标
1. 培养安全评估和防御性编程的工程习惯
2. 建立用户体验和性能优化的设计思维
3. 激发对工具设计和开发者体验的创新兴趣

## 📚 教学重点与难点
- **教学重点**: 
  1. 计算器工具的安全评估算法
  2. 搜索工具的缓存机制和结果格式化
  3. 工具错误处理和用户体验设计
- **教学难点**: 
  1. 数学表达式安全评估的上下文限制
  2. 缓存键设计和TTL管理策略
  3. 复杂结果的结构化格式化
- **突破方法**: 
  1. 通过安全威胁模型讲解评估策略
  2. 分步骤实现缓存和格式化功能
  3. 提供完整的错误处理示例

## 🎭 师生互动设计

### 提问策略
1. **导入提问**: "你设计过什么工具？最需要注意的是什么？"（激活经验）
2. **引导提问**: "缓存能解决什么问题？会引入什么新问题？"（引导技术思考）

3. **案例分析**: 分析真实计算软件的安全评估机制
4. **代码审查**: 互相review工具实现代码，提高代码质量

### 反馈机制
1. **即时反馈**: 课堂问答，及时纠正安全评估误解

## 🔧 差异化教学

### 针对基础薄弱学生
1. **简化任务**: 提供CalculatorTool框架代码，只需填空实现安全评估
2. **额外支持**: 一对一辅导Python eval和上下文，延长练习时间
3. **资源推荐**: 提供Python安全编程和缓存技术教程
4. **成功体验**: 设计可达成的子目标：实现基础表达式评估

### 针对进阶学生
1. **扩展挑战**: 实现支持自定义函数和变量的表达式评估
2. **创新空间**: 鼓励探索基于LRU和LFU的混合缓存策略
3. **领导机会**: 担任小组长，帮助其他同学理解缓存设计原理
4. **项目实战**: 将内置工具集成到实际业务系统中

### 针对中等水平学生
1. **渐进提升**: 从简单缓存扩展到多级缓存架构
2. **榜样学习**: 学习优秀同学的错误处理和用户提示设计
3. **目标引导**: 设定明确目标：实现高性能的工具系统
4. **反馈激励**: 及时肯定性能优化和用户体验改进

## 📊 评估方式

### 形成性评估（课堂内）
1. **观察评估**: 观察学生编写工具代码的熟练程度
2. **提问评估**: 通过提问检验内置工具知识掌握
3. **练习评估**: 检查_safe_eval方法实现正确性
4. **自评互评**: 学生自我评估代码质量，互相评估实现效果

### 总结性评估（课堂后）
1. **作业评估**: 批改内置工具集实现，评分反馈
2. **测验评估**: 单元测验，检验工具设计知识掌握
3. **项目评估**: 在周项目中评估工具模块质量
4. **综合评估**: 结合课堂表现、作业、测验综合评分

### 评估标准
- **优秀（90-100分）**: 实现完整功能，安全评估完善，缓存高效，用户体验优秀，有创新点
- **良好（80-89分）**: 实现基本功能，代码清晰，通过所有测试
- **合格（60-79分）**: 实现核心功能，需要少量调试才能运行
- **需改进（<60分）**: 无法实现基本功能，需要重新学习核心概念

```markdown
# 课堂练习：实现数学表达式安全评估

## 任务描述
在提供的CalculatorTool类基础上，完善_safe_eval方法，实现以下功能：
1. 检查表达式中的字符是否在允许的白名单中
2. 构建安全的评估上下文，限制可用函数和变量
3. 使用eval在受限上下文中计算表达式
4. 返回计算结果或抛出异常

## 要求
- [ ] 定义允许的字符集合：数字、运算符、括号、空格
- [ ] 遍历表达式检查每个字符
- [ ] 发现非法字符抛出ValueError
- [ ] 构建安全的数学上下文：只包含安全的数学函数
- [ ] 使用eval(expression, math_context)计算表达式

## 步骤指导
1. 定义允许字符集合：allowed_chars = set("0123456789+-*/.()%^&|<> =")
2. 遍历表达式字符：for char in expression:
3. 检查字符是否允许：if char not in allowed_chars: raise ValueError
4. 构建数学上下文字典：
   - 清空__builtins__：{"__builtins__": {}}
   - 添加安全函数：abs, round, min, max, sum, pow
   - 添加数学函数：sqrt, sin, cos, tan, log, exp
   - 添加数学常量：pi, e
5. 使用eval计算：return eval(expression, math_context)

## 提示与技巧
- 注意处理空格字符：空格应该在允许字符中
- 考虑扩展运算符：添加**表示幂运算
- 数学函数需要导入math模块：import math
- 可以使用math_context.update()批量添加函数
- 考虑添加自定义函数如：factorial, gcd等

## 检查点
- [ ] 测试1：简单计算 "2+3*4" 返回14
- [ ] 测试2：函数计算 "sqrt(16)+sin(0)" 返回4.0  
- [ ] 测试3：非法字符检测 "2+eval('1')" 抛出ValueError
- [ ] 测试4：常量使用 "pi*2" 返回6.283185307179586

## 扩展挑战（可选）
- 添加变量支持：允许使用预定义的变量如x,y,z
- 支持自定义函数定义和调用
- 实现表达式语法树构建和优化
- 添加表达式复杂度限制，防止过深递归
```
