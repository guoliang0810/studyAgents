# 🎓 详细教案 - Day8 第31节课：LocalSandboxProvider

## 📋 课程基本信息
- **课程名称**: Day8-第31节课：LocalSandboxProvider
- **授课日期**: 第8天（第二周星期一）
- **上课时间**: 11:00-11:45（第3节课）
- **授课教师**: DeerFlow认证架构师讲师
- **学生背景**: Python基础一般，已学习Sandbox抽象接口和Provider模式，了解异步编程基础
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解LocalSandboxProvider的实现原理，包括Provider和具体Sandbox的分离设计
2. 掌握LocalSandbox的核心功能：工作目录隔离、环境变量合并、异步子进程执行
3. 了解本地沙箱的安全限制机制及其在实际应用中的重要性

### 技能目标（学生将能够）
1. 阅读和分析LocalSandboxProvider的完整实现代码
2. 使用LocalSandbox执行简单的系统命令，验证沙箱功能
3. 实现自定义的LocalSandbox扩展，添加额外的安全限制

### 情感/态度目标
1. 培养对代码执行安全的重视，理解隔离机制的重要性
2. 增强对异步编程实际应用的认识，掌握异步子进程管理技巧
3. 激发对底层系统调用的好奇心，探索更多安全执行的可能性

## 📚 教学重点与难点
- **教学重点**: 
  1. LocalSandboxProvider的实现原理和代码结构
  2. LocalSandbox的核心方法：`execute`、`__init__`的实现细节
  3. 本地沙箱的安全限制机制和实际效果
- **教学难点**: 
  1. 异步子进程创建和管理的复杂性，特别是超时和错误处理
  2. 环境变量合并和工作目录隔离的实现原理
  3. 安全限制的平衡：功能性与安全性的权衡
- **突破方法**: 
  1. 通过分步骤代码分析，逐步理解异步执行流程
  2. 使用流程图展示命令执行的生命周期
  3. 实际演示安全限制的效果，加深理解

# 课堂练习：LocalSandbox命令执行实践

## 任务描述
使用LocalSandbox执行系统命令，验证沙箱功能并理解安全限制效果。

## 要求
- [ ] 创建SandboxConfig配置，指定工作目录和超时时间
- [ ] 使用LocalSandboxProvider创建LocalSandbox实例
- [ ] 执行至少3个不同的系统命令（如ls、pwd、echo）
- [ ] 观察命令执行结果，验证工作目录隔离效果
- [ ] 测试超时功能，验证命令超时处理

## 步骤指导
1. 导入必要的模块：LocalSandboxProvider、SandboxConfig
2. 创建SandboxConfig配置：
   ```python
   config = SandboxConfig(
       provider="local",
       workdir="/tmp/test_sandbox",
       timeout=5.0,
       env={"TEST_ENV": "test_value"}
   )
   ```
3. 创建LocalSandboxProvider实例并获取LocalSandbox
4. 执行测试命令：
   ```python
   # 执行ls命令
   result = await sandbox.execute("ls", ["-la"])
   print(result.stdout)
   
   # 执行pwd命令验证工作目录
   result = await sandbox.execute("pwd", [])
   print(result.stdout)
   
   # 测试超时（使用sleep命令）
   result = await sandbox.execute("sleep", ["10"])
   ```
5. 观察输出结果，分析沙箱行为

## 提示与技巧
- 确保工作目录存在，或让LocalSandbox自动创建
- 注意异步函数的调用方式（await）
- 超时测试时使用较短的超时时间（如2秒）
- 捕获和处理可能的异常（如TimeoutError）

## 检查点
- [ ] 成功创建LocalSandbox实例
