# 🎓 详细教案 - Day9 第33节课：虚拟路径架构

## 📋 课程基本信息
- **课程名称**: Day9-第33节课：虚拟路径架构
- **授课日期**: 第9天（第二周星期二）
- **上课时间**: 9:00-9:45（第1节课）
- **授课教师**: DeerFlow认证架构师讲师
- **学生背景**: Python基础一般，已学习沙箱系统基础知识，了解文件路径操作
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解虚拟路径系统在沙箱环境中的重要性和应用场景
2. 掌握路径映射的基本原理，包括虚拟路径到实际路径的转换过程
3. 了解路径遍历攻击的防范机制和安全性设计原则

### 技能目标（学生将能够）
1. 阅读和分析VirtualPathSystem的实现代码，理解路径翻译逻辑
2. 实现简单的虚拟路径映射系统，支持基本的路径转换功能
3. 识别和防范常见的路径安全漏洞，如路径遍历攻击

### 情感/态度目标
1. 培养对系统安全性的重视，理解路径隔离在沙箱环境中的关键作用
2. 增强对文件系统抽象层的认识，掌握虚拟化技术的基本原理
3. 激发对系统底层安全机制的探索兴趣，主动学习和应用安全设计原则

## 📚 教学重点与难点
- **教学重点**: 
  1. 虚拟路径映射的基本原理和实现方式
  2. VirtualPathSystem类的核心方法和设计思想
  3. 路径遍历攻击的检测和防范机制
- **教学难点**: 
  1. 路径标准化和规范化处理，特别是跨平台兼容性问题
  2. 映射规则的优先级和匹配逻辑设计
  3. 安全性设计与功能性的平衡策略
- **突破方法**: 
  1. 通过实际路径映射示例展示转换过程
  2. 使用流程图展示路径翻译的完整流程
  3. 实际演示路径遍历攻击和防护效果

- **软件**: Python 3.12.0、VS Code、Git、文件系统工具

# 课堂练习：虚拟路径系统实现

## 任务描述
实现一个简单的虚拟路径系统，支持基本的路径映射和安全性检查。

## 要求
- [ ] 定义VirtualPathSystem类，包含`translate`方法
- [ ] 支持基本的路径映射规则（前缀匹配）
- [ ] 实现路径标准化和规范化
- [ ] 添加路径遍历攻击检测（防止`../`）
- [ ] 提供默认映射到基础目录的功能

## 步骤指导
1. 定义VirtualPathSystem类，初始化基础目录和映射规则
2. 实现`translate`方法：
   - 标准化输入路径：`os.path.normpath`
   - 安全检查：检测`..`组件
   - 应用映射规则：遍历映射表，前缀匹配
   - 默认映射：映射到基础目录
3. 添加映射规则管理方法：`add_mapping(prefix, target)`
4. 编写测试用例验证功能：
   ```python
   vps = VirtualPathSystem("/tmp/base")
   vps.add_mapping("/workspace", "/tmp/workspace")
   result = vps.translate("/workspace/project/file.txt")
   # 应返回: /tmp/workspace/project/file.txt
   ```

## 提示与技巧
- 使用`os.path.normpath`处理路径标准化
- 注意路径分隔符的跨平台兼容性
- 映射规则按添加顺序检查，注意优先级
- 安全检测要处理多种形式的路径遍历（如`./../`）

## 检查点
- [ ] VirtualPathSystem类正确定义
- [ ] `translate`方法正确实现标准化和安全检测
- [ ] 映射规则正确应用，前缀匹配正常工作
- [ ] 路径遍历攻击被正确检测并阻止
- [ ] 默认映射到基础目录功能正常

## 扩展挑战（可选）
