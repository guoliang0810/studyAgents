## 📝 第二部分：简答题答案

**1. 记忆提取五步流程**

**答案**:

| 步骤 | 输入 | 处理逻辑 | 输出 |
|------|------|---------|------|
| 搜索(Search) | 查询、多层存储 | 遍历各层，计算相关性，过滤低分 | 各层候选列表 |
| 合并(Merge) | 各层候选列表 | 合并所有候选，标记来源层 | 统一候选列表 |
| 去重(Deduplicate) | 统一候选列表 | 计算内容相似度，合并/删除重复 | 去重后列表 |
| 排序(Score & Sort) | 去重后列表 | 计算综合评分，按分数降序 | 有序列表 |
| 截断(Truncate) | 有序列表 | 取前max_results个 | 最终结果 |

---

**2. 四种相关性计算方法**

**答案**:

| 方法 | 原理 | 适用场景 | 时间复杂度 |
|------|------|---------|-----------|
| 精确匹配 | 完全相同返回1.0 | ID查询、精确查找 | O(n) |
| 子串匹配 | 查询在内容中的覆盖比例 | 短查询匹配 | O(n×m) |
| 关键词匹配 | Jaccard相似度(交集/并集) | 多关键词查询 | O(n+m) |
| TF-IDF | TF×IDF，考虑词的重要性 | 长文本相关性 | O(n+m+k) |

---

**3. 综合评分计算方法**

**答案**:
```
综合评分 = 相关性×W1 + 置信度×W2 + 时间分数×W3 + 访问分数×W4
```

权重设计考虑：
- **RELEVANCE优先**：相关性40%，置信度30%，时间20%，访问10%
- **CONFIDENCE优先**：置信度40%，相关性30%，时间20%，访问10%
- **RECENCY优先**：时间40%，相关性30%，置信度20%，访问10%
- **ACCESS优先**：访问40%，相关性40%，置信度20%

---

**4. 时间衰减机制**

**答案**:
```
时间分数 = exp(-衰减因子 × 时间差(秒))
```

不同记忆类型的衰减因子：
- **会话记忆**：λ=0.01（快速衰减，1小时后分数约0.03）
- **短期记忆**：λ=0.001（中等衰减，1天后分数约0.4）
- **长期记忆**：λ=0.0001（缓慢衰减，1周后分数约0.5）

设计考虑：
- 会话记忆时效性强，需要快速衰减
- 长期记忆稳定性强，衰减应较慢

---

**5. 多级存储提取优先级**

**答案**:
```
会话记忆 > 短期记忆 > 长期记忆
```

处理同一记忆出现在多层：
1. 按优先级顺序提取（会话→短期→长期）
2. 使用seen_ids记录已出现的ID
3. 同一ID只保留最高优先级来源

## 💻 第五部分：实现任务答案

**任务1: 向量相似度计算参考实现**

```python
import math
from typing import List

def cosine_similarity(vec1: List[float], vec2: List[float]) -> float:
    """计算余弦相似度"""
    if len(vec1) != len(vec2):
        return 0.0
    
    dot_product = sum(a * b for a, b in zip(vec1, vec2))
    norm1 = math.sqrt(sum(a * a for a in vec1))
    norm2 = math.sqrt(sum(b * b for b in vec2))
    
    if norm1 == 0 or norm2 == 0:
        return 0.0
    
    return dot_product / (norm1 * norm2)
```
