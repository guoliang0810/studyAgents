## 📝 第二部分：简答题答案

**1. 为什么需要记忆更新队列？**

**答案**:
直接更新存储的问题：
1. **并发冲突**：多个Agent同时更新同一记忆，可能导致数据丢失
2. **性能问题**：频繁写入影响读取性能
3. **错误恢复**：更新失败无法重试，数据不一致
4. **顺序问题**：更新顺序可能影响最终结果

队列的优势：
- 串行化处理，避免并发冲突
- 异步处理，不影响主线程
- 支持失败重试
- 优先级控制

**2. 冲突检测的三个条件**

**答案**:
```python
def detect_conflict(existing, new):
    # 条件1: 同一fact_id
    if existing.fact_id != new.fact_id:
        return False
    
    # 条件2: 时间接近（1秒内）
    if abs(existing.timestamp - new.timestamp) >= 1.0:
        return False
    
    # 条件3: 更新类型相同或不兼容
    if (existing.update_type == DELETE and 
        new.update_type in [UPDATE, MERGE]):
        return True
    if (existing.update_type in [UPDATE, ADD] and
        new.update_type in [UPDATE, ADD]):
        return True
    
    return False
```

**3. 三种冲突解决策略**

**答案**:

| 策略 | 原理 | 适用场景 |
|------|------|---------|
| LAST_WRITE_WINS | 时间戳更新的获胜 | 大多数场景，保证数据最新 |
| FIRST_WRITE_WINS | 时间戳更早的获胜 | 保留原始数据，防止覆盖 |
| MERGE | 合并两个更新的内容 | 非冲突字段，多源数据 |

```python
def get_delay(retry_count):
```

**5. MemoryUpdateQueue的线程安全设计**

**答案**:
```python
def process_next(self):
    with self._lock:  # 加锁访问共享数据
        if not self._queue:
            return None
        update = max(self._queue)
        self._queue.remove(update)
        self._processing_queue[update.id] = update
    
    # 不持有锁处理更新
    success = self._process_update(update)
    
    with self._lock:  # 再次加锁更新状态
        if success:
            self._completed_updates.append(update)
```

关键点：
- 只在访问共享数据时加锁
- 处理更新时不持有锁
- 使用deque保证线程安全的队列操作

```python
import heapq

class PriorityQueue:
    def __init__(self):
        self._queue = []
        self._counter = 0  # 用于相同优先级时的FIFO
    
    def push(self, item, priority):
        # 使用负数实现最大堆（Python heap是最小堆）
        heapq.heappush(self._queue, (-priority, self._counter, item))
        self._counter += 1
    
    def pop(self):
        if not self._queue:
            return None
        priority, counter, item = heapq.heappop(self._queue)
        return item
    
    def peek(self):
        if not self._queue:
            return None
        return self._queue[0][2]
    
    def __len__(self):
        return len(self._queue)
```
