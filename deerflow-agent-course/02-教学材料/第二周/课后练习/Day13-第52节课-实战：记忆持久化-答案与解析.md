## 📝 第二部分：简答题答案

**1. SQLite内存数据库需要持久连接的原因**

SQLite的`:memory:`数据库在每次连接时创建全新的空数据库。如果每次都创建新连接，之前的数据会丢失。解决方案：
- 保持一个持久连接（`_persistent_conn`）
- 操作都使用这个连接
- 对于文件数据库，可以每次创建新连接

**2. Fact序列化/反序列化流程**

序列化：
```
Fact对象 → to_dict() → dict → json.dumps() → JSON字符串
```

反序列化：
```
JSON字符串 → json.loads() → dict → Fact.from_dict() → Fact对象
```

**3. 三种持久化策略对比**

| 策略 | 优点 | 缺点 |
|------|------|------|
| 数据库 | 查询灵活，支持索引，事务 | 需要数据库服务 |
| 文件 | 简单，无依赖 | 查询能力弱，大文件性能差 |
| 混合 | 兼顾两者优点 | 实现复杂 |
