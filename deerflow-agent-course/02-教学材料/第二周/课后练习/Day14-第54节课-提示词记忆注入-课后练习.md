## 📝 基础练习

### 练习1：模板扩展方法实现

**任务**：实现三种不同的PromptTemplate扩展方法，并比较其优缺点。

**要求**：
1. **继承扩展**：创建`InheritedMemoryTemplate`类，继承BasePromptTemplate
2. **组合扩展**：创建`ComposedMemoryTemplate`类，组合BasePromptTemplate实例
3. **装饰器扩展**：创建`memory_injection_decorator`装饰器函数
4. **比较分析**：编写对比报告，分析三种方法的适用场景

**提示**：
- 继承扩展：使用`super()`调用父类方法，添加记忆功能
- 组合扩展：将BaseTemplate作为属性，委托方法调用
- 装饰器扩展：使用`@decorator`语法，包装模板函数
- 比较维度：扩展性、性能、代码复杂度、测试难度

### 练习2：上下文注入策略优化

**任务**：优化ContextInjector，实现智能上下文注入策略。

**要求**：
1. **内容选择算法**：基于查询相关性、记忆新鲜度、置信度综合评分
2. **动态注入模式**：根据上下文质量和数量动态选择注入模式
3. **格式化优化**：实现多种上下文格式化模板（列表式、摘要式、对话式）
4. **优先级控制**：为不同来源的记忆设置优先级权重

**提示**：
- 相关性计算：基于关键词匹配、语义相似度、主题一致性
- 新鲜度权重：`freshness = 1 / (1 + age_in_days * decay_rate)`
- 综合评分：`score = relevance * 0.5 + freshness * 0.3 + confidence * 0.2`
- 注入模式选择：高质量多记忆→PREPEND，低质量少记忆→CONDITIONAL

### 练习3：模板变量系统增强

**任务**：增强TemplateVariableSystem，支持高级变量功能。

**要求**：
1. **变量类型转换**：支持自动类型转换和格式化（如数字转字符串）
2. **变量依赖管理**：支持变量间的依赖关系和计算表达式
3. **变量作用域**：实现局部变量和全局变量的作用域管理
4. **变量验证链**：支持多个验证器的链式调用和错误聚合

**提示**：
- 类型转换：使用`ast.literal_eval`安全转换，支持`int()`, `float()`, `str()`等
- 依赖关系：使用有向图管理变量依赖，拓扑排序确保计算顺序
- 作用域管理：使用嵌套字典实现作用域链，支持变量遮蔽
- 验证链：验证器列表按顺序执行，收集所有错误信息

## 🔧 进阶练习

### 练习4：参数化记忆模板引擎

**任务**：实现完整的参数化记忆模板引擎。

**要求**：
1. **模板语法**：支持变量插值、条件语句、循环语句、函数调用
2. **模板编译**：将模板编译为可执行代码或中间表示
3. **模板缓存**：缓存编译结果，提高重复渲染性能
4. **模板调试**：提供模板调试工具，显示变量替换过程

**提示**：

- 编译优化：使用AST解析模板，生成Python代码或自定义字节码
- 缓存策略：基于模板内容和参数的哈希值作为缓存键
- 调试工具：记录每个变量的替换过程和最终结果

### 练习5：记忆检索优化算法

**任务**：优化记忆检索算法，提高相关记忆的召回率和准确率。

**要求**：
1. **向量化检索**：使用文本嵌入向量进行语义相似度计算
2. **混合检索**：结合关键词匹配和向量检索的混合策略
3. **检索缓存**：缓存频繁查询的检索结果，提高响应速度
4. **检索评估**：实现检索效果评估指标（召回率、准确率、F1值）

**提示**：
- 向量模型：使用sentence-transformers或OpenAI embeddings
- 混合策略：`score = keyword_score * 0.4 + vector_score * 0.6`
- 缓存设计：使用LRU缓存，缓存键为查询文本的哈希值
- 评估指标：使用人工标注或自动评估计算检索质量

### 练习6：模板性能监控系统

**任务**：实现模板系统的性能监控和优化工具。

**要求**：
1. **性能指标收集**：模板编译时间、变量替换时间、记忆检索时间
2. **性能分析**：识别性能瓶颈，提供优化建议
3. **自动优化**：基于性能数据自动调整缓存策略和检索参数
4. **监控面板**：可视化展示性能指标和系统状态

**提示**：
- 指标收集：使用`time.perf_counter()`精确计时
- 瓶颈分析：使用Python profiler或自定义性能分析器
- 自动优化：基于历史数据训练简单模型预测最优参数
- 可视化：使用matplotlib或web框架创建监控面板

## 🎯 挑战练习

**任务**：实现完全自适应的模板系统，根据使用情况自动优化。

**要求**：
1. **模板学习**：根据使用反馈自动调整模板内容和结构
2. **参数自适应**：自动调整模板参数和记忆注入策略
3. **A/B测试**：支持不同模板版本的A/B测试和效果对比
4. **在线优化**：实时收集反馈并更新模板配置

**提示**：
- 反馈收集：记录模板使用次数、用户满意度、任务完成率
- 学习算法：使用强化学习或多臂老虎机算法

- 在线更新：使用热更新机制，无需重启服务更新模板

### 挑战2：分布式模板服务

**任务**：设计并实现分布式模板服务架构。

**要求**：
1. **服务拆分**：将模板编译、记忆检索、变量替换拆分为独立服务
2. **负载均衡**：支持多实例部署和请求负载均衡
3. **服务发现**：实现服务注册发现和健康检查
4. **容错处理**：支持服务故障自动转移和降级处理

**提示**：
- 微服务架构：每个功能作为独立服务，通过API或消息队列通信
- 负载均衡：使用Nginx或服务网格实现请求分发
- 服务发现：使用Consul、Etcd或Kubernetes服务发现
- 容错策略：超时重试、断路器模式、降级方案

### 挑战3：模板安全加固

**任务**：加强模板系统的安全性，防止注入攻击和数据泄露。

**要求**：
1. **输入验证**：严格验证所有模板输入，防止恶意内容
2. **沙箱执行**：在安全沙箱中执行模板编译和渲染
3. **访问控制**：控制模板变量的访问权限和数据可见性
4. **审计日志**：记录所有模板操作，支持安全审计

**提示**：
- 输入消毒：移除或转义危险字符和脚本标签
- 沙箱技术：使用Python的`restricted`模式或容器隔离
- 权限模型：基于角色的访问控制（RBAC）或属性访问控制（ABAC）
- 审计跟踪：记录操作者、操作时间、操作内容和结果
