## 📝 第二部分：简答题答案

**1. 技能目录标准化设计**

**意义**:
- 统一接口：所有技能有相同的入口文件和配置格式
- 便于发现：系统可以自动扫描和识别技能
- 易于维护：统一的结构便于管理和更新
- 安全可控：标准化结构便于安全检查

**必需文件**:
- `__init__.py`: Python包标识文件
- `main.py`: 技能主入口，包含`run`函数

**推荐文件**:
- `config.json`: 技能配置（名称、版本、描述、依赖等）
- `README.md`: 技能文档
- `requirements.txt`: Python依赖列表

**2. 动态加载流程**

```python
def load_skill(self, skill_name):
    # 1. 构建技能路径
    skill_path = os.path.join(self.skills_dir, skill_name)
    
    # 2. 验证技能路径
    is_valid, errors = self.validator.validate_skill_path(skill_path)
    
    # 3. 检查是否已加载
    if skill_name in self.loaded_modules:
        return True, self.loaded_modules[skill_name], []
    
    # 4. 动态加载模块
    main_path = os.path.join(skill_path, "main.py")
    spec = importlib.util.spec_from_file_location(f"skill_{skill_name}", main_path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    
    # 5. 缓存模块
    self.loaded_modules[skill_name] = module
    return True, module, []
```

**3. 技能注册和执行流程**

**注册流程**:
1. 验证技能路径是否有效
2. 读取`config.json`获取元数据（或使用默认值）
3. 创建`SkillMetadata`对象
4. 调用`loader.load_skill`加载技能模块
5. 更新技能状态，添加到注册表

**执行流程**:
1. 从注册表获取技能元数据
2. 通过`loader.get_skill_function`获取`run`函数
3. 调用`run(context)`执行技能
4. 捕获异常，构建`SkillResult`返回

**4. 安全检查**

**目的**:
- 防止恶意技能执行危险操作
- 确保技能路径在允许的目录范围内
- 验证技能文件的完整性和合法性

**实现方式**:
```python
class SkillPathValidator:
    def validate_skill_path(self, skill_path):
        # 1. 检查路径是否在基础目录下
        if not skill_path.startswith(self.base_dir):
            return False, ["技能路径不在基础目录下"]
        
        # 2. 检查目录是否存在
        if not os.path.exists(skill_path):
            return False, ["技能目录不存在"]
        
        # 3. 检查必需文件
        for req_file in self.REQUIRED_FILES:
            if not os.path.exists(os.path.join(skill_path, req_file)):
                return False, [f"缺少必需文件: {req_file}"]
        
        return True, []
    
    def validate_skill_name(self, name):
        # 只允许字母、数字、下划线、连字符
        return bool(re.match(r'^[a-zA-Z0-9_-]+$', name))
```

class SkillScaffoldGenerator:
    def __init__(self, base_dir: str = "/skills"):
        self.base_dir = base_dir
    
    def generate(self, skill_name: str, **kwargs) -> str:
        """生成标准技能目录"""

class DependencyChecker:
    def check_dependencies(self, skill_metadata: SkillMetadata) -> Dict[str, Any]:
        """检查技能依赖"""
        results = {
            "skill_name": skill_metadata.name,
            "python_deps": [],
            "skill_deps": [],
            "all_satisfied": True,
            "missing": []
        }
        
        # 检查Python包依赖
        for dep in skill_metadata.dependencies:
            try:
                importlib.import_module(dep)
                results["python_deps"].append({"name": dep, "satisfied": True})
            except ImportError:
                results["python_deps"].append({"name": dep, "satisfied": False})
                results["missing"].append(dep)
                results["all_satisfied"] = False
        
        return results
```

class SkillLoaderWithHotReload(SkillLoader):
    def __init__(self, skills_dir: str = "/skills"):
        super().__init__(skills_dir)
        self.file_timestamps = {}  # 技能名 -> 最后修改时间
    
    def check_and_reload(self, skill_name: str) -> bool:
        """检查并重载已修改的技能"""
        skill_path = os.path.join(self.skills_dir, skill_name)
        main_path = os.path.join(skill_path, "main.py")
        
        # 获取文件修改时间
        current_mtime = os.path.getmtime(main_path)
        last_mtime = self.file_timestamps.get(skill_name, 0)
        
        # 检查是否需要重载
        if current_mtime > last_mtime:
            self.unload_skill(skill_name)
            success, module, _ = self.load_skill(skill_name)
            if success:
                self.file_timestamps[skill_name] = current_mtime
            return success
        return True  # 不需要重载
```
