## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. **监控系统架构**: 理解现代监控系统的分层架构和核心组件
2. **指标类型与设计**: 掌握计数器、仪表、直方图、摘要等指标类型的适用场景
3. **结构化日志**: 了解结构化日志的优势和实现方法，支持高效日志分析
4. **监控数据可视化**: 理解监控数据收集、存储、查询和可视化的完整流程

### 技能目标（学生将能够）
1. **实现指标收集器**: 能够使用Prometheus客户端库实现Agent系统指标收集
2. **设计健康检查系统**: 能够实现分层健康检查，监控系统各组件状态
3. **集成结构化日志**: 能够使用structlog等库实现结构化日志记录
4. **构建监控仪表板**: 能够使用Grafana构建AI Agent系统监控仪表板

### 情感/态度目标
1. **培养可观测性意识**: 认识到监控系统对生产环境稳定性和问题排查的重要性
2. **建立数据驱动思维**: 理解通过指标数据驱动系统优化和决策的价值
3. **增强运维能力自信**: 通过构建完整监控体系，提升对生产系统运维的信心

## 📚 教学重点与难点
- **教学重点**: 
  1. Prometheus指标类型的选择和正确使用
  2. 结构化日志的设计和实现要点
  3. 健康检查系统的分层设计和实现
- **教学难点**: 
  1. 指标标签设计的合理性和对查询性能的影响
  2. 结构化日志与现有代码的集成和迁移
  3. 监控系统的性能开销控制和优化
- **突破方法**: 
  1. 通过实际案例展示不同指标类型的使用场景
  2. 使用对比演示展示结构化日志与传统日志的差异
  3. 通过性能测试展示监控系统开销和优化方法

from prometheus_client import (
    Counter, Gauge, Histogram, Summary, start_http_server
)
import time
from contextlib import contextmanager

# 定义指标
AGENT_REQUESTS_TOTAL = Counter(
    'agent_requests_total',
    'Total agent requests',
    ['agent_type', 'status']
)

AGENT_REQUEST_DURATION = Histogram(
    'agent_request_duration_seconds',
    'Agent request duration',
    ['agent_type'],
    buckets=[0.1, 0.5, 1.0, 2.0, 5.0, 10.0]
)

AGENT_CONCURRENT_REQUESTS = Gauge(
    'agent_concurrent_requests',
    'Current concurrent agent requests',
    ['agent_type']
)

TOOL_CALLS_TOTAL = Counter(
    'tool_calls_total',
    'Total tool calls',
    ['tool_name', 'status']
)

class AgentMetrics:
    """Agent指标收集器"""
    
    def __init__(self, agent_type: str):
        self.agent_type = agent_type
    
    @contextmanager
    def track_request(self):
        """跟踪请求指标"""
        AGENT_CONCURRENT_REQUESTS.labels(
            agent_type=self.agent_type
        ).inc()
        
        start_time = time.time()
        
        try:
            yield
            status = "success"
        except Exception:
            status = "error"
            raise
        finally:
            duration = time.time() - start_time
            AGENT_REQUEST_DURATION.labels(
                agent_type=self.agent_type
            ).observe(duration)
            
            AGENT_REQUESTS_TOTAL.labels(
                agent_type=self.agent_type,
                status=status
            ).inc()
            
            AGENT_CONCURRENT_REQUESTS.labels(
                agent_type=self.agent_type
            ).dec()
    
    def record_tool_call(self, tool_name: str, success: bool):
        """记录工具调用"""
        status = "success" if success else "error"
        TOOL_CALLS_TOTAL.labels(
            tool_name=tool_name,
            status=status
        ).inc()

import structlog
import logging
from datetime import datetime

# 配置结构化日志
structlog.configure(
    processors=[
        structlog.processors.TimeStamper(fmt="iso"),
        structlog.processors.JSONRenderer()
    ],
    context_class=dict,
    logger_factory=structlog.PrintLoggerFactory(),
    wrapper_class=structlog.BoundLogger,
    cache_logger_on_first_use=True,
)

class StructuredLogger:
    """结构化日志记录器"""
    
    def __init__(self, module_name: str):
        self.logger = structlog.get_logger(module_name)
    
    def log_agent_start(self, thread_id: str, input_data: Dict):
        """记录Agent开始执行"""
        self.logger.info(
            "agent_started",
            thread_id=thread_id,
            input_length=len(str(input_data)),
            timestamp=datetime.now().isoformat()
        )
    
    def log_tool_call(self, tool_name: str, args: Dict, duration: float):
        """记录工具调用"""
        self.logger.info(
            "tool_called",
            tool_name=tool_name,
            args=args,
            duration_ms=duration * 1000,
            timestamp=datetime.now().isoformat()
        )
    
    def log_agent_error(self, thread_id: str, error: Exception, context: Dict):
        """记录Agent错误"""
        self.logger.error(
            "agent_error",
            thread_id=thread_id,
            error_type=type(error).__name__,
            error_message=str(error),
            context=context,
            timestamp=datetime.now().isoformat()
        )

### 附录F：监控指标设计指南
| 指标类型 | 适用场景 | 示例指标 | 设计建议 |
