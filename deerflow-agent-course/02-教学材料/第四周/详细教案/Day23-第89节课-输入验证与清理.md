## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. **安全威胁类型**: 理解AI Agent系统面临的主要安全威胁，特别是提示注入、数据泄露等
2. **多层防御原理**: 掌握输入验证的多层防御架构，包括结构验证、内容验证、业务验证和清理
3. **敏感信息检测**: 了解敏感信息（信用卡、SSN、API密钥等）的检测和模糊化处理技术
4. **输入清理技术**: 掌握HTML转义、危险字符移除、递归清理等输入安全处理技术

### 技能目标（学生将能够）
1. **实现多层验证器**: 能够设计和实现包含四层验证的输入验证系统
2. **检测敏感信息**: 能够使用正则表达式检测和模糊化处理敏感信息
3. **安全清理输入**: 能够实现递归的输入清理功能，处理嵌套数据结构
4. **集成验证系统**: 能够将验证系统集成到DeerFlow Agent处理流程中

### 情感/态度目标
1. **培养安全意识**: 认识到输入验证是AI Agent系统的第一道安全防线的重要性
2. **建立防御性编程思维**: 理解"不信任任何输入"的安全编程原则
3. **增强安全实践自信**: 通过实现生产级验证系统，提升对安全架构设计的信心

## 📚 教学重点与难点
- **教学重点**: 
  1. 多层输入验证架构的设计和实现
  2. 敏感信息检测的正则表达式模式和模糊化处理
  3. 递归输入清理技术的实现和应用
- **教学难点**: 
  1. 处理嵌套数据结构的验证和清理
  2. 平衡验证严格性和用户体验
  3. 性能优化的验证系统实现
- **突破方法**: 
  1. 通过逐步代码演示展示递归验证的工作原理
  2. 使用案例分析展示不同场景下的验证策略
  3. 通过性能测试展示验证系统的开销和优化方法

### 附录B：输入验证实现代码示例
```python
from typing import Any, Dict, List
import re
from html import escape

class InputValidator:
    """多层级输入验证器"""
    
    def __init__(self, security_config: Dict):
        self.config = security_config
        
    async def validate_agent_input(self, input_data: Dict) -> Dict:
        """验证Agent输入"""
        
        validated = {}
        
        # 第一层：类型和结构验证
        validated = self._validate_structure(input_data)
        
        # 第二层：内容验证
        validated = await self._validate_content(validated)
        
        # 第三层：业务逻辑验证
        validated = await self._validate_business_rules(validated)
        
        # 第四层：清理和转义
        validated = self._sanitize_input(validated)
        
        return validated
    
    def _validate_structure(self, input_data: Dict) -> Dict:
        """验证输入结构"""
        
        required_fields = self.config.get('required_fields', [])
        for field in required_fields:
            if field not in input_data:
                raise ValidationError(f"Missing required field: {field}")
        
        # 类型检查
        type_rules = self.config.get('type_rules', {})
        for field, expected_type in type_rules.items():
            if field in input_data:
                if not isinstance(input_data[field], expected_type):
                    raise ValidationError(
                        f"Field {field} must be {expected_type.__name__}"
                    )
        
        return input_data.copy()
    
    async def _validate_content(self, input_data: Dict) -> Dict:
        """验证输入内容"""
        
        # 长度限制
        max_lengths = self.config.get('max_lengths', {})
        for field, max_len in max_lengths.items():
            if field in input_data:
                value = str(input_data[field])
                if len(value) > max_len:
                    raise ValidationError(
                        f"Field {field} exceeds maximum length {max_len}"
                    )
        
        # 正则表达式模式验证
        patterns = self.config.get('patterns', {})
        for field, pattern in patterns.items():
            if field in input_data:
                value = str(input_data[field])
                if not re.match(pattern, value):
                    raise ValidationError(
                        f"Field {field} does not match required pattern"
                    )
        
        # 敏感信息检测
        if self.config.get('detect_sensitive_info', False):
            await self._detect_sensitive_info(input_data)
        
        return input_data
    
    def _sanitize_input(self, input_data: Dict) -> Dict:
        """清理输入数据"""
        
        sanitized = {}
        
        for key, value in input_data.items():
            if isinstance(value, str):
                # HTML转义
                sanitized[key] = escape(value)
                
                # 移除危险字符
                dangerous_patterns = [
                    r'<script.*?>.*?</script>',
                    r'on\w+=".*?"',
                    r'javascript:'
                ]
                
                for pattern in dangerous_patterns:
                    sanitized[key] = re.sub(
                        pattern, '', sanitized[key], flags=re.IGNORECASE
                    )
            elif isinstance(value, dict):
                sanitized[key] = self._sanitize_input(value)
            elif isinstance(value, list):
                sanitized[key] = [
                    self._sanitize_input(item) if isinstance(item, dict)
                    else escape(str(item)) if isinstance(item, str)
                    else item
                    for item in value
                ]
            else:
                sanitized[key] = value
        
        return sanitized

import re
from typing import List, Tuple

class SensitiveInfoDetector:
    """敏感信息检测器"""
    
    PATTERNS = {
        'credit_card': r'\b(?:\d[ -]*?){13,16}\b',
        'ssn': r'\b\d{3}[-\s]?\d{2}[-\s]?\d{4}\b',
        'email': r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b',
        'phone': r'\b(?:\+?1[-.\s]?)?\(?[0-9]{3}\)?[-.\s]?[0-9]{3}[-.\s]?[0-9]{4}\b',
        'api_key': r'\b(?:sk-|AKIA|AIza)[A-Za-z0-9]{20,}\b'
    }
    
    def detect(self, text: str) -> List[Tuple[str, str]]:
        """检测敏感信息"""
        
        findings = []
        
        for info_type, pattern in self.PATTERNS.items():
            matches = re.finditer(pattern, text, re.IGNORECASE)
            for match in matches:
                # 模糊化敏感信息（只显示部分）
                sensitive_text = match.group()
                masked = self._mask_sensitive_info(info_type, sensitive_text)
                
                findings.append((info_type, masked))
        
        return findings
    
    def _mask_sensitive_info(self, info_type: str, text: str) -> str:
        """模糊化敏感信息"""
        
        if info_type == 'credit_card':
            if len(text) >= 4:
                return f"****-****-****-{text[-4:]}"
        elif info_type == 'ssn':
            if len(text) >= 4:
                return f"***-**-{text[-4:]}"
        elif info_type == 'api_key':
            if len(text) >= 8:
                return f"{text[:4]}...{text[-4:]}"
        
        # 默认模糊化
        if len(text) > 8:
            return f"{text[:2]}...{text[-2:]}"
        else:
            return "***"
```
