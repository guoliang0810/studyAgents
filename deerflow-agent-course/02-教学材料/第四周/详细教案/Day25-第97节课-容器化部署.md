# 🎓 详细教案 - 45分钟课堂

## 📋 课程基本信息
- **课程名称**: 容器化部署
- **授课日期**: 2024年4月18日（周四）
- **上课时间**: 上午9:00-9:45
- **授课教师**: 张老师
- **学生背景**: Python基础一般，刚学完基础语法，对AI有浓厚兴趣，已完成扩展系统学习
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解容器化部署的核心概念和价值
2. 掌握Docker多阶段构建的原理和最佳实践
3. 了解Docker Compose编排工具的使用方法
4. 认识企业级容器化部署的安全考虑和优化策略

### 技能目标（学生将能够）
1. 编写高效的Dockerfile，支持多阶段构建和优化
2. 使用Docker Compose编排多容器应用
3. 配置容器健康检查、资源限制和网络设置
4. 在实际项目中应用容器化部署，提高部署效率和可维护性

### 情感/态度目标
1. 培养对现代化部署技术的重视和兴趣
2. 增强解决复杂部署问题的信心和能力
3. 激发对DevOps文化和自动化部署的热情
4. 培养安全意识和性能优化思维

## 📚 教学重点与难点
- **教学重点**: Docker多阶段构建原理、Docker Compose编排配置、容器安全最佳实践
- **教学难点**: 多阶段构建优化、容器网络配置、健康检查机制、资源限制管理
- **突破方法**: 通过实际代码演示逐步讲解，使用可视化工具展示容器架构，分组讨论设计决策

## 🛠️ 教学资源准备
- **硬件**: 演示用电脑（16GB+ RAM），安装Docker Desktop和Docker Compose
- **软件**: Docker 24+、Docker Compose、VS Code、Git
- **账户**: Docker Hub账户（可选）、GitHub账户
- **代码**: DeerFlow 2.0代码库（提前克隆到本地）、本课示例代码
- **演示材料**: PPT幻灯片、容器架构图、部署流程图
- **学生材料**: 练习手册、Docker配置模板、评估表

## 🎭 师生互动设计

### 提问策略
1. **导入提问**: "容器和虚拟机有什么区别？容器化部署有什么优势？"
2. **引导提问**: "Docker多阶段构建如何优化镜像大小和构建速度？"
3. **挑战提问**: "如何设计容器健康检查，确保应用可用性？"
4. **应用提问**: "在你的项目中，哪些组件适合容器化部署？"

### 讨论活动
1. **小组讨论**: 3-4人小组，讨论不同Docker镜像优化策略的优缺点
2. **头脑风暴**: 集体创意，设计一个支持多环境部署的容器化方案
3. **案例分析**: 分析真实企业项目的容器化部署实现
4. **代码审查**: 互相review Dockerfile和Docker Compose配置，提高代码质量

### 反馈机制
1. **即时反馈**: 课堂问答，及时纠正对容器概念的理解偏差
2. **过程反馈**: 练习指导，帮助学生正确编写Dockerfile
3. **成果反馈**: 作业批改，提供Docker Compose配置的改进建议
4. **同伴反馈**: 学生互评容器化方案，学习优秀设计模式

## 🔧 差异化教学

### 针对基础薄弱学生
1. **简化任务**: 提供基础的Dockerfile模板，只需修改少数配置
2. **额外支持**: 一对一辅导，讲解Docker基本命令和概念
3. **资源推荐**: 提供Docker官方入门教程
4. **成功体验**: 设计简单的"Hello World"容器，快速获得成功体验

### 针对进阶学生
1. **扩展挑战**: 实现支持多架构（ARM/x86）的容器镜像构建
2. **创新空间**: 探索容器安全扫描和漏洞修复
3. **领导机会**: 担任小组长，帮助其他同学理解容器网络
4. **项目实战**: 设计并实现一个小型容器化部署平台

### 针对中等水平学生
1. **渐进提升**: 从简单容器到复杂编排逐步提升
2. **榜样学习**: 学习优秀同学设计的优雅Dockerfile
3. **目标引导**: 设定明确的容器化部署目标
4. **反馈激励**: 及时肯定良好的部署设计决策

### 附录B：学生练习任务卡
```markdown
# 课堂练习：编写一个Python应用的Dockerfile

## 任务描述
为简单的Python Web应用编写Dockerfile，支持容器化部署。

## 要求
- [ ] 使用Python 3.12-slim作为基础镜像
- [ ] 设置工作目录为/app
- [ ] 复制requirements.txt并安装依赖
- [ ] 复制应用代码到容器中
- [ ] 暴露端口8000
- [ ] 设置启动命令：uvicorn main:app --host 0.0.0.0 --port 8000
- [ ] 添加非root用户运行应用（可选，挑战）

## 步骤指导
1. 创建Dockerfile文件
2. 指定基础镜像：FROM python:3.12-slim
3. 设置工作目录：WORKDIR /app
4. 复制依赖文件：COPY requirements.txt .
5. 安装依赖：RUN pip install -r requirements.txt
6. 复制应用代码：COPY . .
7. 暴露端口：EXPOSE 8000
8. 设置启动命令：CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

## 提示与技巧
- 使用.dockerignore文件排除不必要的文件
- 按依赖层顺序组织COPY命令，利用Docker缓存
- 考虑使用多阶段构建减小镜像大小
- 添加健康检查确保应用可用性

## 检查点
- [ ] 基础镜像选择合适
- [ ] 依赖安装正确
- [ ] 端口暴露正确
- [ ] 启动命令正确

## 扩展挑战（可选）
- 实现多阶段构建，分离构建环境和运行环境
- 添加健康检查命令
- 设置资源限制（CPU、内存）
- 配置非root用户运行
```
