# 🎓 详细教案 - 45分钟课堂

## 📋 课程基本信息
- **课程名称**: Kubernetes部署
- **授课日期**: 2024年4月18日（周四）
- **上课时间**: 上午10:00-10:45
- **授课教师**: 张老师
- **学生背景**: Python基础一般，刚学完基础语法，对AI有浓厚兴趣，已完成容器化部署学习
- **教室环境**: 虚拟教室，共享屏幕，10名学员在线

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解Kubernetes的核心概念和架构
2. 掌握Kubernetes部署配置的编写方法
3. 了解服务发现、负载均衡和自动扩缩容机制
4. 认识企业级Kubernetes部署的安全考虑和优化策略

### 技能目标（学生将能够）
1. 编写Kubernetes Deployment、Service、ConfigMap等资源配置
2. 使用Helm Chart管理复杂的Kubernetes应用
3. 配置健康检查、资源限制和自动扩缩容策略
4. 在实际项目中应用Kubernetes部署，提高系统可靠性和可扩展性

### 情感/态度目标
1. 培养对云原生技术和容器编排的重视和兴趣
2. 增强解决复杂分布式系统部署问题的信心和能力
3. 激发对自动化运维和弹性扩展的热情
4. 培养安全意识和性能优化思维

## 📚 教学重点与难点
- **教学重点**: Kubernetes核心概念、Deployment配置、服务发现、自动扩缩容
- **教学难点**: Pod调度策略、网络策略、存储管理、安全上下文配置
- **突破方法**: 通过实际配置演示逐步讲解，使用可视化工具展示Kubernetes架构，分组讨论设计决策

## 🛠️ 教学资源准备
- **硬件**: 演示用电脑（16GB+ RAM），安装Minikube或Kind
- **软件**: Kubernetes集群（Minikube/Kind/k3s）、kubectl、Helm、VS Code
- **账户**: 容器镜像仓库账户（可选）、GitHub账户
- **代码**: DeerFlow 2.0代码库（提前克隆到本地）、本课示例配置
- **演示材料**: PPT幻灯片、Kubernetes架构图、部署流程图
- **学生材料**: 练习手册、Kubernetes配置模板、评估表

## 🎭 师生互动设计

### 提问策略
1. **导入提问**: "Kubernetes和Docker Compose有什么区别？为什么需要容器编排？"
2. **引导提问**: "Deployment如何确保应用的高可用性和可扩展性？"
3. **挑战提问**: "如何设计零停机部署和自动回滚机制？"
4. **应用提问**: "在你的项目中，哪些组件适合部署到Kubernetes？"

### 讨论活动
1. **小组讨论**: 3-4人小组，讨论不同部署策略（滚动更新 vs 蓝绿部署）的优缺点
2. **头脑风暴**: 集体创意，设计一个支持多环境部署的Kubernetes方案
3. **案例分析**: 分析真实企业项目的Kubernetes部署实现
4. **代码审查**: 互相review Kubernetes配置，提高配置质量

### 反馈机制
1. **即时反馈**: 课堂问答，及时纠正对Kubernetes概念的理解偏差
2. **过程反馈**: 练习指导，帮助学生正确编写YAML配置
3. **成果反馈**: 作业批改，提供Kubernetes配置的改进建议
4. **同伴反馈**: 学生互评部署方案，学习优秀设计模式

## 🔧 差异化教学

### 针对基础薄弱学生
1. **简化任务**: 提供基础的Deployment模板，只需修改少数配置
2. **额外支持**: 一对一辅导，讲解Kubernetes基本命令和概念
3. **资源推荐**: 提供Kubernetes官方入门教程
4. **成功体验**: 设计简单的"Hello World" Pod，快速获得成功体验

### 针对进阶学生
1. **扩展挑战**: 实现支持多集群部署和联邦集群管理
2. **创新空间**: 探索服务网格（如Istio）和流量管理
3. **领导机会**: 担任小组长，帮助其他同学理解Kubernetes网络
4. **项目实战**: 设计并实现一个小型Kubernetes多租户平台

### 针对中等水平学生
1. **渐进提升**: 从简单Deployment到复杂Helm Chart逐步提升
2. **榜样学习**: 学习优秀同学设计的优雅Kubernetes配置
3. **目标引导**: 设定明确的Kubernetes部署目标
4. **反馈激励**: 及时肯定良好的部署设计决策

## 📊 评估方式

### 形成性评估（课堂内）
1. **观察评估**: 观察学生参与度、对Kubernetes概念的理解程度
2. **提问评估**: 通过提问检验Deployment配置编写能力
3. **练习评估**: 检查Deployment配置完成情况和质量
4. **自评互评**: 学生自我评估Kubernetes设计，互相评估实现

### 总结性评估（课堂后）
1. **作业评估**: 批改完整Kubernetes配置，评分反馈
2. **测验评估**: 单元测验，检验Kubernetes部署知识点掌握
3. **项目评估**: 项目中的Kubernetes部署方案设计质量
4. **综合评估**: 结合课堂表现、作业质量和项目应用综合评价

### 评估标准
- **优秀（90-100分）**: 全面掌握Kubernetes部署，能独立设计企业级容器编排方案
- **良好（80-89分）**: 基本掌握核心概念，能编写优化的Deployment和Service配置
- **合格（60-79分）**: 理解Kubernetes基本概念，能编写简单Deployment配置
- **需改进（<60分）**: 需要重新学习Kubernetes部署核心概念

## 🚨 应急预案

### 技术故障
1. **网络中断**: 准备离线演示材料，录制Kubernetes命令讲解视频备用
2. **软件故障**: 准备在线Kubernetes环境（如Play with K8s）备用

4. **平台故障**: 准备备用教学平台（Zoom、腾讯会议等）

### 学生问题
1. **理解困难**: 放慢节奏，增加Kubernetes概念示例，一对一辅导
2. **设备问题**: 提供远程协助，共享屏幕指导Minikube安装
3. **时间不足**: 调整内容优先级，先确保Deployment核心概念
4. **兴趣不足**: 增加实际应用场景，展示Kubernetes部署的强大功能

### 内容调整
1. **进度过快**: 增加Deployment练习时间，补充YAML语法讲解
2. **进度过慢**: 精简高级特性细节，聚焦Kubernetes核心概念
3. **内容过难**: 分解复杂概念，先掌握基础Pod再学习Deployment
4. **内容过易**: 增加企业级Kubernetes部署挑战，探讨安全优化

### 附录B：学生练习任务卡
```markdown
# 课堂练习：编写一个简单的Kubernetes Deployment

## 任务描述
为DeerFlow Agent应用编写Kubernetes Deployment配置，支持基本部署需求。

## 要求
- [ ] 定义Deployment资源，副本数为3
- [ ] 使用deerflow-agent:latest镜像
- [ ] 暴露端口8000
- [ ] 设置资源请求和限制（内存512Mi-1Gi，CPU 250m-500m）
- [ ] 配置存活探针（livenessProbe）和就绪探针（readinessProbe）
- [ ] 设置环境变量（至少包含OPENAI_API_KEY）

## 步骤指导
1. 创建deployment.yaml文件
2. 定义apiVersion、kind、metadata
3. 指定副本数：replicas: 3
4. 定义selector匹配标签
5. 定义template，包含容器配置
6. 配置容器镜像、端口、资源限制
7. 添加健康检查配置
8. 设置环境变量

## 提示与技巧
- 使用kubectl explain deployment查看字段说明
- 注意YAML缩进和格式
- 健康检查路径应与应用实际接口匹配
- 敏感信息应使用Secret而不是明文环境变量

## 检查点
- [ ] YAML格式正确
- [ ] 副本数配置正确
- [ ] 资源限制合理
- [ ] 健康检查配置完整

## 扩展挑战（可选）
- 添加Service配置，暴露服务
- 配置ConfigMap存储应用配置
- 添加HorizontalPodAutoscaler支持自动扩缩容
- 使用Secret管理敏感信息
```
