# 🎓 详细教案 - 第109节课：多租户架构

## 📋 课程基本信息
- **课程名称**: 多租户架构（Multi-tenant Architecture）
- **授课日期**: 2024年4月21日（周日）
- **上课时间**: 上午9:00-9:45（第109节课）

## 🎯 教学目标

### 知识目标（学生将知道/理解）
1. 理解多租户架构的基本概念和应用场景
2. 掌握租户隔离的三种模式：数据库级、Schema级、行级隔离
3. 了解租户配额管理和计费系统设计原理

### 技能目标（学生将能够）
1. 实现基础的租户管理器类（TenantManager）
2. 设计租户配额检查和计费逻辑
3. 配置多租户Agent系统的隔离策略

### 情感/态度目标
1. 培养学生对企业级系统设计的兴趣
2. 增强系统安全和数据隔离意识
3. 建立SaaS产品思维和商业模型理解

## 📚 教学重点与难点
- **教学重点**: 租户隔离模式、配额管理、计费系统设计
- **教学难点**: 行级隔离的实现、跨租户数据安全
- **突破方法**: 通过代码示例逐步讲解，结合真实案例演示

from dataclasses import dataclass
from typing import Dict, Optional
import uuid

@dataclass
class Tenant:
    """租户"""
    id: str
    name: str
    plan: str  # free, pro, enterprise
    quota: Dict[str, int]

class TenantManager:
    """租户管理器"""
    
    def __init__(self):
        self.tenants: Dict[str, Tenant] = {}
        self.current_tenant: Optional[str] = None
    
    def create_tenant(self, name: str, plan: str = "free") -> Tenant:
        """创建租户"""
        tenant = Tenant(
            id=f"tenant_{uuid.uuid4().hex[:8]}",
            name=name,
            plan=plan,
            quota=self._get_quota(plan)
        )
        self.tenants[tenant.id] = tenant
        return tenant
    
    def _get_quota(self, plan: str) -> Dict[str, int]:
        """获取配额"""
        quotas = {
            "free": {
                "requests_per_day": 100,
                "max_concurrent": 1,
                "storage_mb": 100
            },
            "pro": {
                "requests_per_day": 10000,
                "max_concurrent": 5,
                "storage_mb": 1000
            },
            "enterprise": {
                "requests_per_day": -1,  # 无限制
                "max_concurrent": -1,
                "storage_mb": 10000
            }
        }
        return quotas.get(plan, quotas["free"])
    
    def set_current_tenant(self, tenant_id: str):
        """设置当前租户"""
        if tenant_id not in self.tenants:
            raise ValueError(f"租户不存在: {tenant_id}")
        self.current_tenant = tenant_id
    
    def check_quota(self, resource: str) -> bool:
        """检查配额"""
        if not self.current_tenant:
            return True
        
        tenant = self.tenants[self.current_tenant]
        quota = tenant.quota.get(resource)
        
        if quota is None:
            return True
        
        if quota == -1:  # 无限制
            return True
        
        # 实际使用量检查逻辑
        # TODO: 实现实际使用量跟踪
        return True
    
    def calculate_usage_cost(self, tenant_id: str) -> float:
        """计算使用费用"""
        tenant = self.tenants.get(tenant_id)
        if not tenant:
            return 0.0
        
        pricing = {
            "free": {"per_request": 0.0, "monthly_fee": 0.0},
            "pro": {"per_request": 0.01, "monthly_fee": 99.0},
            "enterprise": {"per_request": 0.005, "monthly_fee": 999.0}

        total_cost = usage_cost + plan_pricing["monthly_fee"]
        
        return total_cost
