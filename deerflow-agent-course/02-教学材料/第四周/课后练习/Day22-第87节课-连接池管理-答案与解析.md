## 🧠 概念理解题答案

### 练习1：连接池核心参数

**答案**：

| 参数 | 含义 | 影响 | 建议值 |
|------|------|------|--------|
| 最小连接数 | 池中保持的最小连接数 | 太少：频繁创建；太多：资源浪费 | 2-5 |
| 最大连接数 | 池中允许的最大连接数 | 太少：等待；太多：数据库压力 | 10-50 |
| 连接超时 | 获取连接的超时时间 | 太长：等待久；太短：容易失败 | 30秒 |
| 空闲超时 | 空闲连接的最大存活时间 | 太长：浪费资源；太短：频繁创建 | 5-10分钟 |
| 回收策略 | 何时回收空闲连接 | 影响连接复用率 | LIFO/FIFO |

### 练习2：连接泄漏问题

**答案**：

**原因**：
1. 获取连接后忘记归还
2. 异常发生时不归还连接
3. 连接超时未正确关闭

**检测方法**：
1. 监控活跃连接数趋势
2. 定期检查连接是否超时
3. 使用连接池的统计功能

**预防措施**：
1. 使用上下文管理器
2. 总是使用try-finally
3. 设置合理的超时时间
4. 添加连接泄漏检测

### 练习4：上下文管理器

**答案**：

```python
from contextlib import contextmanager
from typing import Generator, Optional
import threading
import time

class Connection:
    def __init__(self, conn_id: int):
        self.conn_id = conn_id
        self.created_at = time.time()
        self.last_used = time.time()
    
    def is_valid(self, max_idle_time: float) -> bool:
        return time.time() - self.last_used < max_idle_time
    
    def execute(self, query: str):
        self.last_used = time.time()
        return f"Result: {query}"

class ConnectionPool:
    def __init__(self, min_size: int = 2, max_size: int = 10, max_idle_time: float = 300):
        self.min_size = min_size
        self.max_size = max_size
        self.max_idle_time = max_idle_time
        self._pool = []
        self._lock = threading.Lock()
        self._total = 0
        self._init_pool()
    
    def _init_pool(self):
        for _ in range(self.min_size):
            self._pool.append(Connection(self._total))
            self._total += 1
    
    def get_connection(self, timeout: float = 30) -> Optional[Connection]:
        deadline = time.time() + timeout
        while time.time() < deadline:
            with self._lock:
                if self._pool:
                    conn = self._pool.pop()
                    if conn.is_valid(self.max_idle_time):
                        return conn
                    # 过期，创建新的
                
                if self._total < self.max_size:
                    conn = Connection(self._total)
                    self._total += 1
                    return conn
            
            time.sleep(0.1)
        return None
    
    def return_connection(self, conn: Connection):
        if conn.is_valid(self.max_idle_time):
            with self._lock:
                self._pool.append(conn)

@contextmanager
def get_pooled_connection(pool: ConnectionPool) -> Generator[Connection, None, None]:
    conn = pool.get_connection()
    try:
        yield conn
    finally:
        if conn:
            pool.return_connection(conn)

# 使用示例
pool = ConnectionPool(min_size=2, max_size=10)

with get_pooled_connection(pool) as conn:
    result = conn.execute("SELECT * FROM users")
    print(result)
```

## 🔧 实战应用题答案

### 练习5：连接池监控

**答案**：

添加以下监控指标：
1. `active_connections`：当前活跃连接数
2. `idle_connections`：当前空闲连接数
3. `wait_count`：等待获取连接的请求数
4. `wait_time`：平均等待时间
5. `connection_creates`：创建的连接总数
6. `connection_timeouts`：获取连接超时次数

### 练习6：连接池调优策略

**答案**：

**高并发场景**：
- 增加最大连接数
- 减小空闲超时
- 使用连接复用

**低并发场景**：
- 减小最小连接数
- 增大空闲超时
- 减少资源浪费

**动态调优策略**：
1. 根据CPU/内存使用率调整
2. 根据请求队列长度调整
3. 根据响应时间调整
4. 使用自适应连接池
