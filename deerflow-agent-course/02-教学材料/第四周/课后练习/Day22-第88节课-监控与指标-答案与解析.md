## 🧠 概念理解题答案

### 练习1：四大黄金指标

**答案**：

| 指标 | 含义 | Agent系统测量 | 典型阈值 |
|------|------|--------------|----------|
| 延迟 | 请求处理时间 | LLM调用时间、总响应时间 | P99 < 5s |
| 流量 | 系统处理的请求量 | QPS、并发数 | 根据容量 |
| 错误 | 请求失败率 | 错误计数、5xx率 | < 1% |
| 饱和度 | 资源使用程度 | CPU、内存、队列 | < 80% |

---

### 练习2：指标类型

**答案**：

| 类型 | 特点 | 适用场景 | 示例 |
|------|------|----------|------|
| Counter | 只增不减 | 计数 | 请求总数 |
| Gauge | 可增可减 | 当前值 | 内存使用 |
| Histogram | 统计分布 | 延迟分布 | 请求耗时 |
| Summary | 百分位统计 | 精确百分位 | P99延迟 |

### 练习4：健康检查

**答案**：

```python
import time
from enum import Enum

class HealthChecker:
    def __init__(self):
        self.components = []
    
    def register_check(self, name: str, check_fn: callable):
        self.components.append((name, check_fn))
    
    def check_all(self):
        results = []
        overall = "healthy"
        
        for name, check_fn in self.components:
            start = time.time()
            try:
                is_healthy, msg = check_fn()
                duration = (time.time() - start) * 1000
                status = "healthy" if is_healthy else "unhealthy"
                if not is_healthy:
                    overall = "unhealthy"
            except Exception as e:
                duration = (time.time() - start) * 1000
                status = "unhealthy"
                msg = str(e)
                overall = "unhealthy"
            
            results.append({
                "name": name,
                "status": status,
                "message": msg,
                "response_time_ms": duration
            })
        
        return {
            "status": overall,
            "timestamp": time.time(),
            "components": results
        }

# 使用示例
def check_llm():
    # 检查LLM服务可用性
    return True, "LLM服务正常"

def check_database():
    # 检查数据库连接
    return True, "数据库连接正常"

checker = HealthChecker()
checker.register_check("LLM服务", check_llm)
checker.register_check("数据库", check_database)

result = checker.check_all()
print(result)
```

### 练习5：告警规则设计

**答案**：

**告警级别**：
- Critical（严重）：服务不可用
- Warning（警告）：性能下降
- Info（信息）：需要关注

**告警条件示例**：
```
Critical:
- 错误率 > 10%
- 响应时间 P99 > 30s
- 活跃请求数 > 最大值

Warning:
- 错误率 > 1%
- 响应时间 P99 > 10s
- 内存使用 > 80%
```

### 练习6：监控成本与收益

**答案**：

**成本**：
1. 监控组件的计算/存储资源
2. 指标采集的性能开销
3. 告警处理的人力成本
4. 存储历史数据的成本

**收益**：
1. 快速发现和定位问题
2. 容量规划依据
3. 性能优化方向
4. SLA保障

**优化策略**：
1. 合理设置采集频率
2. 减少高基数标签
3. 分级存储策略
4. 智能告警聚合
