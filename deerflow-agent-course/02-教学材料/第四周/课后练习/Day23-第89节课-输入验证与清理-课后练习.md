### 练习3：输入验证器实现
**题目**: 实现一个通用的输入验证器。

**要求**:
1. 支持字符串长度验证
2. 支持类型验证
3. 支持正则表达式验证
4. 支持自定义验证规则

**代码框架**:
```python
import re
from typing import Any, Callable, List, Optional
from dataclasses import dataclass
from enum import Enum

class ValidationError(Exception):
    """验证错误"""
    pass

class ValidationType(Enum):
    STRING = "string"
    INTEGER = "integer"
    FLOAT = "float"
    BOOLEAN = "boolean"
    LIST = "list"
    DICT = "dict"

@dataclass
class ValidationRule:
    """验证规则"""
    name: str
    validate_fn: Callable[[Any], bool]
    error_message: str

class InputValidator:
    """输入验证器"""
    
    def __init__(self):
        self.rules: List[ValidationRule] = []
    
    def add_rule(self, name: str, validate_fn: Callable, error_message: str):
        """添加验证规则"""
        self.rules.append(ValidationRule(name, validate_fn, error_message))
    
    def validate(self, value: Any) -> Any:
        """验证输入"""
        errors = []
        for rule in self.rules:
            if not rule.validate_fn(value):
                errors.append(rule.error_message)
        
        if errors:
            raise ValidationError("; ".join(errors))
        return value
    
    @staticmethod
    def string_length(min_len: int = 0, max_len: Optional[int] = None):
        """字符串长度验证"""
        def validate(s: str) -> bool:
            if not isinstance(s, str):
                return False
            if len(s) < min_len:
                return False
            if max_len and len(s) > max_len:
                return False
            return True
        return validate
    
    @staticmethod
    def pattern(regex: str):
        """正则表达式验证"""
        compiled = re.compile(regex)
        def validate(s: str) -> bool:
            return isinstance(s, str) and bool(compiled.match(s))
        return validate
    
    @staticmethod
    def allowed_values(values: List[Any]):
        """允许值验证"""
        def validate(v: Any) -> bool:
            return v in values
        return validate
```

**知识点**: 输入验证、数据清洗
**难度**: 进阶
**建议时间**: 15分钟

### 练习4：Prompt注入防护
**题目**: 实现Prompt注入检测和防护机制。

**要求**:
1. 检测常见的Prompt注入模式
2. 实现输入清理和转义
3. 使用语义分析识别恶意提示

**代码框架**:
```python
import re
from typing import List, Tuple

class PromptInjectionDetector:
    """Prompt注入检测器"""
    
    # 常见的注入模式
    INJECTION_PATTERNS = [
        r"ignore\s+previous\s+instructions",
        r"forget\s+all\s+instructions",
        r"disregard\s+.*rules",
        r"system\s*:\s*",
        r"assistant\s*:\s*",
        r"you\s+are\s+now\s+",
        r"new\s+instructions",
        r"override\s+.*system",
    ]
    
    def __init__(self):
        self.patterns = [re.compile(p, re.IGNORECASE) for p in self.INJECTION_PATTERNS]
        self.blocked_phrases = [
            "绕过",
            "忽略",
            "修改指令",
            "系统角色"
        ]
    
    def detect(self, text: str) -> Tuple[bool, List[str]]:
        """检测Prompt注入
        
        返回: (是否安全, 检测到的威胁列表)
        """
        threats = []
        
        # 模式匹配检测
        for pattern in self.patterns:
            matches = pattern.findall(text)
            if matches:
                threats.append(f"检测到注入模式: {matches[0]}")
        
        # 关键词检测
        for phrase in self.blocked_phrases:
            if phrase in text:
                threats.append(f"检测到敏感词: {phrase}")
        
        return len(threats) == 0, threats
    
    def sanitize(self, text: str) -> str:
        """清理输入"""
        # 移除系统提示词
        text = re.sub(r"system:\s*.*", "", text, flags=re.IGNORECASE)
        text = re.sub(r"assistant:\s*.*", "", text, flags=re.IGNORECASE)
        
        # 转义特殊字符
        text = text.replace("\x00", "")
        
        return text.strip()
```

**知识点**: Prompt安全、注入检测
**难度**: 进阶
**建议时间**: 15分钟
