# Day23 第90节课：沙箱安全强化 - 答案与解析

## 概念理解题答案

### 练习1：沙箱逃逸

**答案**：
- 沙箱逃逸是指攻击者突破沙箱限制访问宿主机资源
- 常见类型：内核漏洞利用、符号链接攻击、竞态条件

### 练习2：纵深防御

**答案**：
- 多层防御策略，每层独立
- 层次：网络隔离 → 进程限制 → 文件系统限制 → 资源限制 → 审计日志
