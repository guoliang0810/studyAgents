### 练习3：负载均衡器
**题目**: 实现简单的负载均衡器。

```python
from typing import List
import random

class LoadBalancer:
    def __init__(self, servers: List[str]):
        self.servers = servers
    
    def get_server(self) -> str:
        return random.choice(self.servers)
```
