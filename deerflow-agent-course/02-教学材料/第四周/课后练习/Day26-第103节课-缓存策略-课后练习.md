### 练习3：Redis缓存
**题目**: 实现Redis缓存层。

```python
import redis
import json

class Cache:
    def __init__(self):
        self.client = redis.Redis()
    
    def get(self, key: str):
        data = self.client.get(key)
        return json.loads(data) if data else None
    
    def set(self, key: str, value: any, ttl: int = 3600):
        self.client.setex(key, ttl, json.dumps(value))
```
