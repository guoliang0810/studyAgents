### 练习3：备份脚本
**题目**: 实现数据库备份。

```python
import subprocess
from datetime import datetime

def backup_database(db_url: str, backup_dir: str):
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"backup_{timestamp}.sql"
    cmd = f"pg_dump {db_url} > {backup_dir}/{filename}"
    subprocess.run(cmd, shell=True)
    return filename
```
