### 练习3：性能分析
**题目**: 实现性能分析工具。

```python
import time
from functools import wraps

def profile(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = fn(*args, **kwargs)
        print(f"{fn.__name__} took {time.time() - start:.2f}s")
        return result
    return wrapper
```
