### 练习3：审计日志
**题目**: 实现审计日志系统。

```python
import json
from datetime import datetime

class AuditLogger:
    def __init__(self, output):
        self.output = output
    
    def log(self, action: str, user: str, details: dict):
        entry = {
            "timestamp": datetime.utcnow().isoformat(),
            "action": action,
            "user": user,
            "details": details
        }
        self.output.write(json.dumps(entry) + "\n")
```
