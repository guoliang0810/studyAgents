### 练习3：主题配置
**题目**: 实现主题系统。

```python
from typing import Dict

class Theme:
    def __init__(self, config: Dict):
        self.colors = config.get("colors", {})
        self.logo = config.get("logo", "")
        self.fonts = config.get("fonts", {})
    
    def get_css(self) -> str:
        return f"""
        :root {{
            --primary: {self.colors.get('primary', '#000')};
            --secondary: {self.colors.get('secondary', '#fff')};
        }}
        """
```
