# 📋 第一周项目：基础Agent系统

## 🎯 项目概述

### 项目名称
基础Agent系统开发

### 项目目标
基于DeerFlow框架，开发一个能够处理多轮对话、调用工具、管理状态的完整Agent系统。通过本项目，学员将掌握Agent架构的核心概念和实现技能。

### 项目周期
- **开始时间**：第一周周一
- **截止时间**：第一周周日 23:59
- **预计工作量**：15-20小时

### 适用对象
完成第一周所有课程学习的学员

---

## 📝 项目要求

### 功能要求
#### 核心功能（必须实现）
1. **多轮对话支持**
   - 实现基于ThreadState的状态管理
   - 支持对话历史保存和恢复
   - 实现对话上下文长度管理

2. **工具调用能力**
   - 集成至少3种不同类型的工具
   - 实现工具参数验证和错误处理
   - 支持工具结果的格式化展示

3. **自定义中间件**
   - 实现至少2个自定义中间件
   - 中间件需有实际功能（如日志、监控、验证等）
   - 演示中间件执行顺序的影响

4. **配置系统**
   - 支持通过配置文件调整Agent行为
   - 实现配置的热重载（可选）
   - 提供配置验证和默认值

#### 扩展功能（可选实现）
1. **记忆系统集成**
   - 实现短期记忆和长期记忆
   - 支持基于上下文的记忆检索

2. **多模态支持**
   - 支持图片理解或生成
   - 集成多模态模型

3. **性能优化**
   - 实现响应缓存
   - 优化工具调用性能

### 技术栈要求
- **框架**：DeerFlow 2.0
- **编程语言**：Python 3.12+
- **状态管理**：LangGraph StateGraph
- **工具集成**：LangChain Tools
- **配置管理**：Pydantic + YAML

## 🏗️ 架构设计

### 系统架构图
```
┌─────────────────────────────────────────┐
│            用户界面/API                  │
├─────────────────────────────────────────┤
│          Agent执行引擎                   │
│  ┌─────────────┐  ┌─────────────┐      │
│  │   Lead Agent│  │  中间件链    │      │
│  └─────────────┘  └─────────────┘      │
├─────────────────────────────────────────┤
│           工具系统                       │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐      │
│  │工具1│ │工具2│ │工具3│ │...  │      │
│  └─────┘ └─────┘ └─────┘ └─────┘      │
├─────────────────────────────────────────┤
│           状态管理                       │
│  ┌─────────────────────────────────┐    │
│  │          ThreadState            │    │
│  │  - messages: List[Message]      │    │
│  │  - next: str                    │    │
│  │  - config: RunnableConfig       │    │
│  │  - metadata: Dict               │    │
│  └─────────────────────────────────┘    │
└─────────────────────────────────────────┘
```

### 核心组件设计
1. **Lead Agent**
   - 继承DeerFlow的BaseAgent
   - 实现自定义的提示模板
   - 集成工具调用逻辑

2. **自定义中间件**
   - `LoggingMiddleware`：记录执行日志
   - `ValidationMiddleware`：验证输入和状态
   - `PerformanceMiddleware`：监控性能指标

3. **工具实现**
   - `CalculatorTool`：数学计算工具
   - `WebSearchTool`：网络搜索工具（模拟）
   - `FileOperationTool`：文件操作工具（沙箱内）

4. **配置系统**
   - 使用Pydantic进行配置验证
   - YAML格式配置文件
   - 支持环境变量覆盖

## 🚀 项目启动指南

### 环境准备
```bash
# 1. 克隆或创建项目
mkdir week1-project
cd week1-project

# 2. 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 3. 安装依赖
pip install deerflow==2.0.0
pip install langgraph langchain pydantic yaml
pip install pytest pytest-cov

# 4. 初始化项目结构
mkdir -p src/{agents,middlewares,tools,config,utils}
mkdir -p configs tests examples
```

### 开发步骤建议
1. **Day 1-2**：环境搭建和基础框架

2. **Day 3-4**：核心功能实现

3. **Day 5-6**：完善和测试

### 常见问题
1. **状态管理混乱**
   - 建议：先设计ThreadState结构，再实现Reducer
   - 参考：DeerFlow官方示例

2. **工具集成困难**
   - 建议：从简单工具开始，逐步增加复杂度
   - 参考：LangChain工具文档

3. **中间件执行顺序问题**
   - 建议：使用调试工具跟踪中间件执行
   - 参考：DeerFlow中间件文档
