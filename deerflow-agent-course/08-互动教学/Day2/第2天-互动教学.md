### Reducer函数深入

**张老师**："让我们看看`merge_artifacts`这个Reducer函数："

```python
def merge_artifacts(existing: list[str] | None, new: list[str] | None) -> list[str]:
    """Reducer for artifacts list - merges and deduplicates artifacts."""
    if existing is None:
        return new or []
    if new is None:
        return existing
    # Use dict.fromkeys to deduplicate while preserving order
    return list(dict.fromkeys(existing + new))
```

**小王**："这个函数的作用是合并两个列表并去重吗？"

**张老师**："完全正确！在状态管理中，经常需要合并状态。比如：
- 第一次运行：`artifacts = ["file1.txt"]`
- 第二次运行：`artifacts = ["file2.txt"]`
- 合并后：`artifacts = ["file1.txt", "file2.txt"]`

这就是Reducer的核心思想！"

    """合并计数器"""
    existing = existing or 0
    new = new or 0

# 使用示例

### 复杂Reducer：优先级合并

**张老师**："现在看一个复杂场景：任务优先级。小王，如果有高优先级任务来了，应该怎么办？"

**小王**："应该优先处理高优先级任务？"

**张老师**："对！让我们实现一个优先级合并的Reducer："

```python
from enum import Enum

class Priority(Enum):
    LOW = 1
    MEDIUM = 2
    HIGH = 3
    CRITICAL = 4

def merge_priority(existing: Priority | None, new: Priority | None) -> Priority:
    """合并优先级，取最高优先级"""
    if existing is None:
        return new or Priority.LOW
    if new is None:
        return existing
    return max(existing, new, key=lambda p: p.value)

# 使用示例
class TaskState(ThreadState):
    current_priority: Annotated[Priority, merge_priority]
```

**小王**："这个max函数是按枚举值比较的，值越大优先级越高。"

**张老师**："完全正确！你已经理解了枚举和比较函数的使用。"

### 实战：实现对话热度Reducer

**张老师**："现在请你实现一个'对话热度'Reducer，规则是：
1. 新消息加1热度
2. 每过一轮热度减0.5
3. 热度最低为0"

**小王**："我试试...应该是这样："

```python
def merge_conversation_heat(existing: float | None, new: float | None) -> float:
    """合并对话热度"""
    existing = existing or 0.0
    
    if new is None:
        # 没有新消息，热度衰减
        return max(existing - 0.5, 0.0)
    else:
        # 有新消息，热度增加
        return existing + 1.0

# 测试
heat1 = merge_conversation_heat(None, None)  # 0.0
heat2 = merge_conversation_heat(heat1, 1.0)  # 1.0 (新消息)
heat3 = merge_conversation_heat(heat2, None) # 0.5 (衰减)
heat4 = merge_conversation_heat(heat3, 1.0)  # 1.5 (新消息)

print(f"对话热度变化: {heat1} -> {heat2} -> {heat3} -> {heat4}")
```

**张老师**："太棒了！你不仅实现了功能，还考虑了边界情况（最低为0）。"

### Reducer的设计原则

**张老师**："总结一下Reducer的设计原则：
1. **幂等性**：多次合并结果相同
2. **可交换性**：合并顺序不影响结果
3. **可结合性**：`merge(a, merge(b, c)) == merge(merge(a, b), c)`
4. **空值处理**：正确处理None值"

**小王**："这些原则保证了状态合并的可靠性。"

### 配置继承机制

**张老师**："现在看一个更复杂的配置继承例子："

```python
# 配置继承示例
class AgentConfig:
    def __init__(self):
        self.model = "gpt-4"
        self.temperature = 0.7
        self.max_tokens = 1000
        
    def with_overrides(self, **overrides):
        """创建新配置，覆盖部分值"""
        new_config = AgentConfig()
        new_config.__dict__.update(self.__dict__)
        new_config.__dict__.update(overrides)
        return new_config

# 使用示例
base_config = AgentConfig()
print(f"基础配置: model={base_config.model}, temp={base_config.temperature}")

# 运行时覆盖
runtime_config = base_config.with_overrides(temperature=0.9, max_tokens=2000)
print(f"运行时配置: model={runtime_config.model}, temp={runtime_config.temperature}")
```

def validate_config(config: dict, defaults: dict) -> dict:
    """验证并修正配置"""

    # 验证temperature
    temp = config.get("temperature")
    if temp is not None and 0.0 <= temp <= 2.0:

    return validated

```python
# Reducer函数实现
def merge_duration(existing: int | None, new: int | None) -> int:
    """合并学习时长"""
    existing = existing or 0
    new = new or 0
    return existing + new

def merge_mastery(existing: int | None, new: int | None) -> int:
    """合并掌握程度，取最新值"""
    if new is not None:
        return max(0, min(100, new))  # 限制在0-100
    return existing or 0

def merge_review_schedule(existing: list | None, new: list | None) -> list:
    """合并复习计划"""
    if existing is None:
        return new or []
    if new is None:
        return existing
    # 按时间排序，去重
    combined = existing + new
    return sorted(set(combined))
```

**小王**："这些Reducer考虑得很全面！特别是mastery_level限制了范围。"

from typing import Annotated

class LearningAssistantState(ThreadState):

### 完整示例

**张老师**："最后，让我们看一个完整的学习助手Agent示例："

```python
class LearningAssistant:
    def __init__(self):
        self.state = LearningAssistantState()
    
    def study(self, topic: str, duration: int):
        """学习一个主题"""
        # 更新状态
        self.state["learning_topic"] = topic
        self.state["study_duration"] = duration
        
        # 评估掌握程度（简化）
        mastery_increase = min(duration // 10, 20)  # 每10分钟最多提高2%
        current_mastery = self.state.get("mastery_level", 0)
        self.state["mastery_level"] = current_mastery + mastery_increase
        
        print(f"学习了{topic} {duration}分钟，掌握程度提高{mastery_increase}%")
    
    def schedule_review(self, date: str):
        """安排复习"""
        schedule = self.state.get("review_schedule", [])
        schedule.append(date)
        self.state["review_schedule"] = schedule
        print(f"已安排{date}复习")

# 使用示例
assistant = LearningAssistant()
assistant.study("Python列表", 45)
assistant.schedule_review("2024-03-27")
assistant.study("Python字典", 60)

print(f"\n最终状态:")
print(f"主题: {assistant.state.get('learning_topic')}")
print(f"总时长: {assistant.state.get('study_duration', 0)}分钟")
print(f"掌握程度: {assistant.state.get('mastery_level', 0)}%")
print(f"复习计划: {assistant.state.get('review_schedule', [])}")
```
